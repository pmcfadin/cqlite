## Unit 4 (committed): public-surface differential integration test

New file: `cqlite-core/tests/issue_3935_collection_time_byte_order.rs`
(`#![cfg(feature = "write-support")]` — REQUIRED, `storage::write_engine` is
itself so gated; write-support is DEFAULT so the target executes in
`core-tests`).

5 cases:
* `whole_collection_set_matches_byte_order`
* `whole_collection_map_matches_byte_order`
* `per_element_path_matches_byte_order`
* `both_write_paths_agree_on_element_order`   <- the issue's required oracle
* `in_range_only_collection_order_is_unmoved`

Design:
* WHOLE-COLLECTION path reached via `CellOperation::Write { value: Value::Set /
  Value::Map }` -> `write_set_complex_cells` / `write_map_complex_cells` ->
  `compare_collection_elements`.
* PER-ELEMENT path reached via `CellOperation::WriteComplexElement { cell_path }`
  -> `compare_cell_paths`.
* Values: `T_NEG=-1_000_000_000` (out of range), `T_LOW=9e9`,
  `T_MID=4.32e13`, `T_MAX=86_399_999_999_999`. Insertion order is deliberately
  neither the expected nor the old-signed order, so an insertion-order-preserving
  writer fails both.
* `EXPECTED = [T_LOW, T_MID, T_MAX, T_NEG]` is a HAND-DERIVED LITERAL from
  `TimeType` BYTE_ORDER, NOT read back out of CQLite (#3042 round-trip
  invariance — stated in the file's doc comment).
* PRIMARY leg is a RAW `Data.db` byte scan comparing FILE OFFSETS of each
  value's 8-byte BE pattern: no reader, no comparator, no decode path. It
  asserts each pattern occurs EXACTLY ONCE (this fired for real during
  development, when SET+MAP in one file gave 2 occurrences — fail-closed, not a
  silent first-match). Hence one collection column per SSTable.
* Corroboration leg: `SSTableReader::open` +
  `iterate_all_partitions_for_compaction`.

RED-VERIFIED (measured in this lane): with the arm reverted to `x.cmp(y)`,
`test result: FAILED. 2 passed; 3 failed`. FAIL = the two whole-collection cases
+ the agreement case. PASS = `per_element_path_matches_byte_order` (that path
never consulted the fixed function — the pre-existing divergence) and
`in_range_only_collection_order_is_unmoved` (compatibility pin, correct by
construction). Recorded in the file's own "RED-verified" section.

### An out-of-range `time` IS expressible on the write surface
`CellOperation::Write { value: Value::Set([Value::Time(-1_000_000_000), ..]) }`
is accepted and serialized (`encoding.rs:218` `nanos.to_be_bytes()`), so no
weakening of the test was needed and nothing had to be invented.
