Test-only admission instrumentation (issue #1594 wiring guard). Compiled ONLY under the non-default scan-offload-probe feature: in a normal/default/release build this module, its statics, and its call-sites do not exist, so admission control adds zero test surface and no public API. Exposed as pub (via the parent’s feature-gated pub mod scan_admission) so the integration guard can install a low cap and read the in-flight counters.
