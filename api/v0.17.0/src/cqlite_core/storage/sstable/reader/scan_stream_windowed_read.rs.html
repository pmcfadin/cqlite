1//! Synchronous positional chunk reader for the windowed streaming scan's IO half
2//! (issue #1940 restructure).
3//!
4//! # Why this exists
5//!
6//! The windowed feed runs inside a single `spawn_blocking` task (issues #1593,
7//! #1940): both the raw chunk read AND its decompression must stay OFF the async
8//! worker pool. The former implementation drove the read with
9//! `futures::executor::block_on(read_next_block_parts(..))` — an async read over a
10//! `tokio::fs::File`. Even though it ran on a blocking thread, `tokio::fs`'s
11//! `poll_read` RE-DISPATCHES the actual `read(2)` to tokio's blocking pool, so each
12//! chunk read amplified into a second blocking-pool thread. rust-reviewer proved it
13//! bounded, but roborev flagged it as a latent hang under a small custom
14//! `max_blocking_threads`. Owner decision (issue #1940): REMOVE the hazard class —
15//! read SYNCHRONOUSLY on the `spawn_blocking` thread, with zero nested async and
16//! zero blocking-pool amplification.
17//!
18//! These helpers read via the reader's `scan_positional_source` (issue #2876; was
19//! `point_source` under the original #1940 restructure) — the positional
20//! [`ReadAt`](super::read_at::ReadAt) plane built once at open for EVERY backend
21//! (buffered = `pread` on a dedicated `std::fs::File`; mmap = a resident slice over
22//! the SAME unadvised mapping the scan backend uses; `O_DIRECT` = an aligned
23//! positioned read). A positional read carries its offset as a parameter and
24//! touches no tokio reactor/timer, so it completes fully on the calling (blocking)
25//! thread — no `tokio::fs`, no `block_on`, no second blocking thread. `read_at.rs`'s
26//! module docs anticipated exactly this adoption ("shaped so the windowed streaming
27//! scan can adopt it later"). Decompression continues to run in `decode_scan_chunk`
28//! on the same blocking thread (the D2 substrate placement, unchanged).
29//!
30//! This whole feed is scan-only (`feed_compressed_chunks` / `feed_uncompressed_pieces`
31//! are driven exclusively by the windowed streaming scan, never a point lookup), so
32//! EVERY read here uses `scan_positional_source`, never the reader's dedicated
33//! `MADV_RANDOM` point-read mapping (`point_source`, issue #2210) — that advice
34//! suppresses kernel readahead, which is exactly backwards for this mostly-
35//! sequential feed (issue #2876, the #2210 × #1940 cross-path regression this file
36//! was the other half of).
37//!
38//! Byte-parity + integrity are preserved verbatim from the former cursor path:
39//! - **compressed NB** (`CompressionInfo` present): the same per-chunk record
40//!   geometry (`compressed_chunk_offset`/`compressed_chunk_size`, incl. the +4
41//!   trailing CRC), the same corrupt-offset bounds check (roborev #970), the same
42//!   degenerate empty-trailing-chunk EOF bound (issue #2225), and the same
43//!   CRC32-BEFORE-decompress order (the CRC is verified here; the payload is
44//!   returned only after it matches, so a corrupt chunk never reaches the
45//!   decompressor). The compressed read reuses the caller's per-loop scratch (≤1
46//!   alloc/chunk, D2) and records a scratch-regrowth as a copy-chain alloc so the
47//!   `issue_1940_scan_window_substrate_allocs` guard stays honest.
48//! - **uncompressed NB** (no `CompressionInfo`; CQLite's own write surface): the
49//!   data section is fed in bounded pieces, and every `CRC.db` chunk covering a
50//!   piece is verified BEFORE the piece is handed on — computing the CRC from the
51//!   resident piece bytes when a chunk is fully contained, else reading the
52//!   straddling prefix/suffix positionally (mirrors
53//!   `verify_uncompressed_section_in_buffer`). Each chunk is verified at most once
54//!   per reader lifetime via the shared `verified_uncompressed_chunks` memo.
55//!
56//! Kept in a sibling file (campsite rule, epic #1116); included via
57//! `#[path = "scan_stream_windowed_read.rs"] impl`-carrying module in the parent.
58

69/// Bytes handed to the parse half per uncompressed-NB read. Mirrors Cassandra's
70/// default 64 KiB compression chunk so the piece size is uniform with the
71/// compressed path; the sliding window stitches across pieces, so the boundary is
72/// invisible to the parse output. CRC verification is done on `CRC.db` chunk
73/// boundaries independently of this piece size.
74const UNCOMPRESSED_READ_PIECE_BYTES: usize = 64 * 1024;
75
76/// Wrap a positional-read failure with human-readable `context` WITHOUT
77/// discarding its [`ErrorKind`](std::io::ErrorKind) (issue #1940 BLOCKER-2).
78///
79/// The synchronous positional read path used to relabel every read failure as
80/// `std::io::Error::other(..)` (kind `Other`), which erased the source kind — so
81/// a genuine transient fault (`Interrupted`/`WouldBlock`/`TimedOut`) surfacing
82/// through the feed could no longer be recognised by [`is_transient_io`] and was
83/// silently NOT retried. Rebuilding the wrapper with the SAME kind keeps the
84/// classifier honest and lets callers up the stack still see the true io kind,
85/// mirroring `block_io::io_error_with_context`. Non-`Io` variants
86/// (corruption/format) are already typed and pass through unchanged.
87fn io_error_with_context(context: impl std::fmt::Display, source: Error) -> Error {
88    match source {
89        Error::Io(io) => {
90            let kind = io.kind();
91            Error::Io(std::io::Error::new(kind, format!("{context}: {io}")))
92        }
93        other => other,
94    }
95}

98    /// Positional `read_exact_at` that applies the SAME one-shot transient-I/O
99    /// retry the former async feed path had (issue #1588 / #1940 BLOCKER-2), and
100    /// records the read thread at the REAL read site (issue #1940 guard
101    /// integrity).
102    ///
103    /// A transient kernel fault (`Interrupted` EINTR / `WouldBlock` EAGAIN /
104    /// `TimedOut`) is retried EXACTLY once by re-reading at the SAME captured
105    /// `offset` (a positional read carries its offset as a parameter, so the retry
106    /// needs no re-seek); every other error — deterministic corruption/format, or
107    /// a non-transient io kind — fails fast. The returned error is the backend's
108    /// `Error::Io`, so its `ErrorKind` is PRESERVED for the caller to annotate via
109    /// [`io_error_with_context`] (never collapsed to `Error::other`).
110    ///
111    /// The `record_io_read_thread` probe fires HERE, at the actual
112    /// `scan_positional_source.read_exact_at` call site (not at the top of the feed closure),
113    /// so the #1940 no-nesting guard records the thread that performs the real read
114    /// — making its `io_read_thread == decode_thread` equality a true detector of a
115    /// read dispatched off the feed thread. Compiled only under `scan-offload-probe`.
116    fn positional_read_exact_retry_once(
117        &self,
118        offset: u64,
119        buf: &mut [u8],
120        scratch: &mut DirectScratch,
121    ) -> Result<()> {
122        #[cfg(feature = "scan-offload-probe")]
123        super::probe::record_io_read_thread();
124        let mut attempt = 0u8;
125        loop {
126            // `read_exact_at_reusing` reuses `scratch`'s aligned bounce buffer on
127            // the Direct-I/O backend (issue #2319 — no per-chunk aligned alloc); for
128            // mmap/plain-file backends it defers to `read_exact_at` and `scratch`
129            // stays empty, so those paths are byte-for-byte unchanged (#1940).
130            match self
131                .scan_positional_source
132                .read_exact_at_reusing(offset, buf, scratch)
133            {
134                Ok(()) => return Ok(()),
135                Err(e)
136                    if attempt == 0
137                        && crate::storage::sstable::reader::block_io::is_transient_io(&e) =>
138                {
139                    tracing::warn!(
140                        "transient I/O fault ({e}) on positional read at offset 0x{offset:x}; \
141                         re-reading once"
142                    );
143                    attempt = 1;
144                }
145                Err(e) => return Err(e),
146            }
147        }
148    }

150    /// Read compressed chunk `chunk_index` SYNCHRONOUSLY via `scan_positional_source`,
151    /// verifying its trailing CRC32 before returning the compressed payload (issue
152    /// #1940). Returns `Ok(None)` at EOF (past the last chunk, or the degenerate
153    /// empty trailing chunk, issue #2225). Mirrors `read_nb_format_chunk_data`'s
154    /// geometry + integrity checks exactly, but positional (no cursor mutex, no
155    /// `tokio::fs`) and reusing the caller's `scratch` (≤1 alloc/chunk, D2).
156    pub(super) fn read_compressed_chunk_sync(
157        &self,
158        chunk_index: usize,
159        scratch: &mut Vec<u8>,
160        direct_scratch: &mut DirectScratch,
161    ) -> Result<Option<Vec<u8>>> {
162        // NO-READ EXITS COME FIRST, BEFORE THE io TIMER EXISTS (issue #1707,
163        // roborev job 133). Every exit below — no `CompressionInfo`, past the last
164        // chunk (EOF), the degenerate empty trailing chunk (#2225) — performs NO
165        // read at all. Timing them would charge function-call and EOF-check time to
166        // `read.phase.io` and emit an io SAMPLE for a scan that read nothing. The
167        // emitter treats a recorded phase as EVIDENCE THAT THE PHASE RAN (entry is
168        // tracked separately from duration, #1707), so constructing a timer here
169        // would state that this scan performed `Data.db` reads when it performed
170        // none — an absent io series is how a caller learns the opposite.
171        let comp_info = match self.compression_info.as_ref() {
172            Some(ci) => ci,
173            // Callers gate on `compression_info.is_some()`; a None here is a bug.
174            None => return Ok(None),
175        };
176
177        if chunk_index >= comp_info.chunk_offsets.len() {
178            return Ok(None); // EOF
179        }
180
181        // Degenerate empty trailing chunk (issue #2225): a chunk whose logical
182        // start is at/after `data_length` carries 0 real bytes; Cassandra's reader
183        // never touches it (every logical position < data_length maps earlier), and
184        // handing 0 bytes to a decompressor fails. Treat it (and anything beyond,
185        // chunk starts being monotonic) as EOF — identical to the cursor path.
186        let chunk_length = comp_info.chunk_length as u64;
187        if chunk_length > 0 {
188            let logical_start = (chunk_index as u64).saturating_mul(chunk_length);
189            if logical_start >= comp_info.data_length {
190                return Ok(None);
191            }
192        }
193
194        // GEOMETRY AND BUFFER PREPARATION RUN UNTIMED (issue #1707, roborev job
195        // 145). Everything from here to the timer below is arithmetic over already-
196        // resident `CompressionInfo` metadata plus a `Vec` reserve — no byte of
197        // `Data.db` is touched. Timing it charged invalid-offset errors, undersized-
198        // chunk errors, bounds failures and ordinary allocation to `read.phase.io`,
199        // whose catalogued meaning is time spent in STORAGE. An allocator stall
200        // reported as storage latency sends the operator to the disk; a geometry
201        // error reported as io emits an io SAMPLE for a call that read nothing.
202        let file_size = self.scan_positional_source.len();
203        let chunk_offset = comp_info
204            .compressed_chunk_offset(chunk_index)
205            .ok_or_else(|| Error::InvalidFormat(format!("No offset for chunk {chunk_index}")))?;
206        let total_chunk_size = comp_info
207            .compressed_chunk_size(chunk_index, file_size)
208            .ok_or_else(|| {
209                Error::InvalidFormat(format!(
210                    "Cannot determine size for chunk {chunk_index} (file_size={file_size})"
211                ))
212            })?;
213        if total_chunk_size < 4 {
214            return Err(Error::InvalidFormat(format!(
215                "Chunk {chunk_index} size too small: {total_chunk_size} bytes (minimum 4 for CRC)"
216            )));
217        }
218        // Bounds-check against the real Data.db length BEFORE allocating — a corrupt
219        // CompressionInfo offset must surface as a recoverable error, never a
220        // multi-exabyte allocation (roborev #970). NB chunk offsets are absolute
221        // (header_offset = 0).
222        let chunk_end = chunk_offset.checked_add(total_chunk_size);
223        match chunk_end {
224            Some(end) if end <= file_size => {}
225            _ => {
226                return Err(Error::InvalidFormat(format!(
227                    "Chunk {chunk_index} at offset 0x{chunk_offset:x} with size {total_chunk_size} \
228                     exceeds Data.db length {file_size} — corrupt CompressionInfo.db chunk offset"
229                )));
230            }
231        }
232        let chunk_data_size = (total_chunk_size - 4) as usize;
233
234        // A5 counters (E4 SEEK_CALLS + E3 READ_CALLS): the positioned read stands in
235        // for the cursor path's per-chunk seek + read, so record one of each per
236        // chunk to keep the `reads == decompresses` substrate invariant intact.
237        rwc::record_seek();
238        rwc::record_read();
239
240        // ONE positioned read for payload + trailing CRC into the REUSED scratch
241        // (D2). Grow-on-demand to the CHECKED `total_chunk_size` for THIS chunk —
242        // never a giant upfront reserve to the metadata `max_compressed_length`
243        // (which Cassandra commonly stamps as `i32::MAX`, an OOM/DoS on ordinary
244        // files, issue #1940 BLOCKER-1). `try_reserve_exact` returns a typed error
245        // on allocation failure instead of panicking/aborting. After the first few
246        // chunks the scratch has reached the working-set high-water mark, so
247        // subsequent chunks hit neither the reserve nor the resize regrowth —
248        // preserving the ≤1-alloc/chunk STEADY STATE (the `record_chunk_path_alloc`
249        // regrowth counter proves it). `clear()`+`resize` reuses the backing store
250        // when large enough (mirrors `read_nb_format_chunk_data`).
251        let mut buf = std::mem::take(scratch);
252        buf.clear();
253        let cap_before = buf.capacity();
254        let need = total_chunk_size as usize;
255        if need > buf.capacity() {
256            if let Err(e) = buf.try_reserve_exact(need) {
257                // Return the scratch to the caller so a retry could reuse it.
258                *scratch = buf;
259                return Err(Error::memory(format!(
260                    "failed to reserve {need} bytes for chunk {chunk_index} \
261                     (data+CRC at offset 0x{chunk_offset:x}): {e}"
262                )));
263            }
264        }
265        buf.resize(need, 0u8);
266        if buf.capacity() > cap_before {
267            rwc::record_chunk_path_alloc();
268        }
269        // io PHASE (issue #1707): the timer opens IMMEDIATELY BEFORE the positional
270        // read and spans the rest of the function — the read itself, its one-shot
271        // transient retry, and the trailing CRC verify, which is part of SERVICING
272        // the read (the payload is not deliverable until it is verified) and is
273        // catalogued inside the phase ("CRC verify included"). A FAILED read stays
274        // charged: it issued a real `pread` and waited for the kernel to answer, so
275        // a slow failing read is io time and must not vanish from the phase exactly
276        // when the disk is sick. Only work that touches no device — geometry above,
277        // buffer allocation above — was moved out. Zero `Instant::now()` when the
278        // scan is unmetered.
279        //
280        // The injected test delay is armed HERE and nowhere earlier, and must MOVE
281        // WITH this timer if it is ever relocated: it stands in for real read
282        // latency, so a call that performs no read must not sleep it, and it must
283        // stay inside the timed region so an armed delay is charged to io exactly as
284        // real latency is.
285        let _io_phase = crate::observability::read_phase::scoped(ReadPhase::Io);
286        crate::observability::read_phase::io_delay::sleep_if_armed();
287        if let Err(e) =
288            self.positional_read_exact_retry_once(chunk_offset, &mut buf, direct_scratch)
289        {
290            // Return the scratch's capacity to the caller so the next read reuses it.
291            buf.clear();
292            *scratch = buf;
293            // Preserve the source io kind (issue #1940 BLOCKER-2) — never collapse
294            // a transient fault to `Error::other`.
295            return Err(io_error_with_context(
296                format!(
297                    "Failed to read chunk {chunk_index} data+CRC ({total_chunk_size} bytes at \
298                     offset 0x{chunk_offset:x})"
299                ),
300                e,
301            ));
302        }
303
304        // Split the trailing 4-byte big-endian CRC32 off the payload and verify it
305        // BEFORE the payload is trusted (guardrail #1411): a mismatch is a typed
306        // error and the payload never reaches the decompressor.
307        let expected_crc = u32::from_be_bytes([
308            buf[chunk_data_size],
309            buf[chunk_data_size + 1],
310            buf[chunk_data_size + 2],
311            buf[chunk_data_size + 3],
312        ]);
313        buf.truncate(chunk_data_size);
314        let computed_crc = crc32fast::hash(&buf);
315        if computed_crc != expected_crc {
316            return Err(Error::InvalidFormat(format!(
317                "CRC32 mismatch for chunk {chunk_index} at offset 0x{chunk_offset:x}: \
318                 expected=0x{expected_crc:08x}, computed=0x{computed_crc:08x}, \
319                 chunk_size={chunk_data_size}"
320            )));
321        }
322        Ok(Some(buf))
323    }

325    /// Read the next bounded piece of an UNCOMPRESSED-NB data section
326    /// SYNCHRONOUSLY via `scan_positional_source`, starting at byte `pos` (an absolute
327    /// Data.db offset). Returns `Ok(None)` at EOF, else `Ok(Some((piece, next_pos)))`.
328    /// Every `CRC.db` chunk covering the piece is verified (once per reader
329    /// lifetime) BEFORE the piece is returned — from the resident bytes when a
330    /// chunk is fully contained, else by reading the straddling remainder
331    /// positionally (issue #1396; mirrors `verify_uncompressed_section_in_buffer`).
332    pub(super) fn read_uncompressed_piece_sync(
333        &self,
334        pos: u64,
335        direct_scratch: &mut DirectScratch,
336    ) -> Result<Option<(Vec<u8>, u64)>> {
337        // The EOF exit comes FIRST, before the io timer exists (issue #1707, roborev
338        // job 133) — same rule as the compressed sibling above: a call that reads
339        // nothing must construct no timer, sleep no injected delay, and contribute
340        // no io sample.
341        let file_size = self.scan_positional_source.len();
342        let remaining = file_size.saturating_sub(pos);
343        if remaining == 0 {
344            return Ok(None); // EOF
345        }
346        // Piece geometry and the destination buffer are prepared UNTIMED (issue
347        // #1707, roborev job 145) — same rule as the compressed sibling above: a
348        // `min` and a `vec![0u8; n]` touch no device, so charging them to
349        // `read.phase.io` would report allocator time as storage latency.
350        let to_read = remaining.min(UNCOMPRESSED_READ_PIECE_BYTES as u64) as usize;
351        let mut buf = vec![0u8; to_read];
352        // io PHASE (issue #1707): opens immediately before the positional piece read
353        // and spans every covering-chunk CRC verify (including the positional reads a
354        // straddling chunk needs). Failed reads stay charged, for the reason given at
355        // the compressed sibling. Injected delay inside, as there.
356        let _io_phase = crate::observability::read_phase::scoped(ReadPhase::Io);
357        crate::observability::read_phase::io_delay::sleep_if_armed();
358        // Same one-shot transient-retry + kind-preserving wrap as the compressed
359        // path (issue #1940 BLOCKER-2): a transient fault is re-read once, and the
360        // source io kind is preserved (never collapsed to `Error::other`).
361        self.positional_read_exact_retry_once(pos, &mut buf, direct_scratch)
362            .map_err(|e| {
363                io_error_with_context(
364                    format!("Failed to read uncompressed piece ({to_read} bytes at 0x{pos:x})"),
365                    e,
366                )
367            })?;
368        let end = pos + to_read as u64;
369
370        // CRC verification (no-op when this reader has no CRC.db). Compute each
371        // covering chunk's CRC from the resident piece when fully contained, else
372        // read the straddling prefix/suffix positionally. `verify_covering_chunks`
373        // is synchronous and memoizes each chunk so it is checked at most once.
374        if let Some(crc) = self.crc_reader.as_deref() {
375            let piece = &buf;
376            self.verify_covering_chunks(crc, pos, end, |lo, hi, chunk| {
377                if lo >= pos && hi <= end {
378                    let s = (lo - pos) as usize;
379                    let e = (hi - pos) as usize;
380                    Ok(crc32fast::hash(&piece[s..e]))
381                } else {
382                    // A chunk straddling the piece boundary must be read off disk.
383                    // Route it through `read_exact_at_reusing` with the SAME per-scan
384                    // `direct_scratch` the main piece read uses (issue #2319), so the
385                    // Direct-I/O backend reuses the one aligned bounce buffer instead
386                    // of allocating a fresh one per straddling chunk. For mmap/plain
387                    // backends this defers to `read_exact_at` (scratch stays empty),
388                    // so those paths are unchanged.
389                    let mut cbuf = vec![0u8; (hi - lo) as usize];
390                    self.scan_positional_source
391                        .read_exact_at_reusing(lo, &mut cbuf, direct_scratch)
392                        .map_err(|e| {
393                            Error::corruption(format!(
394                                "failed to read uncompressed chunk {chunk} at Data.db offset \
395                             0x{lo:x} for CRC verification: {e}"
396                            ))
397                        })?;
398                    Ok(crc32fast::hash(&cbuf))
399                }
400            })?;
401        }
402        Ok(Some((buf, end)))
403    }

405    /// Synchronous compressed-NB feed body (issue #1940): read each compressed
406    /// chunk positionally (CRC verified in the read), decode it (D2), and ship the
407    /// decompressed `Bytes` on `raw_tx`. `Ok(())` on clean EOF or
408    /// consumer-ended-early; `Err` on a read/decode failure. Runs on the feed's
409    /// `spawn_blocking` thread — no `tokio::fs`, no `block_on`, no blocking-pool
410    /// amplification.
411    pub(super) fn feed_compressed_chunks(
412        reader: &Arc<Self>,
413        raw_tx: &mpsc::Sender<bytes::Bytes>,
414        max_compressed_length: usize,
415    ) -> Result<()> {
416        // Reused compressed-read scratch (issue #1940, D2): read fills it, decode
417        // borrows it, recycle for the next read — no per-chunk compressed alloc.
418        //
419        // Reserve ONCE to the ACTUAL working-set high-water mark — the largest
420        // real compressed-chunk RECORD size, computed from the authoritative
421        // `chunk_offsets` deltas (issue #1940 BLOCKER-1). This is NOT the metadata
422        // `max_compressed_length`: Cassandra COMMONLY stamps that field as
423        // `i32::MAX` (it equals `i32::MAX` whenever `minCompressRatio == 0`, the
424        // DEFAULT — CompressionParams.java:186-189), so a `max_compressed_length`-
425        // driven reserve would attempt a multi-GB allocation on opening an ORDINARY
426        // compressed scan (an OOM/DoS before any real chunk size is known). The
427        // offset-delta high-water mark is bounded by the real per-chunk record size
428        // (a small multiple of `chunk_length`, e.g. 16 KiB), never the file size or
429        // the i32::MAX bound. Reserving to it once means the per-chunk
430        // `clear()`+`resize` never regrows in steady state — preserving the
431        // ≤1-alloc/chunk property the `issue_1940_scan_window_substrate_allocs`
432        // guard measures (the read path's per-chunk `try_reserve_exact` remains a
433        // bounds-checked safety net that records a regrowth only if a chunk ever
434        // exceeds this mark). `try_reserve_exact` returns a typed error on
435        // allocation failure instead of aborting; a corrupt oversized delta surfaces
436        // as `Error::memory`, never a panic. Authoritative metadata, no heuristic.
437        let mut scratch: Vec<u8> = Vec::new();
438        if let Some(ci) = reader.compression_info.as_ref() {
439            let file_size = reader.scan_positional_source.len();
440            let max_record = (0..ci.chunk_offsets.len())
441                .filter_map(|i| ci.compressed_chunk_size(i, file_size))
442                .max()
443                .unwrap_or(0);
444            let want = usize::try_from(max_record).unwrap_or(usize::MAX);
445            if want > 0 {
446                scratch.try_reserve_exact(want).map_err(|e| {
447                    Error::memory(format!(
448                        "failed to reserve {want} bytes for the windowed compressed-read scratch \
449                         (largest actual chunk record): {e}"
450                    ))
451                })?;
452            }
453        }
454        // ONE reusable aligned bounce buffer for the WHOLE scan (issue #2319): the
455        // Direct-I/O backend reuses it across every chunk read instead of allocating
456        // a fresh ~chunk-sized aligned buffer per chunk (the #1940 regression). No-op
457        // (stays empty) for the mmap/plain-file backends.
458        let mut direct_scratch = DirectScratch::new();
459        let mut chunk_index = 0usize;
460        loop {
461            // SYNCHRONOUS positional read + CRC (issue #1940): CRC is verified inside
462            // the read, BEFORE the payload is trusted (guardrail #1411), exactly as
463            // the former cursor path did.
464            match reader.read_compressed_chunk_sync(
465                chunk_index,
466                &mut scratch,
467                &mut direct_scratch,
468            )? {
469                Some(compressed) => {
470                    // Decompression stays HERE, on this blocking thread (D2), off the
471                    // async reactor for every backend.
472                    let (decoded, recycled) =
473                        reader.decode_scan_chunk(chunk_index, max_compressed_length, compressed)?;
474                    scratch = recycled;
475                    chunk_index += 1;
476                    if raw_tx.blocking_send(decoded).is_err() {
477                        return Ok(()); // consumer/parse ended early
478                    }
479                }
480                None => return Ok(()), // EOF
481            }
482        }
483    }
484
485    /// Synchronous uncompressed-NB feed body (issue #1940): read the data section
486    /// in bounded positional pieces (each `CRC.db`-verified before it is shipped),
487    /// decode (zero-copy `Vec`→`Bytes`, no decompressor), and ship on `raw_tx`.
488    /// `Ok(())` on clean EOF or consumer-ended-early; `Err` on a read/CRC failure.
489    pub(super) fn feed_uncompressed_pieces(
490        reader: &Arc<Self>,
491        raw_tx: &mpsc::Sender<bytes::Bytes>,
492    ) -> Result<()> {
493        // ONE reusable aligned bounce buffer for the whole scan (issue #2319), same
494        // as the compressed feed; no-op for non-Direct backends.
495        let mut direct_scratch = DirectScratch::new();
496        let mut pos = reader.calculate_header_size() as u64;
497        let mut chunk_index = 0usize;
498        loop {
499            match reader.read_uncompressed_piece_sync(pos, &mut direct_scratch)? {
500                Some((piece, next_pos)) => {
501                    // No compressor: `decode_scan_chunk` moves the piece into the B1
502                    // cache zero-copy (`Bytes::from(Vec)`) — no per-piece copy — and
503                    // returns the refcounted substrate the window borrows.
504                    let (decoded, _recycled) =
505                        reader.decode_scan_chunk(chunk_index, usize::MAX, piece)?;
506                    pos = next_pos;
507                    chunk_index += 1;
508                    if raw_tx.blocking_send(decoded).is_err() {
509                        return Ok(()); // consumer/parse ended early
510                    }
511                }
512                None => return Ok(()), // EOF
513            }
514        }
515    }
