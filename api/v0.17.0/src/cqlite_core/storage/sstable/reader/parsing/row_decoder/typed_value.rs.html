1//! Decode a bounded byte slice whose type is a **declared `CqlType`** (issue #3631),
2//! and own the ONE implementation of the bounded-decode exhaustion rule.
3//!
4//! ## Why this module exists
5//!
6//! Two decode paths used to match a CLOSED SET of primitive types and fall back to
7//! `Value::Blob` for everything else, while the schema naming the real type was in
8//! hand and unread:
9//!
10//! * `parse_simple_udt_field_value` (`udt.rs`) — a COLLECTION-typed field of a
11//!   frozen UDT (`frozen<map<text,int>>`, `frozen<list<…>>`, `frozen<set<…>>`)
12//!   surfaced to callers as bytes. Instance B of #3631.
13//! * `parse_cell_path_key` (`cell_path_key.rs`) — a non-frozen map's cell-path key.
14//!   Instance A, fixed THERE by #3612 / PR #3736, not here.
15//!
16//! Issue #28 (no-heuristics) forbids that silent degradation: authoritative
17//! metadata only, and where the metadata is present it must be USED. A
18//! `tracing::debug!` is not a diagnostic a caller can see, so a type this decoder
19//! genuinely cannot express is an explicit `Error` naming it.
20//!
21//! ## Format authority (never CQLite's own prior output)
22//!
23//! Every structured shape below is the **frozen / "multi-cell-free"** serialization
24//! Cassandra writes for a value nested inside another value, read at the pinned tag:
25//!
26//! * Collections — `cassandra-5.0.8:src/java/org/apache/cassandra/serializers/CollectionSerializer.java`.
27//!   `writeCollectionSize` is `output.putInt(elements)` (a 4-byte BE i32 count, NOT a
28//!   vint), and `writeValue` writes `putInt(size)` then the bytes, with `putInt(-1)`
29//!   for a null element; `readValue` treats any negative size as null. A `list`/`set`
30//!   is `[i32 count]` then that many values; a `map` is `[i32 count]` then that many
31//!   KEY, VALUE pairs, each independently length-prefixed.
32//! * Tuples — `cassandra-5.0.8:src/java/org/apache/cassandra/db/marshal/TupleType.java`
33//!   (`buildValue` / `split`): each component is `[i32 size][bytes]`, `-1` for null,
34//!   and a tuple may be written with FEWER components than the type declares
35//!   (trailing components are then absent, i.e. null).
36//! * UDTs — `cassandra-5.0.8:src/java/org/apache/cassandra/db/marshal/UserType.java`,
37//!   which extends `TupleType`: identical per-field `[i32 size][bytes]` framing. That
38//!   is already implemented by `parse_nested_udt_from_registry` /
39//!   `parse_inline_udt_value`, which this module delegates to so there is ONE UDT
40//!   field-framing implementation.
41//!
42//! Cross-checked against the committed Cassandra-5.0.2-written fixture
43//! `test-data/fixtures/issue_3504/` and its `sstabledump` golden, where
44//! `udt_hashable_shapes` row 3's `stn` renders the nested `frozen<map<text,int>>`
45//! field as `{"a": 1}` from the on-disk bytes
46//! `00000001 00000001 61 00000004 00000001`.

62impl V5CompressedLegacyParser {
63    /// Assert a bounded decode consumed its entire slice.
64    ///
65    /// # THE one implementation of this rule (issues #3811 + #3820/#3631)
66    /// #3811 landed `require_fully_consumed_raw` beside the type-STRING decoder and
67    /// recorded, in its own doc comment, that #3820 was adding a second copy over
68    /// `&CqlType` and that *"there must be ONE implementation of this rule, not two"*.
69    /// This is that one implementation: `require_fully_consumed_raw` is GONE and all of
70    /// its call sites — `raw_value.rs`'s bounded wrapper, `cell_value_complex.rs`'s two
71    /// frozen-UDT columns, `udt.rs`'s nested-UDT arms and `udt/inline.rs` — name this
72    /// function, with the SAME arguments and the SAME message. The type-string and
73    /// `CqlType` sides therefore share one error class, which is what the #3811 note
74    /// asked for: a caller matching on the message must not have to know which layer
75    /// refused.
76    ///
77    /// `consumed` is what the decoder reports it read; `len` is the exact extent the
78    /// caller handed it. Anything short is `cassandra-5.0.8` `TupleType.split` rule 2
79    /// or rule 4 — a partial component-length prefix, or trailing bytes after the last
80    /// declared component — and Cassandra throws `MarshalException` for both. A
81    /// genuinely SHORT encoding (rule 1, omitted trailing components) leaves
82    /// `consumed == len` and stays ACCEPTED.
83    ///
84    /// Discarding the leftover bytes silently is the framing-error-MASKING class that
85    /// let #3002's `Rows.db` root-base defect hide behind a compensating encoder
86    /// defect: two errors that cancel are undetectable unless something insists the
87    /// accounting balances.
88    ///
89    /// `subject` names the thing being decoded (a column, a field, a nested type) and
90    /// `type_desc` its declared type, both for the message only.
91    pub(in crate::storage::sstable::reader::parsing::row_decoder) fn require_fully_consumed(
92        consumed: usize,
93        len: usize,
94        subject: &str,
95        type_desc: &str,
96    ) -> Result<()> {
97        if consumed == len {
98            return Ok(());
99        }
100        if consumed < len {
101            // Wording deliberately SHARED with `cell_path_key.rs`'s consumption
102            // refusal ("decoded only N of M byte(s)"): it is the same rule, and a
103            // caller matching on the message must not have to know which of the
104            // layers refused.
105            return Err(Error::corruption(format!(
106                "Bounded value '{}' of type '{}' decoded only {} of {} byte(s); the whole \
107             slice must be the value (trailing bytes, or a partial trailing component \
108             header, are corruption — Cassandra TupleType.split rules 2 and 4)",
109                subject, type_desc, consumed, len
110            )));
111        }
112        Err(Error::corruption(format!(
113        "Bounded value '{}' (type '{}'): decoder reported {} bytes consumed but only {} were available",
114        subject, type_desc, consumed, len
115    )))
116    }
117}

123impl V5CompressedLegacyParser {
124    /// Parse a UDT field value from its declared `CqlType`, carrying an explicit
125    /// nesting `depth`.
126    ///
127    /// # THE one per-field entry point for every UDT field loop (issue #3631)
128    /// All the field loops route here — `udt.rs`'s `parse_udt_value`, its
129    /// registry-resolved decoder and `udt/inline.rs`'s inline decoder, plus
130    /// `raw_type_value.rs`'s two marshal-string loops. Each used to carry its own
131    /// ~100-line dispatch over the field's `CqlType`, and three consecutive review
132    /// rounds on this issue each found one more of those copies with one of the same
133    /// three defects (a reset nesting counter, a discarded consumed-byte count, a
134    /// `Value::Blob` fallback for an unresolved UDT name). One implementation is what
135    /// makes the three properties hold BY CONSTRUCTION instead of per call site.
136    ///
137    /// # There is deliberately NO zero-depth wrapper
138    /// A `depth = 0` overload is the thing a caller inside a decode picks by accident,
139    /// and that is precisely how the counter came to be reset at every frozen hop. An
140    /// entry point genuinely at the root — a test, or a column-level decode — writes the
141    /// `0` at the call site, where a reviewer can see it.
142    ///
143    /// # ONE decoder for the whole field type (issue #4070)
144    /// This function used to keep its OWN arms for `Text`/`Ascii`, `Int`, `BigInt`,
145    /// `Boolean`, `Float`, `Double`, `Uuid`/`TimeUuid`, `Timestamp` and `Blob`, so one
146    /// scalar set had two decoders and a type fix had to land in both or the paths
147    /// silently diverged. #4070 DELETED them: the whole field type — scalar, collection,
148    /// tuple and nested UDT alike — now routes through [`Self::parse_typed_value`].
149    ///
150    /// The deletion is OBSERVATIONALLY NEUTRAL on the decoded `Value`, which is why it
151    /// was allowed to be a deletion rather than a behaviour change: each removed arm was
152    /// diffed against its `parse_typed_value` counterpart and agreed on the returned
153    /// variant, the admissible width, borrow-vs-allocate (`Text` and `Blob` both reach
154    /// `value_borrow::borrow_active` on either side), `Boolean` truthiness (`!= 0`),
155    /// `Timestamp` units (millis), the `Uuid`/`TimeUuid` collapse (there is no
156    /// `Value::TimeUuid`) and `Blob` framing (the whole slice, never VInt-framed). The
157    /// only differences were the REFUSAL MESSAGE strings, which are now the declared-width
158    /// wording from the one width gate.
159    ///
160    /// In particular the float SPELLING is unchanged: a `float` field is `Value::Float32`
161    /// on both sides — the widening the old comment here described was removed during
162    /// #3811's review (`b2132fb2c`) and this comment outlived it. `Value::Float32` is the
163    /// spelling format authority requires; it is pinned by
164    /// `a_float_udt_field_decodes_to_float32_not_a_widened_double` in
165    /// `regression_3631_typed_value_tests.rs`, which carries the citation.
166    ///
167    /// What #3631 replaced, and what must never come back, is the trailing `_ =>` arm
168    /// that handed back `Value::Blob` for EVERY remaining type — including a
169    /// `frozen<map<text,int>>` field whose declared type was in hand and unread. That
170    /// silent degradation is what #28 forbids, it made a value HASHABLE in the Python
171    /// binding that should not have been (#3500), and the delegate's own boundary is an
172    /// explicit `Error` naming the type instead (#3722 closed the last copies of it).
173    ///
174    /// Depth is checked on entry and threaded outward: a field reached from INSIDE a
175    /// collection, tuple or another UDT must not restart the counter, because the UDT
176    /// decoders recurse back through here — so a reset at any UDT boundary makes
177    /// `MAX_TYPE_NESTING_DEPTH` bound nothing across alternating collection/UDT layers,
178    /// and a cyclic `UdtRegistry` (which the registry type permits even though CQL does
179    /// not) then recurses until the stack is exhausted.
180    pub(in crate::storage::sstable::reader::parsing::row_decoder) fn parse_simple_udt_field_value_at(
181        &self,
182        data: &[u8],
183        field_type: &CqlType,
184        depth: usize,
185    ) -> Result<Value> {
186        if depth > MAX_TYPE_NESTING_DEPTH {
187            return Err(Error::corruption(format!(
188                "UDT field: type nesting depth {depth} exceeds maximum {MAX_TYPE_NESTING_DEPTH}"
189            )));
190        }
191        // An EMPTY field (`[i32 0]`, i.e. `ByteBufferUtil.EMPTY_BYTE_BUFFER`) is decided
192        // by ONE rule, in the typed decoder — see `empty_is_a_value`, which carries the
193        // pinned-tag citations: NULL for every scalar whose Cassandra serializer guards
194        // `accessor.isEmpty(value) ? null : …`, and the empty string / empty blob /
195        // empty collection for the types where emptiness IS the value.
196        //
197        // Until #4070 that rule needed an explicit `if data.is_empty()` REDIRECT here,
198        // because the scalar arms this function used to carry each demanded their exact
199        // width and so ERRORED on an empty `int` that Cassandra reads as null. With the
200        // arms gone the redirect and the fall-through became the same call with the same
201        // arguments, so it is folded in rather than written twice; the empty rule is
202        // unchanged and still lives in exactly one place.
203        self.parse_typed_value(data, field_type, "UDT field", depth)
204    }

206    /// Read the `[i32 BE]` at `pos`, bounds-checked.
207    fn read_i32_at(data: &[u8], pos: usize, ctx: &str, what: &str) -> Result<i32> {
208        let end = pos.checked_add(I32_LEN).ok_or_else(|| {
209            Error::corruption(format!("{ctx}: offset overflow reading {what} length"))
210        })?;
211        if end > data.len() {
212            return Err(Error::corruption(format!(
213                "{ctx}: need {I32_LEN} bytes for the {what} length at offset {pos}, only {} available",
214                data.len().saturating_sub(pos)
215            )));
216        }
217        Ok(i32::from_be_bytes([
218            data[pos],
219            data[pos + 1],
220            data[pos + 2],
221            data[pos + 3],
222        ]))
223    }
224
225    /// Read one `[i32 size][bytes]` element starting at `*pos`, advancing `*pos`.
226    ///
227    /// `Ok(None)` is a NULL element: `CollectionSerializer.readValue` returns null
228    /// for any negative size, and `TupleType.split` does the same.
229    fn read_sized_element<'d>(
230        data: &'d [u8],
231        pos: &mut usize,
232        ctx: &str,
233        what: &str,
234    ) -> Result<Option<&'d [u8]>> {
235        let size = Self::read_i32_at(data, *pos, ctx, what)?;
236        *pos += I32_LEN;
237        if size < 0 {
238            return Ok(None);
239        }
240        let size = size as usize;
241        let end = pos.checked_add(size).ok_or_else(|| {
242            Error::corruption(format!("{ctx}: offset overflow reading {what} body"))
243        })?;
244        if end > data.len() {
245            return Err(Error::corruption(format!(
246                "{ctx}: {what} declares {size} bytes at offset {pos} but only {} remain",
247                data.len().saturating_sub(*pos)
248            )));
249        }
250        let body = &data[*pos..end];
251        *pos = end;
252        Ok(Some(body))
253    }

255    /// Read the leading `[i32 BE]` element count of a frozen collection, rejecting a
256    /// negative count and one beyond `MAX_FROZEN_COLLECTION_SIZE`.
257    ///
258    /// A ZERO-LENGTH `data` is the empty collection, not corruption: a UDT field
259    /// written with `[i32 size] == 0` carries `ByteBufferUtil.EMPTY_BYTE_BUFFER`, and
260    /// this decoder's callers pass `&[]` for exactly that case.
261    ///
262    /// This is the one reading here NOT taken from Cassandra's own serializer, and it is
263    /// stated rather than dressed up: `CollectionType` does NOT override
264    /// `AbstractType.isEmptyValueMeaningless`, so Cassandra would `compose` an empty
265    /// buffer, and `MapSerializer.deserialize` underflows on one — i.e. Cassandra never
266    /// WRITES a zero-length frozen collection (an empty one is the 4 bytes `[i32 0]`).
267    /// CQLite has always read it as the empty collection, and that behaviour is
268    /// PRESERVED deliberately: it is lenient, it is not a blob, and tightening it is not
269    /// this issue's subject (#3631 criterion 5 is about silent degradation to
270    /// `Value::Blob`).
271    fn read_collection_count(data: &[u8], ctx: &str) -> Result<(usize, usize)> {
272        if data.is_empty() {
273            // No header to consume either, so the cursor starts (and ends) at 0.
274            return Ok((0, 0));
275        }
276        let count = Self::read_i32_at(data, 0, ctx, "collection element count")?;
277        if count < 0 {
278            return Err(Error::corruption(format!(
279                "{ctx}: negative frozen collection element count {count}"
280            )));
281        }
282        let count = count as u64;
283        if count > MAX_FROZEN_COLLECTION_SIZE {
284            return Err(Error::corruption(format!(
285                "{ctx}: frozen collection element count {count} exceeds the {MAX_FROZEN_COLLECTION_SIZE} safety limit"
286            )));
287        }
288        Ok((count as usize, I32_LEN))
289    }

291    /// Capacity to reserve for a declared element `count`, capped by what `data`
292    /// could possibly hold.
293    ///
294    /// `count` is attacker-controlled (it is read out of the value being decoded), so
295    /// reserving it directly lets a 4-byte corrupt header ask for the full
296    /// `MAX_FROZEN_COLLECTION_SIZE` allocation. Every item costs at least its own
297    /// `[i32 size]` prefix, so `data.len() / min_bytes_per_item` is a hard upper
298    /// bound on how many can actually be present; a genuine collection reserves
299    /// exactly, and a lying header reserves what its own bytes justify.
300    fn bounded_capacity(count: usize, data_len: usize, min_bytes_per_item: usize) -> usize {
301        count.min(data_len / min_bytes_per_item)
302    }

304    /// Decode `data` — the COMPLETE value, with no outer length prefix — as the
305    /// declared `ty`, requiring EVERY byte to be accounted for.
306    ///
307    /// This is the `CqlType`-driven sibling of `parse_value_from_raw_bytes` (which is
308    /// driven by a marshal / CQL type STRING). It never degrades to `Value::Blob` for
309    /// a non-`blob` declared type: a type it cannot express is an explicit `Error`.
310    ///
311    /// # Consumption is part of the decode SIGNATURE, not a per-arm checklist
312    /// Every caller — and every future caller — inherits the exhaustion rule, because
313    /// the only way to decode a `CqlType` here is through this function, and the only
314    /// way to get a value WITHOUT the assert is to ask
315    /// [`Self::parse_typed_value_reporting`] for the consumed length and take
316    /// responsibility for it explicitly. Review round 1 of this issue added the check
317    /// to the collection arms, round 2 found the UDT arms still bypassing it; a per-arm
318    /// checklist does not close.
319    pub(in crate::storage::sstable::reader::parsing::row_decoder) fn parse_typed_value(
320        &self,
321        data: &[u8],
322        ty: &CqlType,
323        ctx: &str,
324        depth: usize,
325    ) -> Result<Value> {
326        let (value, consumed) = self.parse_typed_value_reporting(data, ty, ctx, depth)?;
327        Self::require_fully_consumed(consumed, data.len(), ctx, Self::typed_value_label(ty))?;
328        Ok(value)
329    }

331    /// [`Self::parse_typed_value`] WITHOUT the exhaustion assert, reporting how many
332    /// bytes of `data` the decode actually consumed.
333    ///
334    /// `Ok((value, consumed))` where `consumed <= data.len()`. Only two kinds of
335    /// caller may use this instead of the asserting entry point above: the arms
336    /// BELOW, which thread the count outward, and a caller that has a
337    /// Cassandra-derived reason for a short read — of which there is exactly one, a
338    /// UDT/tuple whose trailing components are omitted, and even there
339    /// `TupleType.split` requires the decode to have ended exactly at the end of the
340    /// buffer, which is what the assert in the wrapper checks.
341    fn parse_typed_value_reporting(
342        &self,
343        data: &[u8],
344        ty: &CqlType,
345        ctx: &str,
346        depth: usize,
347    ) -> Result<(Value, usize)> {
348        if depth > MAX_TYPE_NESTING_DEPTH {
349            return Err(Error::corruption(format!(
350                "{ctx}: type nesting depth {depth} exceeds maximum {MAX_TYPE_NESTING_DEPTH}"
351            )));
352        }
353        match ty {
354            // ── Structured shapes (the #3631 subject) ───────────────────────────
355            CqlType::Frozen(inner) => {
356                // `frozen<X>` is serialized EXACTLY as `X` in a nested position; the
357                // wrapper is a type-system marker. Mirrors the `Frozen` arms in
358                // `parse_nested_udt_from_registry` and `parse_value_from_raw_bytes`,
359                // which also surface `Value::Frozen`.
360                //
361                // It consumes NO nesting level, and that is load-bearing rather than
362                // tidy. The limit must count FRAMING layers — the things that make the
363                // decoder recurse over bytes — and `frozen` adds none. Counting it
364                // charged the canonical spellings in this repo's own corpus up to five
365                // levels per logical layer (`frozen<set<frozen<tuple<frozen<udt>,int>>>>`
366                // is the fixture's `stn`), which put real Cassandra-written data within
367                // one level of a FALSE REFUSAL. Termination does not depend on it: every
368                // recursion through a UDT boundary or a collection element still
369                // increments, so any cycle is strictly increasing and bounded.
370                let (inner_value, consumed) =
371                    self.parse_typed_value_reporting(data, inner, ctx, depth)?;
372                Ok((Value::Frozen(Box::new(inner_value)), consumed))
373            }
374            CqlType::List(element) => {
375                let (elements, consumed) =
376                    self.parse_typed_collection_elements(data, element, ctx, depth)?;
377                Ok((Value::List(elements), consumed))
378            }
379            CqlType::Set(element) => {
380                let (elements, consumed) =
381                    self.parse_typed_collection_elements(data, element, ctx, depth)?;
382                Ok((Value::Set(elements), consumed))
383            }
384            CqlType::Map(key_type, value_type) => {
385                let (count, header) = Self::read_collection_count(data, ctx)?;
386                // A map ENTRY costs two `[i32 size]` prefixes, so 8 bytes minimum.
387                let mut entries = Vec::with_capacity(Self::bounded_capacity(count, data.len(), 8));
388                let mut pos = header;
389                for i in 0..count {
390                    let key_ctx = format!("{ctx}: map entry {i} key");
391                    let key = match Self::read_sized_element(data, &mut pos, &key_ctx, "map key")? {
392                        // `MapSerializer` writes a key with `writeValue`, so a
393                        // negative length is representable — but a null key is not a
394                        // legal Cassandra map entry, so it is corruption, not a Null.
395                        None => {
396                            return Err(Error::corruption(format!(
397                                "{key_ctx}: null map key (negative length) is not a legal map entry"
398                            )))
399                        }
400                        Some(bytes) => {
401                            self.parse_typed_value(bytes, key_type, &key_ctx, depth + 1)?
402                        }
403                    };
404                    let value_ctx = format!("{ctx}: map entry {i} value");
405                    let value =
406                        match Self::read_sized_element(data, &mut pos, &value_ctx, "map value")? {
407                            // A negative length is REPRESENTABLE and is corruption, not a
408                            // `Null` — the same rule as the key above, and it used to
409                            // differ. Verified first-hand at the pinned tag:
410                            // `cassandra-5.0.8:src/java/org/apache/cassandra/serializers/MapSerializer.java`
411                            // `deserialize` reads BOTH halves of every entry with
412                            // `readNonNullValue`, and
413                            // `CollectionSerializer.readNonNullValue` throws
414                            // `MarshalException("Null value read when not allowed")` when
415                            // `readValue` returned null, which it does for any `size < 0`.
416                            // So Cassandra itself refuses this byte pattern; surfacing it
417                            // as `Value::Null` invented a value no writer can produce.
418                            None => {
419                                return Err(Error::corruption(format!(
420                                    "{value_ctx}: null map value (negative length) is not a \
421                                     legal map entry — Cassandra's MapSerializer reads \
422                                     entry values with readNonNullValue"
423                                )))
424                            }
425                            Some(bytes) => {
426                                self.parse_typed_value(bytes, value_type, &value_ctx, depth + 1)?
427                            }
428                        };
429                    entries.push((key, value));
430                }
431                Ok((Value::Map(entries), pos))
432            }
433            CqlType::Tuple(element_types) => {
434                if element_types.is_empty() {
435                    return Err(Error::schema(format!(
436                        "{ctx}: tuple type declares no components"
437                    )));
438                }
439                let mut elements = Vec::with_capacity(element_types.len());
440                let mut pos = 0usize;
441                for (i, element_type) in element_types.iter().enumerate() {
442                    // `TupleType.split` stops at the end of the buffer: a tuple may
443                    // be written with fewer components than declared, and the
444                    // trailing components are then absent (null).
445                    if pos >= data.len() {
446                        elements.push(Value::Null);
447                        continue;
448                    }
449                    let element_ctx = format!("{ctx}: tuple component {i}");
450                    elements.push(
451                        match Self::read_sized_element(
452                            data,
453                            &mut pos,
454                            &element_ctx,
455                            "tuple component",
456                        )? {
457                            None => Value::Null,
458                            Some(bytes) => self.parse_typed_value(
459                                bytes,
460                                element_type,
461                                &element_ctx,
462                                depth + 1,
463                            )?,
464                        },
465                    );
466                }
467                // A tuple written with FEWER components than declared is legal —
468                // `TupleType.split` returns early on `position == length` and the loop
469                // above null-pads — but bytes left after the LAST declared component
470                // are trailing garbage (`if (position < length) throw`), which the
471                // caller's one exhaustion assert refuses.
472                Ok((Value::Tuple(elements), pos))
473            }
474            // A UDT nested inside a collection / tuple / another UDT. Delegated so
475            // the per-field `[i32 size][bytes]` framing has ONE implementation.
476            //
477            // `Custom` carries a UDT NAME *or* a marshal type reference the type-string
478            // parser had no `CqlType` for (`EmptyType`, `VectorType(...)`, a
479            // third-party `AbstractType`), so only the former may be routed here:
480            // an unroutable marshal name falls through to the `scalar` arm below and is
481            // refused as an undecodable DECLARED TYPE, which is what it is. Routing it
482            // here reported "nested user-defined type … field list is not available",
483            // misattributing the cause (roborev job 68, finding 1).
484            CqlType::Custom(name) if !Self::custom_is_marshal_type_reference(name) => {
485                self.parse_typed_udt(data, name, &[], ctx, depth)
486            }
487            CqlType::Udt(name, inline_fields) => {
488                self.parse_typed_udt(data, name, inline_fields, ctx, depth)
489            }
490
491            // `vector<float, n>` (issue #4114). NOT a collection: there is no
492            // element count and no per-element `[i32 size]` framing — the value is
493            // exactly `4 * n` raw big-endian binary32 bytes
494            // (`VectorType.java:94-101`, `:445-460`). So it must NOT reuse
495            // `parse_typed_collection_elements`, and the whole framed buffer IS the
496            // value. Routed to the one framing rule in `super::vector_value`.
497            //
498            // An element type CQLite does not implement is refused there BY NAME
499            // (AC4): a vector's layout is decided entirely by its element type, so
500            // a fallback decode could only be a guess (#28).
501            CqlType::Vector(element, dimension) => {
502                crate::schema::vector_type::vector_value::require_float_element(
503                    element, *dimension,
504                )?;
505                crate::schema::vector_type::vector_value::decode_float_vector_exact(
506                    data, ctx, *dimension,
507                )
508            }
509
510            // ── Scalars ─────────────────────────────────────────────────────────
511            // Delegated to the type-STRING decoder by naming the declared type: one
512            // closed `CqlType` -> canonical CQL short form mapping, no guessing, and
513            // one implementation of each scalar's byte layout.
514            scalar => {
515                let short = Self::cql_scalar_short_form(scalar).ok_or_else(|| {
516                    // The no-silent-blob boundary (#3631 acceptance criterion 5).
517                    Error::unsupported_format(format!(
518                        "{ctx}: cannot decode declared type {scalar:?} — CQLite has no \
519                         decoding rule for it, and returning the raw bytes as a blob \
520                         would silently discard the declared type (issue #3631 / #28)"
521                    ))
522                })?;
523                // An EMPTY buffer is NULL for every scalar whose Cassandra serializer
524                // guards `accessor.isEmpty(value) ? null : …` — see
525                // `Self::empty_is_a_value` for the per-serializer reading. The old
526                // `create_empty_value_for_type` handed back an empty BLOB here.
527                if data.is_empty() && !Self::empty_is_a_value(short) {
528                    return Ok((Value::Null, 0));
529                }
530                // A width the declared type does not admit is refused rather than
531                // truncated: the delegate bounds-checks with `<`, so it would read the
532                // first legal width out of a longer frame and drop the tail — and for
533                // `inet`, whose width is a SET of two, it borrows the whole malformed
534                // slice and calls it an address (roborev job 68, finding 2).
535                let widths = Self::scalar_allowed_widths(short);
536                if !widths.is_empty() && !widths.contains(&data.len()) {
537                    let detail = match widths.iter().filter(|w| **w <= data.len()).max() {
538                        Some(w) => format!(
539                            "accepting it would silently discard {} trailing byte(s)",
540                            data.len() - w
541                        ),
542                        None => "it is shorter than any legal width".to_string(),
543                    };
544                    return Err(Error::corruption(format!(
545                        "{ctx}: declared type '{short}' is {} bytes wide (or empty, \
546                         meaning null) but the framed value is {} bytes; {detail} \
547                         (issue #3631)",
548                        Self::render_allowed_widths(widths),
549                        data.len(),
550                    )));
551                }
552                // The delegate is the ASSERTING short name, so on `Ok` it has ALREADY
553                // required `consumed == data.len()` (#3811). That is what makes
554                // reporting `data.len()` here a VERIFIED claim rather than an assumed
555                // one — including for `duration`, the one scalar whose decode can stop
556                // short, whose arm reports where its third VInt actually ended. #3631's
557                // predecessor re-walked those VInts here; that walk is folded out for
558                // the same reason `cell_path_key.rs`'s was.
559                let value = self.parse_value_from_raw_bytes(data, short, ctx, depth)?;
560                Ok((value, data.len()))
561            }
562        }
563    }
564
565    /// The `[i32 count]` + `[i32 size][bytes]`× body shared by `list` and `set`,
566    /// reporting the offset it reached so the caller's one exhaustion assert can see
567    /// a zero-count header with a payload behind it.
568    fn parse_typed_collection_elements(
569        &self,
570        data: &[u8],
571        element_type: &CqlType,
572        ctx: &str,
573        depth: usize,
574    ) -> Result<(Vec<Value>, usize)> {
575        let (count, header) = Self::read_collection_count(data, ctx)?;
576        // One element costs at least its own `[i32 size]` prefix, so 4 bytes.
577        let mut elements = Vec::with_capacity(Self::bounded_capacity(count, data.len(), I32_LEN));
578        let mut pos = header;
579        for i in 0..count {
580            let element_ctx = format!("{ctx}: element {i}");
581            elements.push(
582                match Self::read_sized_element(data, &mut pos, &element_ctx, "element")? {
583                    // Cassandra rejects null collection elements on write
584                    // (`CollectionSerializer.readNonNullValue` throws), so a negative
585                    // length here is corruption rather than a Null element.
586                    None => {
587                        return Err(Error::corruption(format!(
588                            "{element_ctx}: null collection element (negative length) is not legal"
589                        )))
590                    }
591                    Some(bytes) => {
592                        self.parse_typed_value(bytes, element_type, &element_ctx, depth + 1)?
593                    }
594                },
595            );
596        }
597        Ok((elements, pos))
598    }

600    /// Decode a nested UDT named by the declared type, preferring the authoritative
601    /// `UdtRegistry` and falling back to the inline field list carried by
602    /// `CqlType::Udt` (issue #239). An unresolvable name is an explicit `Error`: the
603    /// bytes cannot be interpreted without a field list, and handing back a blob
604    /// would discard the declared type name (#3631 criterion 5).
605    ///
606    /// # Why the reported consumption is `data.len()`, VERIFIED not assumed
607    /// A UDT's field loop STOPS as soon as fewer than four bytes remain, treating the
608    /// undeclared remainder as omitted trailing fields — so a bare `Value` return would
609    /// hide both trailing garbage AND an incomplete 1-3 byte field-length prefix. Since
610    /// #3811 both delegates below END with `Self::require_fully_consumed(current_offset,
611    /// data.len(), …)`, so an `Ok` from either is a PROOF that the loop reached
612    /// `data.len()`.
613    /// `cassandra-5.0.8:src/java/org/apache/cassandra/db/marshal/TupleType.java`
614    /// `split` (which `UserType extends TupleType` inherits and calls) is explicit
615    /// about all three cases: `if (position == length) return Arrays.copyOfRange(...)`
616    /// — omitted trailing components are legal ONLY when the decode ended exactly at
617    /// the end of the buffer; `if (position + 4 > length) throw new
618    /// MarshalException("Not enough bytes to read %dth component")` — a partial length
619    /// prefix is corruption; and, after the loop, `if (position < length) throw ...
620    /// "but got more"` — trailing bytes are corruption.
621    fn parse_typed_udt(
622        &self,
623        data: &[u8],
624        name: &str,
625        inline_fields: &[(String, CqlType)],
626        ctx: &str,
627        depth: usize,
628    ) -> Result<(Value, usize)> {
629        // Crossing a UDT boundary CONSUMES a level: both decoders below recurse back
630        // into `parse_simple_udt_field_value_at`, so passing `depth + 1` (never `0`
631        // or `1`) is what makes ONE limit hold across alternating collection/UDT
632        // nesting. Each decoder re-checks the limit on entry, so an over-deep value is
633        // refused at the boundary that exceeded it.
634        if let Some(registry) = self.udt_registry.as_ref() {
635            // `get_udt_qualified` owns "udt:" + keyspace-qualifier normalization
636            // (issues #239 / #2807).
637            if let Some(def) = registry.get_udt_qualified(&self.keyspace, name) {
638                let value = self.parse_nested_udt_from_registry(data, def, depth + 1)?;
639                return Ok((value, data.len()));
640            }
641        }
642        if !inline_fields.is_empty() {
643            let value = self.parse_inline_udt_value(data, name, inline_fields, depth + 1)?;
644            return Ok((value, data.len()));
645        }
646        Err(Error::unsupported_format(format!(
647            "{ctx}: nested user-defined type '{name}' is declared but its field list is \
648             not available (absent from the UDT registry and carrying no inline \
649             fields), so its bytes cannot be decoded; returning them as a blob would \
650             silently discard the declared type (issue #3631 / #28)"
651        )))
652    }
