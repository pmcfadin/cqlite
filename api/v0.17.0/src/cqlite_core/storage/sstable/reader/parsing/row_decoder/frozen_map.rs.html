1//! FROZEN MAP decoding, and the MAP-KEY NEVER-NULL rule (#3847) — split out of
2//! `frozen.rs` under the campsite rule (#1116).
3//!
4//! `frozen.rs` was 133 lines OVER the 800-line source threshold before #3847 went
5//! near it, so the ratchet forbade ANY growth and two call sites cannot be zero
6//! lines. Rather than acknowledge that with `CQLITE_ALLOW_FILE_GROWTH=1`, the map
7//! decoders move here with the rule they now enforce: this module owns frozen MAP
8//! decoding (`parse_frozen_map_value`, `parse_frozen_map_value_raw`) and the
9//! never-null key invariant, and `frozen.rs` keeps list/set/tuple. That takes
10//! `frozen.rs` under its threshold for the first time.
11//!
12//! # Why this module exists at all
13//!
14//! #3847 widened the shared fixed-width decoder so an EMPTY buffer answers
15//! `Value::Null` — Cassandra's `deserialize()` maps an empty buffer to null, and
16//! `parse_value_from_raw_bytes` now honours that. A VALUE may be null. A MAP KEY
17//! MAY NOT: Cassandra has no way to express one, and #3747 already established the
18//! answer for an empty/untypeable map key — PRESERVE IT OPAQUELY (empty blob, plus
19//! a signal to the caller) rather than drop the entry or hand back an invalid key.
20//!
21//! # The lesson this module is the monument to
22//!
23//! **Widening what a shared decoder ACCEPTS changes every caller that branched on
24//! its REJECTION.** That single cause produced FOUR defects on #3847, each found
25//! one caller further out:
26//!
27//! 1. the gate of record's `core-tests` red — the cell-path key's opaque policy sat
28//!    on the decoder's `Err` arm and stopped firing once the decode SUCCEEDED;
29//! 2. roborev job 152 — a frozen-spelled key decodes to `Frozen(<inner>)`, so a
30//!    test against the RAW value fell through it;
31//! 3. roborev job 153 — BOTH frozen-map key paths (`read_frozen_element`, used by
32//!    `parse_frozen_map_value`, AND `parse_frozen_map_value_raw`) could yield a
33//!    null key, and only the second was reported;
34//! 4. and the reason it took four rounds: each fix addressed the SITE in front of
35//!    it rather than the CLASS.
36//!
37//! # Three properties that stop a fifth site appearing
38//!
39//! * ONE rule, called from BOTH frozen key paths — not the same patch twice.
40//! * STATED OVER THE VALUE, NOT A BYTE LENGTH. `Null` is not a legal key however it
41//!   arose, so the rule takes no length argument and therefore CANNOT miss a caller
42//!   that has not got one. `read_frozen_element` is exactly such a caller.
43//! * IT REUSES THE ONE PEEL HELPER (`peeled_for_inspection`, widened to
44//!   `pub(in ...row_decoder)`) rather than adding a second. That helper LOOPS, so
45//!   a legally re-frozen inner (`frozen<frozen<list<int>>>`, which
46//!   `RawCollection::freeze` permits) is covered. A second peel implementation
47//!   would be a second place for the `Frozen(Null)` case to regress independently.
48//!
49//! # THE PEEL IS A VALUE-SIDE PEEL, AND IT IS NOT WHAT #4104 REMOVED
50//!
51//! An earlier revision of this header justified the peel with "`frozen<int>`
52//! decodes to `Frozen(Null)`". That spelling is now REFUSED at both metadata entry
53//! points (`schema::frozen_scalar`; `CQL3Type.Raw::freeze()` throws —
54//! `cassandra-5.0.8:src/java/org/apache/cassandra/cql3/CQL3Type.java:647-651`), so
55//! it can no longer be the reason. The peel stays because it is stated over the
56//! VALUE and the LEGAL frozen families reach it: a `frozen<absent_udt>` key comes
57//! back as `Frozen(Blob)`, and a `Frozen(..)` wrapper must not hide an invalid
58//! inner from a check keyed on the inner. What #4104 removed is the TYPE-STRING
59//! peel in `complex_column::cell_path_key`, which could only ever change an answer
60//! for a frozen scalar.

64impl V5CompressedLegacyParser {
65    /// Every member of a FROZEN SET, through [`Self::frozen_key_never_null`].
66    ///
67    /// A set member is a KEY (Cassandra stores it in the cell path), so this is the
68    /// set-shaped spelling of the same rule. It exists so the call sites in
69    /// `frozen.rs` read as ONE self-documenting line: that file sits at its 800-line
70    /// campsite threshold, and an inlined `into_iter().map(...)` costs four lines
71    /// there once rustfmt has wrapped it.
72    pub(super) fn frozen_set_members_never_null(&self, xs: Vec<Value>, desc: &str) -> Vec<Value> {
73        xs.into_iter()
74            .map(|v| self.frozen_key_never_null(v, desc))
75            .collect()
76    }
77
78    /// A KEY IS NEVER `null`, whatever produced it — MAP KEYS *and* SET MEMBERS.
79    ///
80    /// roborev job 170 widened this from map keys alone, and the reason is the
81    /// STORAGE MODEL rather than a convention: Cassandra puts a `set<T>` member in
82    /// the CELL PATH (the cell's name, with an empty value), exactly as it puts a
83    /// map key there — so a set member IS a key and `Set([Null])` is as
84    /// unexpressible as a null map key. A `list` element, by contrast, is stored as
85    /// the cell VALUE under a UUID name, so `List([Null])` is a faithful
86    /// `deserialize()` answer and is left alone. The multicell set path already got
87    /// this for free (it decodes members through `cell_path_key`); the FROZEN set
88    /// path did not, which is the gap job 170 found.
89    ///
90    /// roborev job 153 (Medium). #3847 widened the shared fixed-width rule so an
91    /// empty buffer answers `Value::Null`, and BOTH frozen-map key paths decode
92    /// their key through that same shared decoder — `read_frozen_element` (used by
93    /// `parse_frozen_map_value`) and `parse_frozen_map_value_raw` directly — so a
94    /// zero-length fixed-width key produced a `Value::Map` with a NULL KEY, which
95    /// Cassandra has no way to express.
96    ///
97    /// ONE rule called from BOTH sites, rather than the same patch applied twice.
98    /// Job 152 was this defect at the cell-path key and was fixed there alone; the
99    /// standing lesson is that widening what a shared decoder ACCEPTS changes every
100    /// caller that branched on its REJECTION, so the whole class gets swept.
101    ///
102    /// Same answer #3747 established for an untypeable/empty map key: PRESERVE it
103    /// opaquely. An `Err` would be worse — row assembly swallows it into a silently
104    /// truncated row, the hazard `cell_path_key.rs` documents — and dropping the
105    /// entry loses a key Cassandra accepts.
106    ///
107    /// Stated over the VALUE, not over the byte length: `Null` is not a legal key
108    /// however it arose, so this needs no length argument and cannot miss a caller
109    /// that has none. It PEELS first, via the same helper the cell-path `Blob`
110    /// diagnostic uses — a `Frozen(Null)` is exactly as unexpressible as a bare
111    /// `Null`, and a legal frozen key type (collection/tuple/UDT) is precisely what
112    /// puts the wrapper there — and that helper LOOPS, so a re-frozen inner is
113    /// covered.
114    pub(super) fn frozen_key_never_null(&self, key: Value, desc: &str) -> Value {
115        if matches!(Self::peeled_for_inspection(&key), Value::Null) {
116            tracing::warn!(
117                "Frozen {}: empty fixed-width map key decoded as null; preserving it \
118                 opaquely as empty bytes (a map key cannot be null)",
119                desc
120            );
121            return Value::blob(Vec::new());
122        }
123        key
124    }
125
126    /// Parse frozen map value.
127    ///
128    /// The cell layout on disk is:
129    ///   [VUInt blob_len][i32 BE entry_count][i32 BE key_len][key_bytes][i32 BE val_len][val_bytes]...
130    pub(super) fn parse_frozen_map_value(
131        &self,
132        data: &[u8],
133        mut offset: usize,
134        key_type: &str,
135        value_type: &str,
136        column: &crate::schema::Column,
137    ) -> Result<(Value, usize)> {
138        let (count, blob_end) = Self::read_frozen_preamble(data, &mut offset, "map", &column.name)?;
139
140        tracing::debug!(
141            "V5CompressedLegacy: Frozen map '{}' with {} entries, key_type='{}', value_type='{}'",
142            column.name,
143            count,
144            key_type,
145            value_type
146        );
147
148        let mut entries = Vec::with_capacity(count);
149        for i in 0..count {
150            let key_desc = format!("map '{}' key {}", column.name, i);
151            let key_value =
152                self.read_frozen_element(data, &mut offset, blob_end, key_type, &key_desc, 0)?;
153            // A map key is never null (job 153) — ONE rule, both frozen key sites.
154            let key_value = self.frozen_key_never_null(key_value, &key_desc);
155
156            let val_desc = format!("map '{}' value {}", column.name, i);
157            let val_value =
158                self.read_frozen_element(data, &mut offset, blob_end, value_type, &val_desc, 0)?;
159
160            tracing::debug!("Frozen map entry {i}: {key_value:?} -> {val_value:?}");
161            entries.push((key_value, val_value));
162        }
163
164        Self::require_frozen_extent(offset, blob_end, "map", &column.name)?; // #3811 (F)
165        Ok((Value::Map(entries), blob_end))
166    }
167
168    /// Parse frozen map value (raw version without Column parameter).
169    pub(super) fn parse_frozen_map_value_raw(
170        &self,
171        data: &[u8],
172        mut offset: usize,
173        key_type: &str,
174        value_type: &str,
175        column_name: &str,
176        depth: usize,
177    ) -> Result<(Value, usize)> {
178        let count = Self::read_frozen_count(data, &mut offset, data.len(), "map", column_name)?;
179
180        tracing::debug!(
181            "V5CompressedLegacy: Parsing frozen map '{}' with {} entries (raw)",
182            column_name,
183            count
184        );
185
186        let mut entries = Vec::with_capacity(count);
187        for i in 0..count {
188            // Key: [i32 BE len][key bytes]
189            if offset + 4 > data.len() {
190                return Err(Error::corruption(format!(
191                    "Frozen map '{}': not enough bytes for key {} length",
192                    column_name, i
193                )));
194            }
195            let key_len_i32 = i32::from_be_bytes([
196                data[offset],
197                data[offset + 1],
198                data[offset + 2],
199                data[offset + 3],
200            ]);
201            if key_len_i32 < 0 {
202                return Err(Error::corruption(format!(
203                    "Frozen map '{}': negative key {} length {}",
204                    column_name, i, key_len_i32
205                )));
206            }
207            let key_len = key_len_i32 as usize;
208            offset += 4;
209
210            if offset + key_len > data.len() {
211                return Err(Error::corruption(format!(
212                    "Frozen map '{}': key {} needs {} bytes but only {} available",
213                    column_name,
214                    i,
215                    key_len,
216                    data.len() - offset
217                )));
218            }
219            let key_data = &data[offset..offset + key_len];
220            let key_value =
221                self.parse_value_from_raw_bytes(key_data, key_type, column_name, depth)?;
222            // A map key is never null (job 153) — ONE rule, both frozen key sites.
223            let key_desc = format!("map '{}' key {}", column_name, i);
224            let key_value = self.frozen_key_never_null(key_value, &key_desc);
225            offset += key_len;
226
227            // Value: [i32 BE len][value bytes]
228            if offset + 4 > data.len() {
229                return Err(Error::corruption(format!(
230                    "Frozen map '{}': not enough bytes for value {} length",
231                    column_name, i
232                )));
233            }
234            let val_len_i32 = i32::from_be_bytes([
235                data[offset],
236                data[offset + 1],
237                data[offset + 2],
238                data[offset + 3],
239            ]);
240            if val_len_i32 < 0 {
241                return Err(Error::corruption(format!(
242                    "Frozen map '{}': negative value {} length {}",
243                    column_name, i, val_len_i32
244                )));
245            }
246            let val_len = val_len_i32 as usize;
247            offset += 4;
248
249            if offset + val_len > data.len() {
250                return Err(Error::corruption(format!(
251                    "Frozen map '{}': value {} needs {} bytes but only {} available",
252                    column_name,
253                    i,
254                    val_len,
255                    data.len() - offset
256                )));
257            }
258            let val_data = &data[offset..offset + val_len];
259            let val_value =
260                self.parse_value_from_raw_bytes(val_data, value_type, column_name, depth)?;
261            offset += val_len;
262
263            entries.push((key_value, val_value));
264        }
265
266        Ok((Value::Map(entries), offset))
267    }
268}

277    /// A FROZEN MAP KEY can never be `null`, and #3847 made that reachable.
278    ///
279    /// roborev job 153 (Medium). #3847 widened the shared fixed-width rule so an
280    /// empty buffer answers `Value::Null`, and BOTH frozen-map key paths decode
281    /// their key through that same shared decoder — `read_frozen_element` (used by
282    /// `parse_frozen_map_value`) and `parse_frozen_map_value_raw` directly — so a
283    /// zero-length fixed-width key produced a `Value::Map` with a NULL KEY, which
284    /// Cassandra cannot express.
285    ///
286    /// Same policy as the multicell/cell-path key (#3747): PRESERVE the key opaquely
287    /// rather than drop it or return an invalid null. An `Err` here would be worse —
288    /// row assembly swallows it into a silently truncated row, the hazard
289    /// `cell_path_key.rs` documents.
290    #[test]
291    fn an_empty_fixed_width_key_in_a_frozen_map_is_never_a_null_key() {
292        let parser =
293            V5CompressedLegacyParser::new("test".to_string(), "table".to_string(), 0, 0, None);
294        // [i32 count=1][i32 key_len=0][i32 val_len=4][val=7]
295        let mut data = Vec::new();
296        data.extend_from_slice(&1i32.to_be_bytes());
297        data.extend_from_slice(&0i32.to_be_bytes());
298        data.extend_from_slice(&4i32.to_be_bytes());
299        data.extend_from_slice(&7i32.to_be_bytes());
300
301        let (value, _consumed) = parser
302            .parse_frozen_map_value_raw(&data, 0, "int", "int", "m", 0)
303            .expect("an empty key is what Cassandra accepts; keep the entry");
304        let Value::Map(entries) = &value else {
305            panic!("expected a map, got {value:?}");
306        };
307        assert_eq!(entries.len(), 1, "the entry must be kept");
308        assert_ne!(
309            entries[0].0,
310            Value::Null,
311            "a frozen map key must NEVER be null — Cassandra cannot express it"
312        );
313        assert_eq!(
314            entries[0].0,
315            Value::blob(Vec::new()),
316            "preserved opaquely, the same answer the cell-path key gives"
317        );
318    }
