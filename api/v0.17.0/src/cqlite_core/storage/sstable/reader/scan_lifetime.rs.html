1//! Reader-scoped scan-lifetime `madvise` seam (issue #3853).
2//!
3//! # What this is
4//!
5//! An in-flight scan COUNTER plus an RAII guard, both scoped to ONE
6//! [`SSTableReader`](super::SSTableReader). When the first scan on that reader
7//! begins, the reader's SCAN mapping is advised `MADV_WILLNEED`; when the last
8//! one ends it is advised `MADV_DONTNEED`. Before this existed, an explicit
9//! [`PrefetchMode::WillNeed`](crate::config::PrefetchMode::WillNeed) issued its
10//! `MADV_WILLNEED` at reader OPEN — i.e. a reader that was opened and never
11//! scanned paid a full-file read-ahead, and the advice was never withdrawn for
12//! the reader's whole lifetime. That open-time site is gone; this module is
13//! where the advice now lives.
14//!
15//! It is deliberately NOT a policy change:
16//! [`PrefetchMode::Auto`](crate::config::PrefetchMode::Auto) — the default —
17//! still issues NO madvise at all (issue #1143: `MADV_SEQUENTIAL`'s drop-behind
18//! blew up the read-side p99 tail under concurrent write load), and
19//! [`Sequential`](crate::config::PrefetchMode::Sequential) keeps its open-time
20//! advice, which is an explicit drop-behind opt-in. Only `WillNeed` moved.
21//!
22//! # What `MADV_DONTNEED` does here, stated precisely
23//!
24//! The scan mapping is **shared and file-backed** (`MAP_SHARED | PROT_READ`), so
25//! `MADV_DONTNEED` is an **RSS** control: it drops this process's resident
26//! private page-table references to the range. It is NOT a page-cache eviction —
27//! `madvise(2)` keeps the clean file pages in the page cache, and a later touch
28//! repopulates them from there. So the effect being bought is resident-set
29//! footprint after a scan finishes, never cache invalidation of any kind.
30//!
31//! # Why the advice is issued UNDER THE LOCK
32//!
33//! The counter is a [`std::sync::Mutex<u32>`] and both the transition test and
34//! the resulting syscall happen while that lock is held. An `AtomicU32` would
35//! leave a window in which a `1 -> 0` `DONTNEED` lands AFTER a concurrent
36//! `0 -> 1` `WILLNEED` and drops the residency of a mapping a freshly-started
37//! scan is already reading — exactly the interleaving issue #3853's constraint 3
38//! forbids. Serializing the transition with its syscall removes the window.
39//!
40//! This is **not** a reintroduction of the issue #815 scan mutex. #815 removed a
41//! lock held for a scan's ENTIRE DURATION, which serialized concurrent scans on
42//! one reader. This lock is taken exactly TWICE PER SCAN — once at
43//! [`ScanLifetime::begin`], once in [`ScanLifetimeGuard::drop`] — never per row,
44//! per block or per page, and it covers only the counter transition plus the one
45//! syscall whose ordering must be serialized with it. Two scans on one reader
46//! still run fully in parallel.
47//!
48//! # Nesting needs no exemption plumbing
49//!
50//! Several scan entry points delegate to each other
51//! (`iterate_all_partitions` -> `_cancellable` -> `_via_full_index` -> the
52//! sequential fallback), so an inner guard simply raises the count and only the
53//! OUTERMOST guard's drop releases. Contrast `scan_admission`'s
54//! [`Exempt`](super::scan_stream_windowed::scan_admission::ScanAdmission::Exempt),
55//! which exists because a bounded SEMAPHORE can hold-and-wait on itself; a
56//! counter cannot, so every site can be wired unconditionally.
57//!
58//! # What is guarded, and what is NOT (issue #3853 fix round 1)
59//!
60//! An earlier account of this seam claimed that *every* whole-`Data.db` walk
61//! reachable on [`SSTableReader`] holds a guard. That claim was FALSE when it
62//! was written — a sweep of every reachable function that mints a scan cursor or
63//! drives `stitch_all_chunks*` found EIGHT unguarded sites of nineteen, two of
64//! them real entry points (`prepare_delta_scan`, `scan_for_key`). A wrong
65//! invariant in a doc comment is worse than no invariant, because it is what
66//! stops the next person looking. The TRUE rule, stated as what is actually
67//! enforced:
68//!
69//! **A whole-data-section walk holds a guard if it is one of the enumerated
70//! entry points, OR if it reaches the data through the
71//! `stitch_all_chunks_cancellable` funnel.** Nothing else is guaranteed.
72//!
73//! Neither half is a closure, and the residual is NAMED rather than implied:
74//!
75//! - The entry-point set is CURATED. A new `pub`/`pub(super)` walk added
76//!   tomorrow is not guarded until someone wires it, and no mechanism reds when
77//!   they do not. Re-run the sweep (segment each `data_access/*.rs` and
78//!   `partition_lookup.rs` by `fn`, and for every body containing
79//!   `new_scan_cursor()` or `stitch_all_chunks*(` check whether the body also
80//!   contains `begin_scan()`) rather than trusting this list.
81//! - The funnel covers only walks that GO THROUGH it. A **raw block-loop walk**
82//!   — the shape `get_all_entries`' and `scan_for_key`'s non-stitching branches
83//!   already have, `while let Some(block) = self.read_next_block(..)` — bypasses
84//!   the funnel entirely. Such a walk added in future is NOT automatically
85//!   guarded. The funnel guard is a narrowing of the hole, not a closure.
86//!
87//! Consequence of being unguarded, for scale: the seam is a resident-set
88//! control, so a missed site means that walk's pages are not advised in and not
89//! released after — an RSS and read-ahead regression, never a correctness one.

96/// Per-reader scan-lifetime state. `inner == None` means the seam is DISABLED
97/// for this reader: [`begin`](Self::begin) hands out an inert guard, no syscall
98/// is ever issued and both counters stay at zero.
99pub(crate) struct ScanLifetime {
100    inner: Option<Inner>,
101}
102
103struct Inner {
104    /// The reader's SCAN mapping, or `None` for the counting-only test
105    /// construction (and on non-unix, where `madvise` does not exist) — the
106    /// counters still move so the transition logic is testable without I/O.
107    #[cfg_attr(not(unix), allow(dead_code))]
108    mmap: Option<Arc<memmap2::Mmap>>,
109    /// Scans currently in flight on this reader. Guards the transition AND the
110    /// syscall (see the module docs).
111    in_flight: std::sync::Mutex<u32>,
112    /// `MADV_WILLNEED` / `MADV_DONTNEED` ATTEMPTS (see
113    /// [`SSTableReader::scan_lifetime_advice_counts`]).
114    willneed: AtomicU64,
115    dontneed: AtomicU64,
116}
117
118impl ScanLifetime {
119    /// A disabled seam: no mapping, no syscalls, counters pinned at zero.
120    pub(crate) fn disabled() -> Arc<Self> {
121        Arc::new(Self { inner: None })
122    }
123
124    /// An ENABLED seam over `mmap`, the reader's scan mapping.
125    ///
126    /// Unix-only: `Mmap::advise` / `Mmap::unchecked_advise` are `#[cfg(unix)]`
127    /// in memmap2, so on every other target the seam is disabled outright.
128    #[cfg(unix)]
129    pub(crate) fn for_scan_mapping(mmap: Arc<memmap2::Mmap>) -> Arc<Self> {
130        Arc::new(Self {
131            inner: Some(Inner::new(Some(mmap))),
132        })
133    }
134
135    /// An ENABLED seam with NO mapping: the transition logic and the counters
136    /// run, no syscall is issued. Lets the unit tests below pin the 0->1 / 1->0
137    /// semantics with no file, no mapping and no I/O at all.
138    #[cfg(test)]
139    pub(crate) fn counting_only() -> Arc<Self> {
140        Arc::new(Self {
141            inner: Some(Inner::new(None)),
142        })
143    }
144
145    /// Register one in-flight scan, advising `MADV_WILLNEED` on the 0->1
146    /// transition, and return the RAII guard whose drop unregisters it.
147    pub(crate) fn begin(self: &Arc<Self>) -> ScanLifetimeGuard {
148        match &self.inner {
149            None => ScanLifetimeGuard { lifetime: None },
150            Some(inner) => {
151                // Poisoned means a panic happened while the lock was held. The
152                // guarded state is a `u32` plus one best-effort syscall, so
153                // there is no invariant to protect by refusing to proceed;
154                // recover the count and carry on (never `unwrap`).
155                let mut count = inner
156                    .in_flight
157                    .lock()
158                    .unwrap_or_else(|poisoned| poisoned.into_inner());
159                // `saturating_add` cannot wrap a live count back to 0 and so can
160                // never fabricate a spurious "last scan ended" release. At the
161                // (unreachable) `u32::MAX` ceiling the seam simply stops
162                // releasing — it holds WILLNEED — which is the safe direction.
163                *count = count.saturating_add(1);
164                if *count == 1 {
165                    inner.advise_willneed();
166                }
167                ScanLifetimeGuard {
168                    lifetime: Some(Arc::clone(self)),
169                }
170            }
171        }
172    }
173
174    /// Scans currently in flight (0 when the seam is disabled).
175    pub(crate) fn in_flight(&self) -> u32 {
176        match &self.inner {
177            None => 0,
178            Some(inner) => *inner
179                .in_flight
180                .lock()
181                .unwrap_or_else(|poisoned| poisoned.into_inner()),
182        }
183    }
184
185    /// `(willneed, dontneed)` advice ATTEMPTS ((0, 0) when disabled).
186    pub(crate) fn advice_counts(&self) -> (u64, u64) {
187        match &self.inner {
188            None => (0, 0),
189            Some(inner) => (
190                inner.willneed.load(Ordering::Relaxed),
191                inner.dontneed.load(Ordering::Relaxed),
192            ),
193        }
194    }
195}
196
197impl Inner {
198    fn new(mmap: Option<Arc<memmap2::Mmap>>) -> Self {
199        Self {
200            mmap,
201            in_flight: std::sync::Mutex::new(0),
202            willneed: AtomicU64::new(0),
203            dontneed: AtomicU64::new(0),
204        }
205    }
206
207    /// First scan started: ask the kernel to populate the mapping. Counted as an
208    /// ATTEMPT before the call, so the counter reflects transitions taken rather
209    /// than syscall outcomes; an advise failure is non-fatal and logged at
210    /// `debug`, the same posture as the pre-existing madvise sites.
211    fn advise_willneed(&self) {
212        self.willneed.fetch_add(1, Ordering::Relaxed);
213        #[cfg(unix)]
214        if let Some(mmap) = &self.mmap {
215            if let Err(e) = mmap.advise(memmap2::Advice::WillNeed) {
216                tracing::debug!("madvise(WILLNEED) on scan mapping failed: {}", e);
217            }
218        }
219    }
220
221    /// Last scan ended: drop this process's residency for the scan mapping.
222    fn advise_dontneed(&self) {
223        self.dontneed.fetch_add(1, Ordering::Relaxed);
224        #[cfg(unix)]
225        if let Some(mmap) = &self.mmap {
226            // SAFETY: memmap2 puts `DontNeed` behind `UncheckedAdvice` because
227            // for an ANONYMOUS or PRIVATE mapping `MADV_DONTNEED` makes the next
228            // touch read as ZERO-FILL, which would change observable content
229            // under a live borrow. That case cannot arise here:
230            // `MmapOptions::map` maps `PROT_READ | MAP_SHARED` over a FILE
231            // (memmap2-0.9.11 `src/unix.rs:245-257`), and this reader's standing
232            // contract is that the file is immutable for the reader's lifetime
233            // (see `SSTableReader::map_file`). For a shared file-backed mapping
234            // `MADV_DONTNEED` discards resident pages and the next touch
235            // repopulates from the up-to-date file contents — the SAME bytes. So
236            // no borrow can observe a change: outstanding zero-copy borrows into
237            // this mapping (`value_borrow.rs`) stay valid, and the whole cost of
238            // touching a released page under a stale borrow is a REFAULT, never
239            // a content change.
240            if let Err(e) = unsafe { mmap.unchecked_advise(memmap2::UncheckedAdvice::DontNeed) } {
241                tracing::debug!("madvise(DONTNEED) on scan mapping failed: {}", e);
242            }
243        }
244    }
245}

247/// RAII registration of ONE in-flight scan on one reader.
248///
249/// `Send + 'static` (it holds only an `Option<Arc<ScanLifetime>>`) so it can be
250/// held across `await` points and moved into a spawned scan task, which is how
251/// the streaming scan surfaces bind it to the task's lifetime. An inert guard
252/// (disabled seam) costs one `None` check on drop.
253pub(crate) struct ScanLifetimeGuard {
254    lifetime: Option<Arc<ScanLifetime>>,
255}
256
257impl Drop for ScanLifetimeGuard {
258    fn drop(&mut self) {
259        let Some(lifetime) = self.lifetime.take() else {
260            return;
261        };
262        let Some(inner) = &lifetime.inner else {
263            return;
264        };
265        let mut count = inner
266            .in_flight
267            .lock()
268            .unwrap_or_else(|poisoned| poisoned.into_inner());
269        *count = count.saturating_sub(1);
270        if *count == 0 {
271            inner.advise_dontneed();
272        }
273    }
274}

276impl SSTableReader {
277    /// Register this scan with the reader's scan-lifetime seam (issue #3853).
278    ///
279    /// Called at the top of each ENUMERATED scan entry point, and inside the
280    /// `stitch_all_chunks_cancellable` funnel; the returned guard must be bound
281    /// for the scan's whole duration (`let _scan = self.begin_scan();`).
282    /// The set of guarded walks is CURATED, not exhaustive — see the module
283    /// docs' "What is guarded, and what is NOT" for the true rule and its
284    /// residual.
285    /// A no-op for every reader whose seam is disabled — which is every reader
286    /// that is not mmap-backed at an explicit `PrefetchMode::WillNeed` with a
287    /// dedicated point mapping.
288    pub(crate) fn begin_scan(&self) -> ScanLifetimeGuard {
289        self.scan_lifetime.begin()
290    }
291
292    /// `(willneed, dontneed)` scan-lifetime madvise ATTEMPTS on this reader.
293    ///
294    /// Counts ATTEMPTS, not successes: each counter is incremented on the
295    /// counter transition that decides to advise, BEFORE the syscall, and an
296    /// `EINVAL`/`ENOMEM` from `madvise` leaves the count raised (the failure is
297    /// logged at `debug` and is non-fatal). So the pair reports the scan-lifetime
298    /// TRANSITIONS this reader took, which is the observable property #3853 is
299    /// about. Incremented once per scan-start / scan-end transition — never per
300    /// row, block or page — so a reader under a nested or concurrent scan burst
301    /// still reports `(1, 1)`.
302    ///
303    /// `(0, 0)` forever when the seam is disabled for this reader, including the
304    /// default `PrefetchMode::Auto` (issue #1143) and every non-mmap backend.
305    /// Unconditionally `pub` and NOT feature-gated on purpose: a cfg-gated
306    /// assertion would be coverage that executes in no gate component (#3522).
307    pub fn scan_lifetime_advice_counts(&self) -> (u64, u64) {
308        self.scan_lifetime.advice_counts()
309    }
310
311    /// Scans currently in flight on this reader (0 when the seam is disabled).
312    pub fn scan_lifetime_in_flight(&self) -> u32 {
313        self.scan_lifetime.in_flight()
314    }
315
316    /// Whether the scan-lifetime seam is ENABLED for this reader, i.e. whether
317    /// [`scan_lifetime_advice_counts`](Self::scan_lifetime_advice_counts) can
318    /// ever move off `(0, 0)`.
319    ///
320    /// Exists so a test asserting "open issued NO advice" is not VACUOUS: a
321    /// `(0, 0)` reading is also what a buffered reader, a non-unix target or an
322    /// `Auto`-prefetch reader returns, so the `(0, 0)` assertion only carries
323    /// information alongside a positive control that the seam was armed at all.
324    /// Because the seam is armed only for an mmap-backed reader at an explicit
325    /// `WillNeed` whose point plane holds a DIFFERENT mapping, a `true` here also
326    /// proves the reader took the mmap backend.
327    pub fn scan_lifetime_enabled(&self) -> bool {
328        self.scan_lifetime.is_enabled()
329    }
330}

336        self.inner.is_some()
337    }

340/// Resolve the scan-lifetime seam for a reader being opened (issue #3853).
341///
342/// ENABLED only when ALL THREE hold:
343///
344/// 1. the reader took the **mmap** backend
345///    ([`ScanSource::Mapped`](super::source::ScanSource::Mapped)) — the other
346///    backends have no per-mapping advice concept at all;
347/// 2. the resolved prefetch mode is an explicit
348///    [`PrefetchMode::WillNeed`](crate::config::PrefetchMode::WillNeed).
349///    `Auto` must issue NOTHING (issue #1143) and `Sequential` keeps its
350///    open-time drop-behind advice, which is a different, explicit opt-in;
351/// 3. the POINT plane holds a DIFFERENT mapping from the scan plane, tested by
352///    `Arc::ptr_eq`. `SSTableReader::point_read_mmap` returns the scan `Arc`
353///    ITSELF when the file is below `POINT_MMAP_MADV_RANDOM_MIN_BYTES` (8 MiB)
354///    or when the dedicated map / its `MADV_RANDOM` failed, so pointer identity
355///    is an EXACT test of "does the point plane share the scan mapping". Same
356///    `Arc` => DISABLED: releasing the scan mapping's residency would degrade
357///    the point plane that is reading through the very same pages (issue #3853
358///    AC bullet 3 / constraint 3).
359///
360/// Anything else yields [`ScanLifetime::disabled`].
361#[cfg(unix)]
362pub(crate) fn resolve(
363    scan_source: &super::source::ScanSource,
364    prefetch: crate::config::PrefetchMode,
365    point_plane_mmap: Option<&Arc<memmap2::Mmap>>,
366) -> Arc<ScanLifetime> {
367    let scan_mmap = match scan_source {
368        super::source::ScanSource::Mapped(mmap) => mmap,
369        _ => return ScanLifetime::disabled(),
370    };
371    if !matches!(prefetch, crate::config::PrefetchMode::WillNeed) {
372        return ScanLifetime::disabled();
373    }
374    match point_plane_mmap {
375        Some(point) if !Arc::ptr_eq(point, scan_mmap) => {
376            ScanLifetime::for_scan_mapping(Arc::clone(scan_mmap))
377        }
378        // Same allocation (sub-8-MiB file, or a failed dedicated map), or no
379        // point mapping recorded at all: never release the scan mapping.
380        _ => ScanLifetime::disabled(),
381    }
382}

399    #[test]
400    fn disabled_never_advises() {
401        let lifetime = ScanLifetime::disabled();
402        let guard = lifetime.begin();
403        assert_eq!(lifetime.in_flight(), 0);
404        drop(guard);
405        assert_eq!(lifetime.advice_counts(), (0, 0));
406    }

408    #[test]
409    fn first_begin_advises_willneed_and_last_end_advises_dontneed() {
410        let lifetime = ScanLifetime::counting_only();
411        let outer = lifetime.begin();
412        assert_eq!(lifetime.advice_counts(), (1, 0));
413        assert_eq!(lifetime.in_flight(), 1);
414        let inner = lifetime.begin();
415        assert_eq!(
416            lifetime.advice_counts(),
417            (1, 0),
418            "nested begin must not re-advise"
419        );
420        assert_eq!(lifetime.in_flight(), 2);
421        drop(inner);
422        assert_eq!(
423            lifetime.advice_counts(),
424            (1, 0),
425            "inner end must not release"
426        );
427        drop(outer);
428        assert_eq!(lifetime.advice_counts(), (1, 1));
429        assert_eq!(lifetime.in_flight(), 0);
430        drop(lifetime.begin());
431        assert_eq!(lifetime.advice_counts(), (2, 2), "a later scan re-advises");
432    }
433
434    #[test]
435    fn overlapping_threads_advise_exactly_once() {
436        const THREADS: usize = 8;
437        let lifetime = ScanLifetime::counting_only();
438        let barrier = Arc::new(std::sync::Barrier::new(THREADS));
439        let mut handles = Vec::with_capacity(THREADS);
440        for _ in 0..THREADS {
441            let lifetime = Arc::clone(&lifetime);
442            let barrier = Arc::clone(&barrier);
443            handles.push(std::thread::spawn(move || {
444                let guard = lifetime.begin();
445                // Every thread holds its guard until ALL threads hold one, so the
446                // overlap is a barrier fact, never a sleep race.
447                barrier.wait();
448                drop(guard);
449            }));
450        }
451        for h in handles {
452            assert!(h.join().is_ok());
453        }
454        assert_eq!(lifetime.advice_counts(), (1, 1));
455        assert_eq!(lifetime.in_flight(), 0);
456    }

465    /// Map a small temp file twice and return `(scan_mmap, distinct_point_mmap)`.
466    fn two_mappings() -> (
467        Arc<memmap2::Mmap>,
468        Arc<memmap2::Mmap>,
469        tempfile::NamedTempFile,
470    ) {
471        let mut tmp = tempfile::NamedTempFile::new().expect("temp file");
472        tmp.write_all(&[7u8; 4096]).expect("write");
473        tmp.flush().expect("flush");
474        let map = || {
475            let f = std::fs::File::open(tmp.path()).expect("open");
476            // SAFETY: read-only mapping of a file this test owns and does not
477            // mutate while mapped (same contract as `SSTableReader::map_file`).
478            Arc::new(unsafe { memmap2::MmapOptions::new().map(&f).expect("map") })
479        };
480        let scan = map();
481        let point = map();
482        assert!(!Arc::ptr_eq(&scan, &point), "two distinct mappings");
483        (scan, point, tmp)
484    }
485
486    #[test]
487    fn enabled_only_for_mapped_willneed_with_a_distinct_point_plane() {
488        let (scan, point, _tmp) = two_mappings();
489        let mapped = super::super::source::ScanSource::Mapped(Arc::clone(&scan));
490
491        assert!(
492            resolve(&mapped, PrefetchMode::WillNeed, Some(&point)).is_enabled(),
493            "mmap + WillNeed + distinct point mapping must arm the seam"
494        );
495
496        // #1143: `Auto` issues nothing, ever. `Off`/`Sequential` are not this
497        // seam's business either (Sequential keeps its open-time advice).
498        for mode in [
499            PrefetchMode::Auto,
500            PrefetchMode::Off,
501            PrefetchMode::Sequential,
502        ] {
503            assert!(
504                !resolve(&mapped, mode, Some(&point)).is_enabled(),
505                "prefetch {:?} must leave the seam disabled",
506                mode
507            );
508        }
509
510        // The point plane sharing the scan mapping (sub-8-MiB file, or a failed
511        // dedicated map) must disable the seam, as must an absent point mapping.
512        assert!(
513            !resolve(&mapped, PrefetchMode::WillNeed, Some(&scan)).is_enabled(),
514            "a shared point/scan mapping must disable the seam"
515        );
516        assert!(
517            !resolve(&mapped, PrefetchMode::WillNeed, None).is_enabled(),
518            "no recorded point mapping must disable the seam"
519        );
520
521        // Non-mmap backends have no per-mapping advice concept.
522        let buffered = super::super::source::ScanSource::Buffered { file_len: 4096 };
523        assert!(!resolve(&buffered, PrefetchMode::WillNeed, Some(&point)).is_enabled());
524    }
