1//! The LAST-RESORT regular-column scanner: `[0x00]`-anchored `[name][type]`
2//! lists, for files where the partition-key/clustering sections could not be
3//! located at all.
4//!
5//! Extracted from `serialization_header/mod.rs` under the campsite rule
6//! (#1116): that file was 747 lines against an 800-line target, and the
7//! confirm-then-refuse rule below could not be documented there without
8//! tripping the `file-size` ratchet.
9//!
10//! # WHY A REFUSAL HERE IS NOT AUTHORITATIVE ON ARRIVAL (#4104, roborev job 121)
11//!
12//! This scanner runs only after the marker search has failed to locate a header,
13//! and it anchors on a single `0x00` byte. So its candidates are the WEAKEST
14//! guesses in the module: any `0x00` followed by a small count and a plausible
15//! `[len][name][VInt len][type]` run reaches the semantic gate. Propagating a
16//! `FrozenType(<scalar>)` refusal from such a run — which the first #4104 fix
17//! did — lets unrelated bytes make an otherwise VALID SSTable unopenable, the
18//! same over-refusal `candidate_identity::candidate_confirmed_as_header` fixed
19//! on the sequential paths (job 120).
20//!
21//! There is no `keyType` FIELD here to confirm against, so that helper does not
22//! apply. The rule used instead is the one property this site can decide:
23//!
24//! **A refusal is enforced exactly where the scanner would otherwise have
25//! ACCEPTED, and only on evidence that what it accepted is a header.**
26//!
27//! Concretely, a deferred refusal becomes authoritative only when all three
28//! hold:
29//!
30//! 1. the candidate's column list is COMPLETE and TERMINATED — every one of its
31//!    own declared `column_count` entries decoded, which is the same condition
32//!    the accept path requires;
33//! 2. every column type in it is a fully-qualified marshal class SPELLING, not
34//!    merely a string that contains the package (see
35//!    [`super::candidate_identity::is_marshal_type_spelling`]); and
36//! 3. the backtracking recovered a partition-key type that is also such a
37//!    spelling and that ends EXACTLY at the anchor, i.e. the `[VInt len][class
38//!    name]` field Cassandra's `SerializationHeader.writeType` writes
39//!    immediately before the counts.
40//!
41//! ## What that confirmation does and does not establish
42//!
43//! It establishes that these bytes carry a length-framed marshal class spelling
44//! ending exactly where a count section begins, followed by a fully consumed
45//! `count × ([len][name][VInt len][marshal spelling])` list — the byte shape and
46//! the type-string spellings `AbstractType::toString()` produces and therefore
47//! the only ones `writeType` can have written (`cassandra-5.0.8:src/java/org/
48//! apache/cassandra/db/SerializationHeader.java`; framing tabulated in
49//! `docs/sstables-definitive-guide/chapters/08-statistics-db.md`).
50//!
51//! It does NOT establish that this offset IS the header: no `keyType` field, no
52//! clustering or static section and no EncodingStats anchor are decoded here, so
53//! the evidence is strictly weaker than the sequential paths'. That is inherent
54//! to a scanner whose premise is that the header could not be located — it is
55//! the strongest evidence available at this site, not a proof of identity.
56//!
57//! ## It does not reopen the fail-open
58//!
59//! An UNCONFIRMED candidate carrying a deferred refusal is SKIPPED, never
60//! returned: its surveyed columns hold a raw marshal spelling in place of a CQL
61//! type, and returning those would be both a wrong schema and the #28
62//! heuristic-fallback the deferral exists to avoid. A CONFIRMED one propagates
63//! `Refused`, so it can reach neither another candidate nor the dispatcher's
64//! empty-schema `Ok` (job 119's fail-open).

72/// `(partition_key_types, regular_columns)` — what the backtracking column
73/// scanner recovers when no partition-key/clustering section could be located.
74/// Named so its `Result` stays inside clippy's `type_complexity` budget.
75pub(super) type RegularColumns = (Vec<String>, Vec<ColumnInfo>);

77/// Extract partition key type by backtracking from the `0x00 0x00` marker
78///
79/// The partition key type descriptor ends immediately before the marker.
80/// We try parsing VInt lengths at different offsets before the marker to find
81/// a valid type string that matches Cassandra marshal type patterns.
82fn extract_partition_key_before_marker(input: &[u8], marker_offset: usize) -> Option<String> {
83    if marker_offset < 3 {
84        return None;
85    }
86
87    tracing::debug!(
88        "Backtracking from marker at offset {} (input len: {})",
89        marker_offset,
90        input.len()
91    );
92
93    // Try parsing VInt lengths at different positions before the marker
94    // Type strings can be up to 200 bytes, and VInts can be 1-9 bytes,
95    // so we need to search back at least 209 bytes (200 + 9)
96    let max_lookback = 210;
97    let search_start = marker_offset.saturating_sub(max_lookback);
98    tracing::debug!(
99        "Searching for VInt from offset {} to {} ({} positions)",
100        search_start,
101        marker_offset,
102        marker_offset - search_start
103    );
104
105    for vint_start in (search_start..marker_offset).rev() {
106        // Try to parse VInt at this position
107        match parse_vuint(&input[vint_start..marker_offset]) {
108            Ok((remaining, type_len)) => {
109                // Validate type length is reasonable first (before any arithmetic)
110                if !(10..200).contains(&type_len) {
111                    continue;
112                }
113
114                // Calculate how many bytes the VInt consumed
115                let vint_len = marker_offset - vint_start - remaining.len();
116                let type_start = vint_start + vint_len;
117
118                // Bounds check before addition to prevent overflow
119                let type_len_usize = type_len as usize;
120                if type_start > input.len() || type_len_usize > input.len() - type_start {
121                    continue;
122                }
123
124                let type_end = type_start + type_len_usize;
125
126                // Validate:
127                // 1. The type string ends exactly at the marker
128                // 2. The type string is valid UTF-8
129                // 3. It matches Cassandra marshal type patterns
130                if type_end == marker_offset {
131                    if let Ok(type_str) = std::str::from_utf8(&input[type_start..type_end]) {
132                        tracing::debug!(
133                            "Candidate at vint_start={}: type_len={}, type_start={}, type_end={}, str={}",
134                            vint_start, type_len, type_start, type_end, type_str
135                        );
136                        // Validate it's a Cassandra marshal type
137                        // Note: Partition key types may or may not start with '('
138                        // Both "(org.apache.cassandra..." and "org.apache.cassandra..." are valid
139                        if type_str.contains("org.apache.cassandra") {
140                            tracing::debug!(
141                                "Found partition key type at offset {}: length={}, type={}",
142                                vint_start,
143                                type_len,
144                                type_str
145                            );
146                            return Some(type_str.to_string());
147                        } else {
148                            tracing::debug!(
149                                "Rejected candidate (starts_with='(': {}, contains 'org.apache.cassandra': {})",
150                                type_str.starts_with('('),
151                                type_str.contains("org.apache.cassandra")
152                            );
153                        }
154                    } else {
155                        tracing::debug!(
156                            "Rejected candidate at vint_start={}: not valid UTF-8",
157                            vint_start
158                        );
159                    }
160                }
161            }
162            Err(_) => continue, // Try next offset
163        }
164    }
165
166    None
167}

169/// Whether a COMPLETE candidate's own recovered strings confirm that this anchor
170/// holds a SerializationHeader, to the extent this site can decide.
171///
172/// `candidate_key_type` is what the backtracking recovered immediately before the
173/// anchor (`None` = nothing did), and `declared_types` are the RAW type spellings
174/// of the columns the candidate declared. Both must be fully-qualified marshal
175/// class spellings, which is what `SerializationHeader.writeType` writes and what
176/// arbitrary bytes quoting a type name generally are not. The module header
177/// states precisely what this establishes and what it does not.
178fn scanned_candidate_confirmed(candidate_key_type: Option<&str>, declared_types: &[&str]) -> bool {
179    let Some(key_type) = candidate_key_type else {
180        tracing::debug!(
181            "Column-section candidate refused a type but no partition-key type ends at its \
182             anchor, so nothing identifies it as a header; continuing the scan"
183        );
184        return false;
185    };
186    if !is_marshal_type_spelling(key_type) {
187        tracing::debug!(
188            "Column-section candidate refused a type but the string before its anchor is not \
189             a marshal class spelling ({:?}); continuing the scan",
190            key_type
191        );
192        return false;
193    }
194    // Empty is unconfirmable rather than vacuously confirmed: a candidate that
195    // declared no column cannot have refused one. (The scanner already rejects
196    // `column_count == 0`, so this is a guard against a future caller, not a
197    // reachable state.)
198    !declared_types.is_empty()
199        && declared_types.iter().all(|declared| {
200            let spelled = is_marshal_type_spelling(declared);
201            if !spelled {
202                tracing::debug!(
203                    "Column-section candidate refused a type but one of its column types is \
204                     not a marshal class spelling ({:?}); continuing the scan",
205                    declared
206                );
207            }
208            spelled
209        })
210}

212/// Parse regular columns section from SerializationHeader
213///
214/// Returns: (partition_key_types, regular_columns)
215/// Partition key types are extracted via backtracking when found before the column section marker.
216///
217/// A `FrozenType(<scalar>)` refusal raised inside a candidate is DEFERRED to that
218/// candidate's acceptance point and enforced only if
219/// [`scanned_candidate_confirmed`] holds — this module's header states the rule
220/// and what it does and does not establish (#4104, roborev job 121).
221pub(super) fn parse_regular_columns(
222    input: &[u8],
223) -> Result<(&[u8], RegularColumns), HeaderSchemaError<'_>> {
224    let mut search_offset = 0;
225    let mut partition_key_types = Vec::new();
226
227    while search_offset + 2 < input.len() && search_offset < 8192 {
228        if input[search_offset] == 0x00 {
229            let (marker_offset, count_offset) =
230                if search_offset + 1 < input.len() && input[search_offset + 1] == 0x00 {
231                    (search_offset, search_offset + 2)
232                } else {
233                    (search_offset, search_offset + 1)
234                };
235
236            if count_offset >= input.len() {
237                break;
238            }
239
240            let column_count = input[count_offset] as usize;
241            if column_count == 0 || column_count > 50 {
242                search_offset += 1;
243                continue;
244            }
245
246            tracing::debug!(
247                "Attempting to extract partition key by backtracking from marker at offset {}",
248                marker_offset
249            );
250            // Kept per-candidate as well as pushed: `partition_key_types`
251            // accumulates across candidates, so it cannot answer "what did the
252            // backtracking recover at THIS anchor?", which is what the
253            // confirmation below asks.
254            let mut candidate_key_type = None;
255            if let Some(pk_type) = extract_partition_key_before_marker(input, marker_offset) {
256                tracing::debug!("Found partition key type before marker: {}", pk_type);
257                candidate_key_type = Some(pk_type.clone());
258                partition_key_types.push(pk_type);
259            } else {
260                tracing::debug!(
261                    "No partition key type found via backtracking at offset {}",
262                    marker_offset
263                );
264            }
265
266            let mut pos = count_offset + 1;
267
268            let context_len = std::cmp::min(128, input.len() - marker_offset);
269            let context_hex: String = input[marker_offset..marker_offset + context_len]
270                .iter()
271                .map(|b| format!("{:02x}", b))
272                .collect::<Vec<_>>()
273                .join(" ");
274            tracing::debug!(
275                "Pattern found at offset {}: count={}, next 128 bytes: {}",
276                marker_offset,
277                column_count,
278                context_hex
279            );
280
281            // Try to parse all columns - if successful, we found the right section
282            let mut parsed_columns = Vec::with_capacity(column_count);
283            let mut parse_success = true;
284            // The refused type, held until this candidate is either accepted or
285            // skipped, plus the RAW spellings the candidate declared (the
286            // confirmation judges spellings, and `ColumnInfo::column_type` holds
287            // the CONVERTED CQL name).
288            let mut deferred_refusal = None;
289            let mut declared_types: Vec<&str> = Vec::with_capacity(column_count);
290
291            for col_idx in 0..column_count {
292                if pos >= input.len() {
293                    tracing::debug!(
294                        "Column {} parsing failed at offset {}: position {} exceeds buffer length {}",
295                        col_idx,
296                        marker_offset,
297                        pos,
298                        input.len()
299                    );
300                    parse_success = false;
301                    break;
302                }
303
304                if pos >= input.len() {
305                    tracing::debug!(
306                        "Column {} parsing failed at offset {}: no data available for name length byte (pos={}, len={})",
307                        col_idx,
308                        marker_offset,
309                        pos,
310                        input.len()
311                    );
312                    parse_success = false;
313                    break;
314                }
315
316                let name_len = input[pos] as usize;
317                pos += 1;
318
319                if name_len == 0 || name_len > 200 || pos + name_len > input.len() {
320                    tracing::debug!(
321                        "Column {} parsing failed at offset {}: name_len sanity check failed (name_len={}, pos={}, buffer_len={})",
322                        col_idx,
323                        marker_offset,
324                        name_len,
325                        pos,
326                        input.len()
327                    );
328                    parse_success = false;
329                    break;
330                }
331
332                // Column name (UTF-8 string)
333                let name_bytes = &input[pos..pos + name_len];
334                let column_name = match std::str::from_utf8(name_bytes) {
335                    Ok(s) => s.to_string(),
336                    Err(e) => {
337                        let name_hex: String = name_bytes
338                            .iter()
339                            .map(|b| format!("{:02x}", b))
340                            .collect::<Vec<_>>()
341                            .join(" ");
342                        tracing::debug!(
343                            "Column {} parsing failed at offset {}: UTF-8 decode error for column name at pos {} (len={}): {:?}, bytes: {}",
344                            col_idx,
345                            marker_offset,
346                            pos,
347                            name_len,
348                            e,
349                            name_hex
350                        );
351                        parse_success = false;
352                        break;
353                    }
354                };
355                pos += name_len;
356
357                if pos >= input.len() {
358                    tracing::debug!(
359                        "Column {} ('{}') parsing failed at offset {}: no data available for type length byte (pos={}, len={})",
360                        col_idx,
361                        column_name,
362                        marker_offset,
363                        pos,
364                        input.len()
365                    );
366                    parse_success = false;
367                    break;
368                }
369
370                // Parse type length as VInt (can exceed 127 for collection types)
371                let type_len_result = parse_vuint(&input[pos..]);
372                let (type_remaining, type_len_u64) = match type_len_result {
373                    Ok(r) => r,
374                    Err(_) => {
375                        tracing::debug!(
376                            "Column {} ('{}') parsing failed at offset {}: VInt parse error at pos {}",
377                            col_idx,
378                            column_name,
379                            marker_offset,
380                            pos
381                        );
382                        parse_success = false;
383                        break;
384                    }
385                };
386                let type_len = type_len_u64 as usize; // #3848: raw `u64` bounded on the `if` below
387                pos = input.len() - type_remaining.len();
388
389                if type_len_u64 == 0 || type_len_u64 > 5000 || pos + type_len > input.len() {
390                    tracing::debug!(
391                        "Column {} ('{}') parsing failed at offset {}: type_len sanity check failed (type_len={}, pos={}, buffer_len={})",
392                        col_idx,
393                        column_name,
394                        marker_offset,
395                        type_len,
396                        pos,
397                        input.len()
398                    );
399                    parse_success = false;
400                    break;
401                }
402
403                // Column type: decoded and CQL-converted in one step. The two causes
404                // no longer share one arm (#4104, roborev job 119) — they are
405                // DIFFERENT answers. Bytes that are not UTF-8 mean "this marker
406                // offset holds no readable header", so the search continues. A type
407                // no Cassandra writer can have recorded means the header IS here and
408                // is unwritable, so it fails CLOSED and carries its message out.
409                let type_bytes = &input[pos..pos + type_len];
410                let Ok(internal_type) = std::str::from_utf8(type_bytes) else {
411                    tracing::debug!(
412                        "Column {} ('{}') parsing failed at offset {}: column type at pos {} \
413                         (len={}) is not valid UTF-8; bytes: {:02x?}",
414                        col_idx,
415                        column_name,
416                        marker_offset,
417                        pos,
418                        type_len,
419                        type_bytes
420                    );
421                    parse_success = false;
422                    break;
423                };
424                declared_types.push(internal_type);
425                let cql_type = match convert_marshal_type_to_cql_checked(internal_type) {
426                    Ok(cql_type) => cql_type,
427                    Err(refusal) => {
428                        // DEFERRED, not propagated: this anchor is a `0x00` guess
429                        // and an unrelated byte run must not make a valid SSTable
430                        // unopenable (module header). The raw spelling stands in
431                        // for the CQL name so the list can decode to its declared
432                        // end — the candidate is SKIPPED rather than returned if
433                        // the refusal turns out to be unconfirmed, so this
434                        // spelling never reaches a caller as a schema.
435                        deferred_refusal.get_or_insert(refusal);
436                        internal_type.to_string()
437                    }
438                };
439                pos += type_len;
440
441                parsed_columns.push(ColumnInfo {
442                    name: column_name,
443                    column_type: cql_type,
444                    is_primary_key: false, // Will be determined from partition/clustering info
445                    key_position: None,
446                    is_static: false,
447                    is_clustering: false,
448                    clustering_reversed: false,
449                });
450            }
451
452            if parse_success && parsed_columns.len() == column_count {
453                // The candidate is COMPLETE, so this is the point at which it
454                // would be accepted as the header — and therefore the point at
455                // which a deferred refusal is decided.
456                if let Some(refusal) = deferred_refusal {
457                    if scanned_candidate_confirmed(candidate_key_type.as_deref(), &declared_types) {
458                        return Err(HeaderSchemaError::Refused(refusal));
459                    }
460                    tracing::debug!(
461                        "Column section at offset {} refused a type but is not confirmed as a \
462                         header; skipping this candidate and continuing the scan",
463                        marker_offset
464                    );
465                    search_offset += 1;
466                    continue;
467                }
468
469                // Successfully parsed all columns
470                let column_names: Vec<&str> =
471                    parsed_columns.iter().map(|c| c.name.as_str()).collect();
472                tracing::debug!(
473                    "Successfully parsed {} columns at offset {}: {:?}",
474                    parsed_columns.len(),
475                    marker_offset,
476                    column_names
477                );
478                if !partition_key_types.is_empty() {
479                    tracing::debug!(
480                        "Extracted {} partition key types via backtracking: {:?}",
481                        partition_key_types.len(),
482                        partition_key_types
483                    );
484                }
485
486                let remaining = &input[pos..];
487                return Ok((remaining, (partition_key_types, parsed_columns)));
488            }
489        }
490
491        search_offset += 1;
492    }
493
494    // Column section not found - return empty vecs (not an error, some files may have no regular columns)
495    tracing::debug!(
496        "Regular column section not found: searched {} bytes",
497        search_offset
498    );
499    Ok((input, (Vec::new(), Vec::new())))
