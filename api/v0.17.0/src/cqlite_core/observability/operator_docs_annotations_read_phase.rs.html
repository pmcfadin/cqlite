1//! Operator annotations for the read-PHASE timing histograms and the
2//! reader/WAL resource gauges (issue #1707, AI7 of epic #1686).
3//!
4//! A SECOND annotation table beside `operator_docs_annotations.rs`, which was
5//! already at the campsite-rule source target (#1116): the table is append-only
6//! data, so a new family gets a new file rather than growing the existing one.
7//! Both are listed in `operator_docs_annotations::ANNOTATION_TABLES` and the
8//! renderer walks the union in catalog order.
9//!
10//! Prose split (issue #1707): the PER-METRIC operator sentence lives in these
11//! `interpretation` fields (they are what lands in the two committed markdown
12//! artifacts); the CROSS-metric "why was this query slow?" narrative — which
13//! order to read the phases in, and what to cross-check — lives in the
14//! `observability` module docs, so it is not duplicated per row.
15
16// No `attr` import: this family is deliberately attribute-FREE (every dimension

18// honestly knows), so every entry's `attributes` is empty.
