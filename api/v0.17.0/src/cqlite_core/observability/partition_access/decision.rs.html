1//! The decoded-partition-cache decision procedure, in executable form
2//! (issue #2827).
3//!
4//! The normative statement of this procedure — with its arithmetic, its
5//! provenance and its owner-settable threshold — is the committed note at
6//! `docs/research/decoded-partition-cache-decision.md`. This module is the same
7//! procedure as code, so a closed [`WindowSummary`] can be priced without a human
8//! analysis round and so the refusal conditions are testable rather than
9//! aspirational.
10//!
11//! **What it does not do.** It does not deliver a field skew number and it does not
12//! deliver the go/no-go for the 64–128 MiB decoded-partition cache. Issue #2827's
13//! original AC2 is **not satisfied** by this change — not waived, not deferred:
14//! satisfiable on a real keyed workload run with the probe enabled, whose absence
15//! (`docs/research/phase2-verify-caching.md:214-216`) is the reason it is unmet here.
16//!
17//! "Satisfiable" is SCOPED, not universal: this module REFUSES a window it cannot
18//! price, and three of those refusals are reachable on a healthy system — a
19//! non-census window, a non-zero `unavailable` fraction, and (under #2412's lazy
20//! Summary-guided open) a BIG generation whose `Index.db` is not resident. Every one
21//! fails SAFE — a refusal is never a false "go" — but the FIRST real window may well
22//! be refused, and obtaining a priceable one can take a shorter window, a resident
23//! index, or both. Applied to a window this
24//! repository generated, the procedure REFUSES by construction
25//! ([`WindowSource::Synthetic`]) — a synthetic input is a legitimate oracle for a
26//! claim about the instrument and an illegitimate one for a claim about the world.
27//!
28//! **`H_max` is NOT a ceiling — it is an estimate under a stated ranking
29//! heuristic.** It assumes a clairvoyant (Belady) cache, which alone would make it
30//! an upper bound; but buckets are ordered by `accesses / bytes` rather than by what
31//! a cache actually serves, `(accesses − distinct) / bytes`, so a bucket of large HOT
32//! partitions can be outranked by dense small SINGLETONS that serve nothing once
33//! admitted. The error from that defect was measured at ≈0.10 maximum observed, and
34//! because other mechanisms push independently (the fractional final-bucket take,
35//! and the instrument's own coverage limitations) **the total error can bias in
36//! EITHER direction**.
37//!
38//! Tracked as **issue #3340**. **#3340 MUST land before any go/no-go verdict is
39//! derived from a real production window**; until then a value near the threshold
40//! decides nothing, and neither a high nor a low reading is sound on its own.

44/// Where the measured window came from. A window this project generated can never
45/// be the go/no-go, however green it looks.
46#[derive(Clone, Copy, Debug, PartialEq, Eq)]
47pub enum WindowSource {
48    /// A real workload observed in the field.
49    Field,
50    /// A load this repository generated (a test, a rig, a loadgen run).
51    Synthetic,
52}
53
54/// Minimum accesses before a window is treated as a workload at all.
55pub const MIN_ACCESSES: u64 = 10_000;
56
57/// The recommended go threshold on `H_max(128 MiB)`.
58///
59/// **An OWNER-SETTABLE parameter, recorded as such**, not a derived constant. Its
60/// arithmetic: a decoded-partition cache targets decode/merge work, and the Arm-1
61/// CPU decomposition (#2818) measured k-way merge at 3.2% of on-CPU against LZ4
62/// decompress + CRC at ~23%. A cache whose ESTIMATED hit ratio is below 50% on a ≤~3% work
63/// share cannot move the end-to-end number by more than ~1.5%, which is under the
64/// round harness's noise floor. Naming a default with its arithmetic is what stops
65/// the first person to run the procedure from re-litigating it.
66pub const RECOMMENDED_GO_THRESHOLD: f64 = 0.50;
67
68/// The decode multiplier `m`: decoded bytes per on-disk byte.
69///
70/// **This is the one remaining ASSUMPTION in the procedure, not a measurement.**
71/// Its provenance is the Phase-0 wire estimate at
72/// `docs/research/phase2-verify-caching.md:221-222`, which is explicitly labelled
73/// an estimate there. Measuring it is follow-up F3.
74pub const ASSUMED_DECODE_MULTIPLIER: f64 = 3.5;

76/// Why the procedure declined to price a window. Each is a NO ANSWER, never a
77/// default verdict.
78#[derive(Clone, Debug, PartialEq)]
79pub enum Refusal {
80    /// The byte total is incomplete by an unknown amount: some partitions had no
81    /// authoritative extent at all — neither an index-recorded size nor a
82    /// measurable successor gap. A window whose bytes were MEASURED is complete and
83    /// is NOT refused here; incompleteness, not provenance, is what this condition
84    /// tests.
85    UnpriceableFraction {
86        /// Fraction of distinct partitions with `size_source = unavailable`.
87        fraction: f64,
88        /// How many of them there were.
89        partitions: u64,
90    },
91    /// The recorder hit its sampling floor; the surviving sample is worthless.
92    SamplingFloor {
93        /// The sampling scale in force at close.
94        sample_denominator: u64,
95    },
96    /// The window is a SAMPLE, not a census, so its per-bucket byte totals are in
97    /// the sample domain and cannot be filled against a real cache budget.
98    NonCensusSample {
99        /// The sampling scale in force at close (`2^k`).
100        sample_denominator: u64,
101    },
102    /// The recorder could not seat some accesses in its table at all, so the
103    /// histogram is missing input.
104    DroppedAccesses {
105        /// How many accesses were lost.
106        dropped: u64,
107        /// How many the window was asked to record.
108        recorded: u64,
109    },
110    /// The window is not a workload.
111    TooFewAccesses {
112        /// Accesses attributable to the admitted sample.
113        accesses: u64,
114        /// The stated minimum.
115        minimum: u64,
116    },
117    /// The window came from load this project generated. Recordable as an
118    /// instrument self-check; never citable as the go/no-go.
119    SyntheticWorkload,
120    /// Every priced partition reported zero bytes, so no budget can be filled.
121    NoPricedBytes,
122    /// An input was outside the domain the arithmetic is defined on.
123    ///
124    /// Checked before anything else because the failure is a FALSE GO, not a wrong
125    /// number: `decode_multiplier == 0.0` makes the on-disk budget `+inf`, every
126    /// bucket then "fits", and the procedure reports a maximal hit ratio clearing any
127    /// threshold. A `NaN` multiplier yields a `NaN` ratio that clears nothing but
128    /// reports a verdict anyway; a non-positive or `NaN` threshold makes
129    /// `clears_threshold` meaningless.
130    InvalidInput {
131        /// Which input, and what was wrong with it.
132        detail: &'static str,
133        /// The offending value, for the operator reading the refusal.
134        value: f64,
135    },
136}

138impl std::fmt::Display for Refusal {
139    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
140        match self {
141            Refusal::UnpriceableFraction {
142                fraction,
143                partitions,
144            } => write!(
145                f,
146                "REFUSED: {partitions} distinct partitions ({:.1}% of the window) have \
147                 size_source=unavailable, so the on-disk byte total is incomplete by an \
148                 unknown amount; a hit-ratio computed from a partial byte total would \
149                 overstate what fits in the budget",
150                fraction * 100.0
151            ),
152            Refusal::SamplingFloor { sample_denominator } => write!(
153                f,
154                "REFUSED: the recorder reached its sampling floor (denominator \
155                 {sample_denominator}); the surviving sample is statistically worthless"
156            ),
157            Refusal::NonCensusSample { sample_denominator } => write!(
158                f,
159                "REFUSED: this window is a 1-in-{sample_denominator} SAMPLE, not a \
160                 census. Its per-bucket bytes are sample-domain totals, so filling a \
161                 real cache budget against them would price the whole budget against \
162                 1/{sample_denominator} of the working set and OVERSTATE what fits. \
163                 Remedy: shorten the measurement window so the distinct set fits the \
164                 counting table — set CQLITE_PARTITION_ACCESS_WINDOW_SECS (or \
165                 CQLITE_PARTITION_ACCESS_WINDOW_ACCESSES) and re-measure"
166            ),
167            Refusal::DroppedAccesses { dropped, recorded } => write!(
168                f,
169                "REFUSED: {dropped} of {recorded} accesses could not be seated in the \
170                 counting table, so the histogram is missing input. Only NEW keys are \
171                 ever dropped, which suppresses the singleton bucket and overstates \
172                 concentration — the direction that flatters the cache"
173            ),
174            Refusal::TooFewAccesses { accesses, minimum } => write!(
175                f,
176                "REFUSED: {accesses} accesses is below the stated minimum of {minimum}; \
177                 this window is not a workload"
178            ),
179            Refusal::SyntheticWorkload => write!(
180                f,
181                "REFUSED: the window came from synthetic or self-generated load. Its output \
182                 may be recorded as an instrument self-check and may NEVER be cited as the \
183                 decoded-partition-cache go/no-go — the answer would be a function of a \
184                 distribution we chose"
185            ),
186            Refusal::NoPricedBytes => write!(
187                f,
188                "REFUSED: no partition in the window carried authoritative on-disk bytes, \
189                 so no budget can be filled"
190            ),
191            Refusal::InvalidInput { detail, value } => write!(
192                f,
193                "REFUSED: {detail} (got {value}). This is rejected rather than computed \
194                 because the arithmetic would still produce a verdict — a zero decode \
195                 multiplier makes the on-disk budget infinite, every bucket fits, and \
196                 the result is a maximal hit ratio that clears any threshold: a FALSE GO"
197            ),
198        }
199    }
200}

202/// A priced window.
203///
204/// **The name is historical**: it comes from the Belady/clairvoyant framing the
205/// procedure was originally written around. It is retained because renaming a public
206/// type is not worth a churn here — but [`Self::h_max`] is an ESTIMATE under a stated
207/// ranking heuristic, not a ceiling. See that field's documentation and issue #3340.
208#[derive(Clone, Copy, Debug, PartialEq)]
209pub struct Ceiling {
210    /// The decoded-cache budget priced, in bytes.
211    pub budget_bytes: u64,
212    /// On-disk bytes that fit in that budget under the assumed decode multiplier.
213    pub on_disk_budget_bytes: f64,
214    /// Estimated hit ratio under the procedure's stated ranking heuristic.
215    ///
216    /// **Not a ceiling.** The clairvoyance assumption alone would make it one, but
217    /// the bucket ranking uses `accesses / bytes` where a cache serves
218    /// `(accesses − distinct) / bytes`, so large hot partitions can be outranked by
219    /// dense small singletons and the budget spent on them. Measured error from that
220    /// defect ≈0.10 max observed; with the fractional final-bucket take and the
221    /// instrument's coverage limitations pushing independently, the total error can
222    /// go EITHER way. Issue #3340 must land before this decides anything real.
223    pub h_max: f64,
224    /// `h_max >= threshold`. Given the above this is an INDICATION, not a verdict:
225    /// a `false` is not automatically a sound no-go and a `true` is not a licence to
226    /// build — at most a licence to simulate LRU against the captured window.
227    pub clears_threshold: bool,
228    /// The threshold applied (an owner-settable parameter).
229    pub threshold: f64,
230}
231
232/// The procedure's answer.
233#[derive(Clone, Debug, PartialEq)]
234pub enum Verdict {
235    /// The window could not be priced. Names the reason.
236    Refused(Refusal),
237    /// The window was priced.
238    Priced(Ceiling),
239}
240
241impl Verdict {
242    /// Convenience: was this a refusal?
243    pub fn is_refusal(&self) -> bool {
244        matches!(self, Verdict::Refused(_))
245    }
246}

248/// Apply the procedure to one closed window at one decoded-cache budget.
249///
250/// Refusal conditions are checked FIRST and in order; each yields no answer rather
251/// than a default verdict. Every one of them is a property this procedure cannot
252/// price around: an incomplete byte total, lost input, a sample rather than a
253/// census, too little traffic to be a workload, or load we generated ourselves.
254pub fn evaluate(
255    summary: &WindowSummary,
256    source: WindowSource,
257    budget_bytes: u64,
258    decode_multiplier: f64,
259) -> Verdict {
260    evaluate_with_threshold(
261        summary,
262        source,
263        budget_bytes,
264        decode_multiplier,
265        RECOMMENDED_GO_THRESHOLD,
266    )
267}
268
269/// [`evaluate`] with an explicit go threshold — the threshold is the owner's
270/// parameter, so it is an argument rather than a constant baked into the answer.
271///
272/// `decode_multiplier` must be finite and `> 0`; `threshold` must be finite and in
273/// `[0.0, 1.0]`. Anything else is [`Refusal::InvalidInput`] — see that variant for why
274/// these are refused rather than computed.
275pub fn evaluate_with_threshold(
276    summary: &WindowSummary,
277    source: WindowSource,
278    budget_bytes: u64,
279    decode_multiplier: f64,
280    threshold: f64,
281) -> Verdict {
282    // 0. INPUT DOMAIN, before anything else. No in-repo caller can supply a bad value
283    //    today (they all pass `ASSUMED_DECODE_MULTIPLIER` / `RECOMMENDED_GO_THRESHOLD`),
284    //    but both are `f64` on a public function, and the failure mode is a false GO
285    //    rather than a visible error — the exact bias class this instrument exists to
286    //    avoid. The day a CLI flag or config plumbs the multiplier through, this is the
287    //    guard that stops a typo from reading as a verdict.
288    if !decode_multiplier.is_finite() || decode_multiplier <= 0.0 {
289        return Verdict::Refused(Refusal::InvalidInput {
290            detail: "the decode multiplier must be a finite number greater than zero",
291            value: decode_multiplier,
292        });
293    }
294    if !threshold.is_finite() || !(0.0..=1.0).contains(&threshold) {
295        return Verdict::Refused(Refusal::InvalidInput {
296            detail: "the go threshold must be a finite hit ratio in [0.0, 1.0]",
297            value: threshold,
298        });
299    }
300
301    // 1. An incomplete byte total cannot be priced.
302    let unavailable = summary.unavailable_partitions();
303    if unavailable > 0 {
304        return Verdict::Refused(Refusal::UnpriceableFraction {
305            fraction: summary.unavailable_fraction(),
306            partitions: unavailable,
307        });
308    }
309    // 2. Input the recorder could not seat at all. Checked early because the loss
310    //    is BIASED — see the refusal text — so it invalidates the shape, not just
311    //    the totals.
312    if summary.dropped_accesses > 0 {
313        return Verdict::Refused(Refusal::DroppedAccesses {
314            dropped: summary.dropped_accesses,
315            recorded: summary.recorded_accesses,
316        });
317    }
318    // 3. A window at the sampling floor is statistically worthless.
319    if summary.at_sampling_floor {
320        return Verdict::Refused(Refusal::SamplingFloor {
321            sample_denominator: summary.sample_denominator,
322        });
323    }
324    // 4. A SAMPLE cannot be filled against a real budget.
325    //
326    //    The budget arithmetic below compares `C / m` — real bytes — against
327    //    `B_b`, which for a downsampled window covers only the admitted 1-in-2^k
328    //    share of the distinct partitions. Pricing the full budget against a
329    //    fraction of the working set makes everything appear to fit and yields a
330    //    FALSE "go". The committed note is explicit that absolute `n_b` and `B_b`
331    //    must be scaled by `2^k` before they mean anything.
332    //
333    //    Refusing rather than scaling, deliberately: scaling by `2^k` gives an
334    //    unbiased POINT estimate of the population totals but says nothing about
335    //    its variance, and the procedure's output is a go/no-go, not an interval —
336    //    so a scaled verdict would look exactly as authoritative as a census one
337    //    while resting on an extrapolation this instrument cannot bound. The spec's
338    //    only priced scenario is a census, the bucket FRACTIONS a sample does
339    //    support are still readable off the emitted series, and a census is cheap
340    //    to obtain (shorten the window until the distinct set fits the table).
341    if !summary.is_census() {
342        return Verdict::Refused(Refusal::NonCensusSample {
343            sample_denominator: summary.sample_denominator,
344        });
345    }
346    // 5. A window below the stated minimum is not a workload.
347    let total_accesses = summary.total_accesses();
348    if total_accesses < MIN_ACCESSES {
349        return Verdict::Refused(Refusal::TooFewAccesses {
350            accesses: total_accesses,
351            minimum: MIN_ACCESSES,
352        });
353    }
354    // 6. Self-generated load is not evidence about the world.
355    if source == WindowSource::Synthetic {
356        return Verdict::Refused(Refusal::SyntheticWorkload);
357    }
358    if summary.total_bytes() == 0 {
359        return Verdict::Refused(Refusal::NoPricedBytes);
360    }
361
362    // Order buckets by ACCESS DENSITY (accesses per on-disk byte), descending: the
363    // best bytes to spend the budget on are the ones serving the most accesses.
364    let mut ordered: Vec<(RepeatBucket, f64, u64, u64, u64)> = RepeatBucket::ALL
365        .iter()
366        .filter_map(|b| {
367            let s = summary.bucket(*b);
368            // PRICED distinct partitions, whichever authoritative provenance they
369            // carry: an extent measured as a successor gap is as real as one an
370            // index handed over, and skipping it here would silently price the
371            // window at zero.
372            let priced = s.distinct_priced();
373            if s.bytes == 0 || priced == 0 {
374                return None;
375            }
376            let density = s.accesses as f64 / s.bytes as f64;
377            Some((*b, density, s.accesses, priced, s.bytes))
378        })
379        .collect();
380    ordered.sort_by(|a, b| {
381        // Descending density. `partial_cmp` cannot be `None` here (both operands
382        // are finite positives), but fall back to Equal rather than unwrapping.
383        b.1.partial_cmp(&a.1).unwrap_or(std::cmp::Ordering::Equal)
384    });
385
386    let on_disk_budget = budget_bytes as f64 / decode_multiplier;
387    let mut remaining = on_disk_budget;
388    let mut served = 0f64;
389    for (_, _, accesses, distinct, bytes) in ordered {
390        if remaining <= 0.0 {
391            break;
392        }
393        // Every selected partition's FIRST access in the window is compulsory, so a
394        // bucket of `n` partitions serving `a` accesses can hit at most `a - n`.
395        let hittable = accesses.saturating_sub(distinct) as f64;
396        let bytes_f = bytes as f64;
397        if bytes_f <= remaining {
398            served += hittable;
399            remaining -= bytes_f;
400        } else {
401            // Take the last bucket fractionally, by byte share.
402            let f = remaining / bytes_f;
403            served += f * hittable;
404            remaining = 0.0;
405        }
406    }
407
408    let h_max = served / total_accesses as f64;
409    Verdict::Priced(Ceiling {
410        budget_bytes,
411        on_disk_budget_bytes: on_disk_budget,
412        h_max,
413        clears_threshold: h_max >= threshold,
414        threshold,
415    })
416}

426    fn recorder() -> PartitionAccessRecorder {
427        PartitionAccessRecorder::new(WindowConfig {
428            duration: Duration::from_secs(86_400),
429            max_accesses: u64::MAX,
430            ..WindowConfig::default()

434    /// Build a census window with `n` partitions each accessed `times` times and
435    /// each `bytes` bytes on disk.
436    fn window(spec: &[(u64, u32, u64)]) -> WindowSummary {
437        let r = recorder();
438        let mut key = 0u64;
439        for (n, times, bytes) in spec {
440            for _ in 0..*n {
441                key += 1;
442                for _ in 0..*times {
443                    r.record(
444                        TableScope::new("ks", "t"),
445                        &key.to_le_bytes(),
446                        AccessWeight::SuccessorGap(*bytes),
447                    );
448                }
449            }
450        }
451        r.close_window().expect("window recorded accesses")
452    }

488    #[test]
489    fn an_out_of_domain_input_is_refused_rather_than_priced() {
490        // M2: every one of these produces a VERDICT if the arithmetic is allowed to
491        // run, and the first is a false GO — the failure class this whole change
492        // exists to eliminate.
493        let s = window(&[(600, 20, 1_024), (10_000, 1, 1_024)]);
494        assert!(
495            s.total_accesses() >= MIN_ACCESSES,
496            "so only the input is at issue"
497        );
498
499        // A zero multiplier makes the on-disk budget +inf: every bucket fits and the
500        // ratio is maximal, clearing any threshold.
501        for bad_multiplier in [0.0, -1.0, f64::NAN, f64::INFINITY, f64::NEG_INFINITY] {
502            match evaluate(&s, WindowSource::Field, 128 * 1024 * 1024, bad_multiplier) {
503                Verdict::Refused(Refusal::InvalidInput { value, .. }) => {
504                    assert!(
505                        value.is_nan() == bad_multiplier.is_nan()
506                            && (value.is_nan() || value == bad_multiplier),
507                        "the refusal must name the offending value"
508                    );
509                }
510                other => panic!("multiplier {bad_multiplier} must be refused: {other:?}"),
511            }
512        }
513
514        // A threshold outside [0,1] makes `clears_threshold` meaningless: <= 0 always
515        // clears, > 1 never can, NaN never compares.
516        for bad_threshold in [-0.1, 1.5, f64::NAN, f64::INFINITY] {
517            let v = evaluate_with_threshold(
518                &s,
519                WindowSource::Field,
520                128 * 1024 * 1024,
521                ASSUMED_DECODE_MULTIPLIER,
522                bad_threshold,
523            );
524            assert!(
525                matches!(v, Verdict::Refused(Refusal::InvalidInput { .. })),
526                "threshold {bad_threshold} must be refused: {v:?}"
527            );
528        }
529
530        // The BOUNDARIES are inside the domain and must still price.
531        for ok_threshold in [0.0, 1.0, RECOMMENDED_GO_THRESHOLD] {
532            let v = evaluate_with_threshold(
533                &s,
534                WindowSource::Field,
535                128 * 1024 * 1024,
536                ASSUMED_DECODE_MULTIPLIER,
537                ok_threshold,
538            );
539            assert!(
540                matches!(v, Verdict::Priced(_)),
541                "threshold {ok_threshold} is in domain and must price: {v:?}"
542            );
543        }
544        // A tiny-but-positive multiplier is in domain — unhelpful, not invalid.
545        assert!(matches!(
546            evaluate(
547                &s,
548                WindowSource::Field,
549                128 * 1024 * 1024,
550                f64::MIN_POSITIVE
551            ),
552            Verdict::Priced(_)
553        ));
554    }

589    fn a_complete_census_window_is_priced_and_the_estimate_is_hand_checkable() {
590        // 500 hot partitions × 20 accesses at 1 KiB, plus 10,000 cold partitions
591        // accessed once at 1 KiB.
592        //   A = 500*20 + 10_000 = 20_000
593        //   hot bucket (17+):  a=10_000, n=500,   B=512_000 B  → density 0.0195
594        //   cold bucket (1):   a=10_000, n=10_000,B=10_240_000 → density 0.00098
595        // On-disk budget at 128 MiB / 3.5 = 38.34 MiB, which swallows both buckets
596        // (10.75 MiB total), so served = (10_000-500) + (10_000-10_000) = 9_500
597        // and H_max = 9_500 / 20_000 = 0.475.
598        let s = window(&[(500, 20, 1_024), (10_000, 1, 1_024)]);
599        assert!(s.is_census());
600        assert_eq!(s.total_accesses(), 20_000);
601        let v = evaluate(
602            &s,
603            WindowSource::Field,
604            128 * 1024 * 1024,
605            ASSUMED_DECODE_MULTIPLIER,
606        );
607        match v {
608            Verdict::Priced(c) => {
609                assert!(
610                    (c.h_max - 0.475).abs() < 1e-9,
611                    "expected the hand-computed 0.475, got {}",
612                    c.h_max
613                );
614                assert!(!c.clears_threshold, "0.475 is below the 0.50 threshold");
615            }
616            other => panic!("expected a priced verdict, got {other:?}"),
617        }
618    }
