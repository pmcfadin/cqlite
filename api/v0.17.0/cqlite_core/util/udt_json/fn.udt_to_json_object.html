Expand description

Render udt as a JSON object holding its DECLARED FIELDS AND NOTHING ELSE.

  • Field declaration order is preserved (serde_json is built with preserve_order).
  • A field whose value is None renders as JSON null: a null-valued field is still a declared field, and the null is the user’s data.
  • udt.type_name / udt.keyspace are deliberately NOT emitted. --format json has no metadata channel, and inventing a key inside the field namespace is the defect this helper exists to remove.

render_field renders each present field value by the CALLER’s own rules.
