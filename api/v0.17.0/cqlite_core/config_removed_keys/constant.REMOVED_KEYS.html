Every cqlite_core::Config key removed by issue #1696.

§Scope

This table starts at #1696, which is where the mechanism starts: a removal PR from now on extends it, and one that forgets to is incomplete. Removals that predate the mechanism (e.g. #1619’s decorative compaction.strategy / max_sstables / size_ratio / max_threads / background_interval) are deliberately NOT listed — they were never reported and adding them now would be a separate, testable change rather than part of this one.
