pub fn estimate_arrow_row_bytes(columns: &[ColumnInfo], row: &QueryRow) -> usize
Expand description

Upper bound, in Arrow payload bytes, on row’s contribution to a batch built from columns by rows_to_record_batch.

Walks columns (never the whole row.values map — an unprojected cell never reaches the batch) and resolves each cell exactly as transpose_columns does, then charges, per Arrow slot, the slot’s structural overhead plus its value-driven content bytes.

Returns usize::MAX when the row exhausts MAX_ESTIMATE_NODES or its widths saturate — a fail-closed signal that cuts the batch.

§Example

let columns = vec![ColumnInfo {
    name: "b".into(),
    data_type: DataType::Blob,
    nullable: true,
    position: 0,
    table_name: None,
    cql_type: Some(CqlType::Blob),
}];
let row_with = |n: usize| {
    let mut values: HashMap<Arc<str>, Value> = HashMap::new();
    values.insert(Arc::from("b"), Value::Blob(vec![0u8; n].into()));
    QueryRow::with_interned_values(RowKey::new(Vec::new()), values)
};
// Width-sensitive: the estimates differ by at least the content difference.
assert!(
    estimate_arrow_row_bytes(&columns, &row_with(1024))
        - estimate_arrow_row_bytes(&columns, &row_with(16))
        >= 1024 - 16
);
