cqlite.rpc.phase.active — gauge 1 (issue #2361).

In-flight visibility of the phase a do_get is CURRENTLY executing, set to 1 on phase entry and back to 0 on exit (via super::super’s PhaseTimer transition/Drop). RPC_PHASE_DURATION only records a sample once a phase COMPLETES, so a do_get wedged forever in stream (the #2361 hang: a merge that never returns a batch) recorded NOTHING — this gauge shows stream = 1 for the entire hang, so a stall is observable BEFORE completion. Bounded attributes: attr::RPC_METHOD, attr::RPC_PHASE (the closed three-value set) — low cardinality (methods × 3 phases). NEVER a ticket/key/query value.
