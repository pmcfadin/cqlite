Delta-encoding base for IndexInfo.width field.

Each block’s actual width is stored as (actual_width - WIDTH_BASE) so that typical blocks near 64 KiB encode to a small or zero VInt value.

Source: IndexInfo.WIDTH_BASE = 64 * 1024.
