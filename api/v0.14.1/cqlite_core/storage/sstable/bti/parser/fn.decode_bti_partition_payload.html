pub fn decode_bti_partition_payload(

) -> BtiResult<BtiPartitionLocation>
Expand description

Decode the BTI partition leaf payload at payload_start inside trie_data.

§Arguments

  • trie_data – raw bytes of the trie (i.e. the file excluding the 8-byte root-offset footer).
  • payload_start – offset within trie_data where the payload begins (immediately after the 1-byte node header).
  • payload_bits – the payloadBits value from the node header’s low nibble.

§Returns

Ok(BtiPartitionLocation) on success; a parse error if payload_bits is out of the expected range or the data is too short.

§Reference

Mirrors PartitionIndex.java readPayload and Cassandra’s SizedInts.read.
