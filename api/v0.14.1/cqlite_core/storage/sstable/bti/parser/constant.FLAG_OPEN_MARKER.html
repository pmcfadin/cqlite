The FLAG_OPEN_MARKER bit in a Rows.db trie node’s payloadBits (low nibble of the header byte). When set, an open-deletion DeletionTime follows the SizedInts block offset. Mirrors RowIndexReader.FLAG_OPEN_MARKER.
