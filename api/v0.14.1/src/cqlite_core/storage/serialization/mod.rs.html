1//! Type serialization for SSTable Data.db generation
2//!
3//! Provides CQL type encoders that produce byte-correct Cassandra 5.0 format.
4//! Handles all primitive types, collections, UDTs, and edge cases.
5//!
6//! Critical encoding gotchas (from M5 Council Recommendation):
7//! - VInt encoding: Must match VIntCoding.java exactly
8//! - UDT field lengths: 4-byte big-endian i32, NOT VInt
9//! - Decimal encoding: [i32 BE scale][VInt unscaled_len][unscaled_bytes]
10//! - Duration encoding: [VInt months][VInt days][VInt nanos] (all signed)
11//! - Date encoding: Unsigned with offset for lexicographic ordering
12//!
13//! TODO: Implementation in M5.0-14 through M5.0-16
