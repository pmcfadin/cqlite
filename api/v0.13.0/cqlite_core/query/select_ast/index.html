CQL SELECT Abstract Syntax Tree.

AST types for SELECT statements executed directly against SSTable files. Covers projections, WHERE expressions, aggregates, GROUP BY/HAVING, ORDER BY, LIMIT/OFFSET, collection access, and arithmetic expressions.
