cqlite_core::observability

Module config 

Source
Expand description

Observability configuration, populated from the standard CQLITE_OTEL_* environment variables (epic #1031, issue #1032).

The config type is always compiled (it carries no OpenTelemetry types), so callers and tests can construct and inspect it whether or not the observability feature is enabled. The actual exporter wiring lives in crate::observability’s feature-gated init.
