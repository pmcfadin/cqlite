Record an error into catalog::ERRORS_TOTAL with EXTRA bounded attributes beyond the canonical {cqlite.error.category, cqlite.subsystem} pair.

Identical to record_error but appends the caller-supplied extra attributes to the same single counter increment (and still marks the active span errored with the derived category). The extra keys MUST be bounded (closed value sets), e.g. the Flight do_get abort taxonomy’s cqlite.flight.abort_reason (issue #2681) — never a raw message, ticket, or key. No-op when the observability feature is off.
