cqlite.flight.admission.limit — gauge 1 (issue #2420, WS4).

The configured do_get admission ceiling K (the --max-concurrent-scans value). A constant level while the server runs; recorded on startup so a dashboard can chart in_use against the limit. No attributes (bounded). DISTINCT from RPC_IN_FLIGHT: this is the CONFIGURED ceiling, not a live count.
