1//! Synchronous positional chunk reader for the windowed streaming scan's IO half
2//! (issue #1940 restructure).
3//!
4//! # Why this exists
5//!
6//! The windowed feed runs inside a single `spawn_blocking` task (issues #1593,
7//! #1940): both the raw chunk read AND its decompression must stay OFF the async
8//! worker pool. The former implementation drove the read with
9//! `futures::executor::block_on(read_next_block_parts(..))` — an async read over a
10//! `tokio::fs::File`. Even though it ran on a blocking thread, `tokio::fs`'s
11//! `poll_read` RE-DISPATCHES the actual `read(2)` to tokio's blocking pool, so each
12//! chunk read amplified into a second blocking-pool thread. rust-reviewer proved it
13//! bounded, but roborev flagged it as a latent hang under a small custom
14//! `max_blocking_threads`. Owner decision (issue #1940): REMOVE the hazard class —
15//! read SYNCHRONOUSLY on the `spawn_blocking` thread, with zero nested async and
16//! zero blocking-pool amplification.
17//!
18//! These helpers read via the reader's `point_source` — the positional
19//! [`ReadAt`](super::read_at::ReadAt) plane built once at open for EVERY backend
20//! (buffered = `pread` on a dedicated `std::fs::File`; mmap = a resident slice;
21//! `O_DIRECT` = an aligned positioned read). A positional read carries its offset
22//! as a parameter and touches no tokio reactor/timer, so it completes fully on the
23//! calling (blocking) thread — no `tokio::fs`, no `block_on`, no second blocking
24//! thread. `read_at.rs`'s module docs anticipated exactly this adoption ("shaped so
25//! the windowed streaming scan can adopt it later"). Decompression continues to run
26//! in `decode_scan_chunk` on the same blocking thread (the D2 substrate placement,
27//! unchanged).
28//!
29//! Byte-parity + integrity are preserved verbatim from the former cursor path:
30//! - **compressed NB** (`CompressionInfo` present): the same per-chunk record
31//!   geometry (`compressed_chunk_offset`/`compressed_chunk_size`, incl. the +4
32//!   trailing CRC), the same corrupt-offset bounds check (roborev #970), the same
33//!   degenerate empty-trailing-chunk EOF bound (issue #2225), and the same
34//!   CRC32-BEFORE-decompress order (the CRC is verified here; the payload is
35//!   returned only after it matches, so a corrupt chunk never reaches the
36//!   decompressor). The compressed read reuses the caller's per-loop scratch (≤1
37//!   alloc/chunk, D2) and records a scratch-regrowth as a copy-chain alloc so the
38//!   `issue_1940_scan_window_substrate_allocs` guard stays honest.
39//! - **uncompressed NB** (no `CompressionInfo`; CQLite's own write surface): the
40//!   data section is fed in bounded pieces, and every `CRC.db` chunk covering a
41//!   piece is verified BEFORE the piece is handed on — computing the CRC from the
42//!   resident piece bytes when a chunk is fully contained, else reading the
43//!   straddling prefix/suffix positionally (mirrors
44//!   `verify_uncompressed_section_in_buffer`). Each chunk is verified at most once
45//!   per reader lifetime via the shared `verified_uncompressed_chunks` memo.
46//!
47//! Kept in a sibling file (campsite rule, epic #1116); included via
48//! `#[path = "scan_stream_windowed_read.rs"] impl`-carrying module in the parent.

59/// Bytes handed to the parse half per uncompressed-NB read. Mirrors Cassandra's
60/// default 64 KiB compression chunk so the piece size is uniform with the
61/// compressed path; the sliding window stitches across pieces, so the boundary is
62/// invisible to the parse output. CRC verification is done on `CRC.db` chunk
63/// boundaries independently of this piece size.
64const UNCOMPRESSED_READ_PIECE_BYTES: usize = 64 * 1024;
65
66/// Wrap a positional-read failure with human-readable `context` WITHOUT
67/// discarding its [`ErrorKind`](std::io::ErrorKind) (issue #1940 BLOCKER-2).
68///
69/// The synchronous positional read path used to relabel every read failure as
70/// `std::io::Error::other(..)` (kind `Other`), which erased the source kind — so
71/// a genuine transient fault (`Interrupted`/`WouldBlock`/`TimedOut`) surfacing
72/// through the feed could no longer be recognised by [`is_transient_io`] and was
73/// silently NOT retried. Rebuilding the wrapper with the SAME kind keeps the
74/// classifier honest and lets callers up the stack still see the true io kind,
75/// mirroring `block_io::io_error_with_context`. Non-`Io` variants
76/// (corruption/format) are already typed and pass through unchanged.
77fn io_error_with_context(context: impl std::fmt::Display, source: Error) -> Error {
78    match source {
79        Error::Io(io) => {
80            let kind = io.kind();
81            Error::Io(std::io::Error::new(kind, format!("{context}: {io}")))
82        }
83        other => other,
84    }
85}

88    /// Positional `read_exact_at` that applies the SAME one-shot transient-I/O
89    /// retry the former async feed path had (issue #1588 / #1940 BLOCKER-2), and
90    /// records the read thread at the REAL read site (issue #1940 guard
91    /// integrity).
92    ///
93    /// A transient kernel fault (`Interrupted` EINTR / `WouldBlock` EAGAIN /
94    /// `TimedOut`) is retried EXACTLY once by re-reading at the SAME captured
95    /// `offset` (a positional read carries its offset as a parameter, so the retry
96    /// needs no re-seek); every other error — deterministic corruption/format, or
97    /// a non-transient io kind — fails fast. The returned error is the backend's
98    /// `Error::Io`, so its `ErrorKind` is PRESERVED for the caller to annotate via
99    /// [`io_error_with_context`] (never collapsed to `Error::other`).
100    ///
101    /// The `record_io_read_thread` probe fires HERE, at the actual
102    /// `point_source.read_exact_at` call site (not at the top of the feed closure),
103    /// so the #1940 no-nesting guard records the thread that performs the real read
104    /// — making its `io_read_thread == decode_thread` equality a true detector of a
105    /// read dispatched off the feed thread. Compiled only under `scan-offload-probe`.
106    fn positional_read_exact_retry_once(
107        &self,
108        offset: u64,
109        buf: &mut [u8],
110        scratch: &mut DirectScratch,
111    ) -> Result<()> {
112        #[cfg(feature = "scan-offload-probe")]
113        super::probe::record_io_read_thread();
114        let mut attempt = 0u8;
115        loop {
116            // `read_exact_at_reusing` reuses `scratch`'s aligned bounce buffer on
117            // the Direct-I/O backend (issue #2319 — no per-chunk aligned alloc); for
118            // mmap/plain-file backends it defers to `read_exact_at` and `scratch`
119            // stays empty, so those paths are byte-for-byte unchanged (#1940).
120            match self
121                .point_source
122                .read_exact_at_reusing(offset, buf, scratch)
123            {
124                Ok(()) => return Ok(()),
125                Err(e)
126                    if attempt == 0
127                        && crate::storage::sstable::reader::block_io::is_transient_io(&e) =>
128                {
129                    tracing::warn!(
130                        "transient I/O fault ({e}) on positional read at offset 0x{offset:x}; \
131                         re-reading once"
132                    );
133                    attempt = 1;
134                }
135                Err(e) => return Err(e),
136            }
137        }
138    }

140    /// Read compressed chunk `chunk_index` SYNCHRONOUSLY via `point_source`,
141    /// verifying its trailing CRC32 before returning the compressed payload (issue
142    /// #1940). Returns `Ok(None)` at EOF (past the last chunk, or the degenerate
143    /// empty trailing chunk, issue #2225). Mirrors `read_nb_format_chunk_data`'s
144    /// geometry + integrity checks exactly, but positional (no cursor mutex, no
145    /// `tokio::fs`) and reusing the caller's `scratch` (≤1 alloc/chunk, D2).
146    pub(super) fn read_compressed_chunk_sync(
147        &self,
148        chunk_index: usize,
149        scratch: &mut Vec<u8>,
150        direct_scratch: &mut DirectScratch,
151    ) -> Result<Option<Vec<u8>>> {
152        let comp_info = match self.compression_info.as_ref() {
153            Some(ci) => ci,
154            // Callers gate on `compression_info.is_some()`; a None here is a bug.
155            None => return Ok(None),
156        };
157        let file_size = self.point_source.len();
158
159        if chunk_index >= comp_info.chunk_offsets.len() {
160            return Ok(None); // EOF
161        }
162
163        // Degenerate empty trailing chunk (issue #2225): a chunk whose logical
164        // start is at/after `data_length` carries 0 real bytes; Cassandra's reader
165        // never touches it (every logical position < data_length maps earlier), and
166        // handing 0 bytes to a decompressor fails. Treat it (and anything beyond,
167        // chunk starts being monotonic) as EOF — identical to the cursor path.
168        let chunk_length = comp_info.chunk_length as u64;
169        if chunk_length > 0 {
170            let logical_start = (chunk_index as u64).saturating_mul(chunk_length);
171            if logical_start >= comp_info.data_length {
172                return Ok(None);
173            }
174        }
175
176        let chunk_offset = comp_info
177            .compressed_chunk_offset(chunk_index)
178            .ok_or_else(|| Error::InvalidFormat(format!("No offset for chunk {chunk_index}")))?;
179        let total_chunk_size = comp_info
180            .compressed_chunk_size(chunk_index, file_size)
181            .ok_or_else(|| {
182                Error::InvalidFormat(format!(
183                    "Cannot determine size for chunk {chunk_index} (file_size={file_size})"
184                ))
185            })?;
186        if total_chunk_size < 4 {
187            return Err(Error::InvalidFormat(format!(
188                "Chunk {chunk_index} size too small: {total_chunk_size} bytes (minimum 4 for CRC)"
189            )));
190        }
191        // Bounds-check against the real Data.db length BEFORE allocating — a corrupt
192        // CompressionInfo offset must surface as a recoverable error, never a
193        // multi-exabyte allocation (roborev #970). NB chunk offsets are absolute
194        // (header_offset = 0).
195        let chunk_end = chunk_offset.checked_add(total_chunk_size);
196        match chunk_end {
197            Some(end) if end <= file_size => {}
198            _ => {
199                return Err(Error::InvalidFormat(format!(
200                    "Chunk {chunk_index} at offset 0x{chunk_offset:x} with size {total_chunk_size} \
201                     exceeds Data.db length {file_size} — corrupt CompressionInfo.db chunk offset"
202                )));
203            }
204        }
205        let chunk_data_size = (total_chunk_size - 4) as usize;
206
207        // A5 counters (E4 SEEK_CALLS + E3 READ_CALLS): the positioned read stands in
208        // for the cursor path's per-chunk seek + read, so record one of each per
209        // chunk to keep the `reads == decompresses` substrate invariant intact.
210        rwc::record_seek();
211        rwc::record_read();
212
213        // ONE positioned read for payload + trailing CRC into the REUSED scratch
214        // (D2). Grow-on-demand to the CHECKED `total_chunk_size` for THIS chunk —
215        // never a giant upfront reserve to the metadata `max_compressed_length`
216        // (which Cassandra commonly stamps as `i32::MAX`, an OOM/DoS on ordinary
217        // files, issue #1940 BLOCKER-1). `try_reserve_exact` returns a typed error
218        // on allocation failure instead of panicking/aborting. After the first few
219        // chunks the scratch has reached the working-set high-water mark, so
220        // subsequent chunks hit neither the reserve nor the resize regrowth —
221        // preserving the ≤1-alloc/chunk STEADY STATE (the `record_chunk_path_alloc`
222        // regrowth counter proves it). `clear()`+`resize` reuses the backing store
223        // when large enough (mirrors `read_nb_format_chunk_data`).
224        let mut buf = std::mem::take(scratch);
225        buf.clear();
226        let cap_before = buf.capacity();
227        let need = total_chunk_size as usize;
228        if need > buf.capacity() {
229            if let Err(e) = buf.try_reserve_exact(need) {
230                // Return the scratch to the caller so a retry could reuse it.
231                *scratch = buf;
232                return Err(Error::memory(format!(
233                    "failed to reserve {need} bytes for chunk {chunk_index} \
234                     (data+CRC at offset 0x{chunk_offset:x}): {e}"
235                )));
236            }
237        }
238        buf.resize(need, 0u8);
239        if buf.capacity() > cap_before {
240            rwc::record_chunk_path_alloc();
241        }
242        if let Err(e) =
243            self.positional_read_exact_retry_once(chunk_offset, &mut buf, direct_scratch)
244        {
245            // Return the scratch's capacity to the caller so the next read reuses it.
246            buf.clear();
247            *scratch = buf;
248            // Preserve the source io kind (issue #1940 BLOCKER-2) — never collapse
249            // a transient fault to `Error::other`.
250            return Err(io_error_with_context(
251                format!(
252                    "Failed to read chunk {chunk_index} data+CRC ({total_chunk_size} bytes at \
253                     offset 0x{chunk_offset:x})"
254                ),
255                e,
256            ));
257        }
258
259        // Split the trailing 4-byte big-endian CRC32 off the payload and verify it
260        // BEFORE the payload is trusted (guardrail #1411): a mismatch is a typed
261        // error and the payload never reaches the decompressor.
262        let expected_crc = u32::from_be_bytes([
263            buf[chunk_data_size],
264            buf[chunk_data_size + 1],
265            buf[chunk_data_size + 2],
266            buf[chunk_data_size + 3],
267        ]);
268        buf.truncate(chunk_data_size);
269        let computed_crc = crc32fast::hash(&buf);
270        if computed_crc != expected_crc {
271            return Err(Error::InvalidFormat(format!(
272                "CRC32 mismatch for chunk {chunk_index} at offset 0x{chunk_offset:x}: \
273                 expected=0x{expected_crc:08x}, computed=0x{computed_crc:08x}, \
274                 chunk_size={chunk_data_size}"
275            )));
276        }
277        Ok(Some(buf))
278    }

280    /// Read the next bounded piece of an UNCOMPRESSED-NB data section
281    /// SYNCHRONOUSLY via `point_source`, starting at byte `pos` (an absolute
282    /// Data.db offset). Returns `Ok(None)` at EOF, else `Ok(Some((piece, next_pos)))`.
283    /// Every `CRC.db` chunk covering the piece is verified (once per reader
284    /// lifetime) BEFORE the piece is returned — from the resident bytes when a
285    /// chunk is fully contained, else by reading the straddling remainder
286    /// positionally (issue #1396; mirrors `verify_uncompressed_section_in_buffer`).
287    pub(super) fn read_uncompressed_piece_sync(
288        &self,
289        pos: u64,
290        direct_scratch: &mut DirectScratch,
291    ) -> Result<Option<(Vec<u8>, u64)>> {
292        let file_size = self.point_source.len();
293        let remaining = file_size.saturating_sub(pos);
294        if remaining == 0 {
295            return Ok(None); // EOF
296        }
297        let to_read = remaining.min(UNCOMPRESSED_READ_PIECE_BYTES as u64) as usize;
298        let mut buf = vec![0u8; to_read];
299        // Same one-shot transient-retry + kind-preserving wrap as the compressed
300        // path (issue #1940 BLOCKER-2): a transient fault is re-read once, and the
301        // source io kind is preserved (never collapsed to `Error::other`).
302        self.positional_read_exact_retry_once(pos, &mut buf, direct_scratch)
303            .map_err(|e| {
304                io_error_with_context(
305                    format!("Failed to read uncompressed piece ({to_read} bytes at 0x{pos:x})"),
306                    e,
307                )
308            })?;
309        let end = pos + to_read as u64;
310
311        // CRC verification (no-op when this reader has no CRC.db). Compute each
312        // covering chunk's CRC from the resident piece when fully contained, else
313        // read the straddling prefix/suffix positionally. `verify_covering_chunks`
314        // is synchronous and memoizes each chunk so it is checked at most once.
315        if let Some(crc) = self.crc_reader.as_deref() {
316            let piece = &buf;
317            self.verify_covering_chunks(crc, pos, end, |lo, hi, chunk| {
318                if lo >= pos && hi <= end {
319                    let s = (lo - pos) as usize;
320                    let e = (hi - pos) as usize;
321                    Ok(crc32fast::hash(&piece[s..e]))
322                } else {
323                    // A chunk straddling the piece boundary must be read off disk.
324                    // Route it through `read_exact_at_reusing` with the SAME per-scan
325                    // `direct_scratch` the main piece read uses (issue #2319), so the
326                    // Direct-I/O backend reuses the one aligned bounce buffer instead
327                    // of allocating a fresh one per straddling chunk. For mmap/plain
328                    // backends this defers to `read_exact_at` (scratch stays empty),
329                    // so those paths are unchanged.
330                    let mut cbuf = vec![0u8; (hi - lo) as usize];
331                    self.point_source
332                        .read_exact_at_reusing(lo, &mut cbuf, direct_scratch)
333                        .map_err(|e| {
334                            Error::corruption(format!(
335                                "failed to read uncompressed chunk {chunk} at Data.db offset \
336                             0x{lo:x} for CRC verification: {e}"
337                            ))
338                        })?;
339                    Ok(crc32fast::hash(&cbuf))
340                }
341            })?;
342        }
343        Ok(Some((buf, end)))
344    }

346    /// Synchronous compressed-NB feed body (issue #1940): read each compressed
347    /// chunk positionally (CRC verified in the read), decode it (D2), and ship the
348    /// decompressed `Bytes` on `raw_tx`. `Ok(())` on clean EOF or
349    /// consumer-ended-early; `Err` on a read/decode failure. Runs on the feed's
350    /// `spawn_blocking` thread — no `tokio::fs`, no `block_on`, no blocking-pool
351    /// amplification.
352    pub(super) fn feed_compressed_chunks(
353        reader: &Arc<Self>,
354        raw_tx: &mpsc::Sender<bytes::Bytes>,
355        max_compressed_length: usize,
356    ) -> Result<()> {
357        // Reused compressed-read scratch (issue #1940, D2): read fills it, decode
358        // borrows it, recycle for the next read — no per-chunk compressed alloc.
359        //
360        // Reserve ONCE to the ACTUAL working-set high-water mark — the largest
361        // real compressed-chunk RECORD size, computed from the authoritative
362        // `chunk_offsets` deltas (issue #1940 BLOCKER-1). This is NOT the metadata
363        // `max_compressed_length`: Cassandra COMMONLY stamps that field as
364        // `i32::MAX` (it equals `i32::MAX` whenever `minCompressRatio == 0`, the
365        // DEFAULT — CompressionParams.java:186-189), so a `max_compressed_length`-
366        // driven reserve would attempt a multi-GB allocation on opening an ORDINARY
367        // compressed scan (an OOM/DoS before any real chunk size is known). The
368        // offset-delta high-water mark is bounded by the real per-chunk record size
369        // (a small multiple of `chunk_length`, e.g. 16 KiB), never the file size or
370        // the i32::MAX bound. Reserving to it once means the per-chunk
371        // `clear()`+`resize` never regrows in steady state — preserving the
372        // ≤1-alloc/chunk property the `issue_1940_scan_window_substrate_allocs`
373        // guard measures (the read path's per-chunk `try_reserve_exact` remains a
374        // bounds-checked safety net that records a regrowth only if a chunk ever
375        // exceeds this mark). `try_reserve_exact` returns a typed error on
376        // allocation failure instead of aborting; a corrupt oversized delta surfaces
377        // as `Error::memory`, never a panic. Authoritative metadata, no heuristic.
378        let mut scratch: Vec<u8> = Vec::new();
379        if let Some(ci) = reader.compression_info.as_ref() {
380            let file_size = reader.point_source.len();
381            let max_record = (0..ci.chunk_offsets.len())
382                .filter_map(|i| ci.compressed_chunk_size(i, file_size))
383                .max()
384                .unwrap_or(0);
385            let want = usize::try_from(max_record).unwrap_or(usize::MAX);
386            if want > 0 {
387                scratch.try_reserve_exact(want).map_err(|e| {
388                    Error::memory(format!(
389                        "failed to reserve {want} bytes for the windowed compressed-read scratch \
390                         (largest actual chunk record): {e}"
391                    ))
392                })?;
393            }
394        }
395        // ONE reusable aligned bounce buffer for the WHOLE scan (issue #2319): the
396        // Direct-I/O backend reuses it across every chunk read instead of allocating
397        // a fresh ~chunk-sized aligned buffer per chunk (the #1940 regression). No-op
398        // (stays empty) for the mmap/plain-file backends.
399        let mut direct_scratch = DirectScratch::new();
400        let mut chunk_index = 0usize;
401        loop {
402            // SYNCHRONOUS positional read + CRC (issue #1940): CRC is verified inside
403            // the read, BEFORE the payload is trusted (guardrail #1411), exactly as
404            // the former cursor path did.
405            match reader.read_compressed_chunk_sync(
406                chunk_index,
407                &mut scratch,
408                &mut direct_scratch,
409            )? {
410                Some(compressed) => {
411                    // Decompression stays HERE, on this blocking thread (D2), off the
412                    // async reactor for every backend.
413                    let (decoded, recycled) =
414                        reader.decode_scan_chunk(chunk_index, max_compressed_length, compressed)?;
415                    scratch = recycled;
416                    chunk_index += 1;
417                    if raw_tx.blocking_send(decoded).is_err() {
418                        return Ok(()); // consumer/parse ended early
419                    }
420                }
421                None => return Ok(()), // EOF
422            }
423        }
424    }

426    /// Synchronous uncompressed-NB feed body (issue #1940): read the data section
427    /// in bounded positional pieces (each `CRC.db`-verified before it is shipped),
428    /// decode (zero-copy `Vec`→`Bytes`, no decompressor), and ship on `raw_tx`.
429    /// `Ok(())` on clean EOF or consumer-ended-early; `Err` on a read/CRC failure.
430    pub(super) fn feed_uncompressed_pieces(
431        reader: &Arc<Self>,
432        raw_tx: &mpsc::Sender<bytes::Bytes>,
433    ) -> Result<()> {
434        // ONE reusable aligned bounce buffer for the whole scan (issue #2319), same
435        // as the compressed feed; no-op for non-Direct backends.
436        let mut direct_scratch = DirectScratch::new();
437        let mut pos = reader.calculate_header_size() as u64;
438        let mut chunk_index = 0usize;
439        loop {
440            match reader.read_uncompressed_piece_sync(pos, &mut direct_scratch)? {
441                Some((piece, next_pos)) => {
442                    // No compressor: `decode_scan_chunk` moves the piece into the B1
443                    // cache zero-copy (`Bytes::from(Vec)`) — no per-piece copy — and
444                    // returns the refcounted substrate the window borrows.
445                    let (decoded, _recycled) =
446                        reader.decode_scan_chunk(chunk_index, usize::MAX, piece)?;
447                    pos = next_pos;
448                    chunk_index += 1;
449                    if raw_tx.blocking_send(decoded).is_err() {
450                        return Ok(()); // consumer/parse ended early
451                    }
452                }
453                None => return Ok(()), // EOF
454            }
455        }
456    }
