Struct SchemaBuilderVisitor

pub struct SchemaBuilderVisitor;
Expand description

Visitor that converts CQL CREATE TABLE AST to TableSchema

This visitor extracts the business logic from the existing nom parser and converts AST structures to TableSchema objects.
