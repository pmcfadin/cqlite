sampling_level written for a freshly constructed SSTable.

Cassandra stores a downsampling level between 1 and BASE_SAMPLING_LEVEL in the Summary.db header. For a new SSTable that has never been downsampled the level is always BASE_SAMPLING_LEVEL (128). It is independent of min_index_interval.
