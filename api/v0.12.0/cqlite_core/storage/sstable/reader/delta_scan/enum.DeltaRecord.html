Expand description

A single change record emitted by the delta-scan API.

Records stream in SSTable order (partition, then clustering). The scan makes no cross-SSTable decisions — no merge, no GC-grace filtering.

§Variant reference

VariantCQL operationKey scope
UpsertINSERT/UPDATE on regular columns(pk, ck)
StaticUpsertUPDATE on static columnspk
RowDeleteDELETE FROM t WHERE pk=? AND ck=?(pk, ck)
RangeDeleteDELETE FROM t WHERE pk=? AND ck>=? AND ck<?pk + bounds
PartitionDeleteDELETE FROM t WHERE pk=?pk

§Downstream merge keys

  • Upsert / RowDelete — reconcile on (partition, clustering).
  • StaticUpsert — reconcile on partition.
  • PartitionDelete / RangeDelete — apply as predicates using __ts (i.e. deleted_at) to decide last-write-wins per cell.

Variants§

§

Upsert

A row-level insert or update of regular (non-static) columns.

liveness is Some when the row was created with INSERT and carries a primary-key liveness timestamp. UPDATE statements produce rows with liveness: None.

Each element of cells is a (column_id, delta) pair. Only the columns actually written in this generation appear; absent columns are not present (they are null in the Parquet envelope).

Fields

§keys: RowKeys

Partition key + clustering columns for this row.

§liveness: Option<CellMeta>

Row liveness info, present only for INSERT operations.

§cells: Vec<(ColumnId, CellDelta)>

Per-column cell deltas for non-static columns modified in this row.

§

StaticUpsert

An update of one or more static columns for a partition.

Static columns belong to the partition, not individual rows. The clustering key is empty in partition_key.

Fields

§partition_key: RowKeys

Partition key (no clustering columns).

§cells: Vec<(ColumnId, CellDelta)>

Per-column cell deltas for static columns modified.

§

RowDelete

A row-level tombstone (DELETE FROM t WHERE pk=? AND ck=?).

Fields

§keys: RowKeys

Partition key + clustering columns identifying the deleted row.

§deleted_at: i64

Deletion timestamp in microseconds since the Unix epoch (markedForDeleteAt in Cassandra internals).

§

RangeDelete

A range tombstone covering a contiguous clustering-key range within a single partition.

start and end may be prefix bounds (see RangeBound).

DELETE FROM t WHERE pk=1 AND ck >= 'a' AND ck < 'm'

Fields

§partition_key: RowKeys

Partition key (no clustering columns — bounds carry the range).

§start: RangeBound

Inclusive or exclusive lower clustering-key bound.

§end: RangeBound

Inclusive or exclusive upper clustering-key bound.

§deleted_at: i64

Deletion timestamp in microseconds since the Unix epoch.

§

PartitionDelete

A partition-level tombstone (DELETE FROM t WHERE pk=?).

Supersedes every row and cell in the partition whose writetime is older than deleted_at.

Fields

§partition_key: RowKeys

Partition key (no clustering columns).

§deleted_at: i64

Deletion timestamp in microseconds since the Unix epoch.
