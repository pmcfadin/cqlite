pub fn warning_for_json(source: &str, content: &str) -> Option<String>
Expand description

The deprecation warning a JSON Config document should produce, or None when it names no removed key (or is not parseable JSON at all).

Unparseable content yields None rather than an error: this scan must never be the thing that rejects a document. crate::Config::from_json_str owns the real parse and the real error, and only reaches this once that parse SUCCEEDED.
