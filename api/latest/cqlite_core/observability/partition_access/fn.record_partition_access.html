Record one LOGICAL partition access on the process-global recorder.

A no-op — one relaxed atomic load, no allocation, no emission — when the probe is disabled, which is the default.

Call this ONCE per logical partition read, never once per per-SSTable probe: with size-tiered compaction a live partition is present in several generations at once, so per-probe counting would multiply every partition’s repeat count by the generation count, shift the whole histogram right and manufacture concentration the workload does not have — a bias toward “build the cache”.
