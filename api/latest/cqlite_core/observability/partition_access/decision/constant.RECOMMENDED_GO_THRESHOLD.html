The recommended go threshold on H_max(128 MiB).

An OWNER-SETTABLE parameter, recorded as such, not a derived constant. Its arithmetic: a decoded-partition cache targets decode/merge work, and the Arm-1 CPU decomposition (#2818) measured k-way merge at 3.2% of on-CPU against LZ4 decompress + CRC at ~23%. A cache whose ESTIMATED hit ratio is below 50% on a ≤~3% work share cannot move the end-to-end number by more than ~1.5%, which is under the round harness’s noise floor. Naming a default with its arithmetic is what stops the first person to run the procedure from re-litigating it.
