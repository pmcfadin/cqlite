evaluate with an explicit go threshold — the threshold is the owner’s parameter, so it is an argument rather than a constant baked into the answer.

decode_multiplier must be finite and > 0; threshold must be finite and in [0.0, 1.0]. Anything else is Refusal::InvalidInput — see that variant for why these are refused rather than computed.
