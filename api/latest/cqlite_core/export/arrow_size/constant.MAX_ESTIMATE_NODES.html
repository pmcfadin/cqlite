Constant MAX_ESTIMATE_NODES

pub const MAX_ESTIMATE_NODES: usize = 65_536;
Expand description

Maximum number of branching slots one COLUMN’s estimate may queue — a slot that can fan out into further slots (a collection, a map, a struct, or a rendered container).

Leaf slots do not count against it (they never enter the worklist — see MAX_ESTIMATE_LEAF_SLOTS), so this bounds the value’s structure: nesting depth and container-of-container fan-out, neither of which a legitimate Cassandra schema drives anywhere near 65,536. A column exceeding it fails closed to usize::MAX (cut the batch) instead of spending unbounded time, and because only branching slots are queued the worklist itself can never exceed this many entries.

Reset per column (issue #2825 review C2): one wide column can no longer starve the columns after it.
