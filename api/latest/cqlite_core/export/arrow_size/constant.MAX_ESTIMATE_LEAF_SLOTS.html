Expand description

Maximum number of leaf slots one COLUMN’s estimate may charge inline.

A leaf costs no worklist entry, so this is purely a linear-work bound: it exists so a Value tree far larger than any decoded Cassandra row still terminates in bounded time. Sized ~8× above the largest legal single cell (Cassandra’s classic 65,535-element collection limit is 131,070 leaf slots for a map), so the shapes review C2 called out — one near-limit collection, or several thousand-element collections per row — are estimated exactly rather than failing closed.
