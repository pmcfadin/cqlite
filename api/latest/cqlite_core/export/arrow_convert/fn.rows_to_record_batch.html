pub fn rows_to_record_batch(
    columns: &[ColumnInfo],
    rows: &[QueryRow],
) -> Result<RecordBatch, ArrowConvertError>
Expand description

Convert a slice of QueryRow values to an Arrow [RecordBatch].

The schema is derived from columns via build_arrow_schema. Each column is converted to an Arrow array using the same type mapping.

§Errors

Returns ArrowConvertError if any value cannot be represented in the target Arrow type, or if the Arrow schema/array construction fails.
