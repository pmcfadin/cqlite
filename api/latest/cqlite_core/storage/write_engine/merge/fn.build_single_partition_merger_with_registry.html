Like build_single_partition_merger, but threads an authoritative UdtRegistry onto every candidate reader (issue #2349) so a frozen<UDT> cell inside a collection decodes structurally instead of as opaque bytes — the cold point-read analogue of the full-scan KWayMerger::new_with_gc_and_registry_cancellable. Passing None is byte-identical to the registry-free path. Used by the Flight point-read route so point and full-scan reads never diverge (issue #1918 differential lane).
