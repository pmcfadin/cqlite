cqlite_core::storage::sstable::statistics_reader

Module integrity 

Source
Expand description

The strict Statistics.db layout + checksum check, shared by every reader (#4612).

StatisticsReader used to parse whatever it could from a damaged file, and the merge then silently re-ordered columns and re-based every write timestamp onto the wrong EncodingStats baseline. Every in-scope consumer now reads the file through this module, so a truncated or corrupt Statistics.db is a named Error::Corruption carrying the path, never a degraded open. The layout check is a port of Cassandra’s own integrity rules:

cassandra-5.0.8 io/sstable/metadata/MetadataSerializer.java:146-212 (deserialize): [i32 count][crc32], then count x [i32 type][i32 offset] followed by a crc32 over the count and every pair, then each component’s bytes followed by a crc32 of those bytes; a component’s length is the next offset minus its own (the last one runs to end of file). Every checksum mismatch is a CorruptSSTableException (:214-227). hasMetadataChecksum() is true for every in-scope format (BIG na+ at format/big/BigFormat.java:404; BTI da at format/bti/BtiFormat.java:349-352).

Constants§

MAX_STATISTICS_BYTES
The most bytes read from one Statistics.db. A real file is a few KiB (a TOC, a handful of histograms and the serialization header); the cap only bounds a hostile or runaway file so the read can never be unbounded (#4613 item 5). A file larger than this is refused, never truncated to fit.

Functions§

read_bounded_statistics
Read path under MAX_STATISTICS_BYTES + 1 bytes (the extra byte lets [checked] tell an oversize file from one exactly at the cap) with no integrity check, for callers that apply their own classification (verify).
read_checked_statistics
Read path under MAX_STATISTICS_BYTES and refuse it unless it passes the strict layout and checksum check. A missing or unreadable file is an Error::Io; a damaged one is an Error::Corruption naming path.
read_checked_statistics_async
read_checked_statistics for async callers.
require_checked_statistics
Refuse the whole input set unless every PRESENT generation’s Statistics.db passes the strict check (a missing one is left to its existing handling). For the entry points whose downstream helpers (baseline seeding, schema normalization) must never run on a degraded read. The error names the failing path.
