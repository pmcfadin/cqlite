pub fn data_db_checksum_full_reads() -> u64
Expand description

Number of full Data.db re-reads performed for checksum computation since the last reset (Issue #1663).

The streaming write path accumulates the whole-file digest and the per-chunk CRC.db values as it writes, so a non-empty SSTableWriter::finish() must leave this at 0. A regression that reintroduces the finish-time double re-read (one for Digest.crc32, one for CRC.db) bumps it to 2, failing the issue-#1663 work guard.
