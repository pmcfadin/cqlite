Cassandra 5 ‘oa’ format row/cell state machine

This module implements a spec-accurate state machine for parsing Cassandra 5+ SSTable row and cell data according to the exact binary format specification.

State machine flow: HEADER → PARTITION_KEY → DELETION_INFO → STATIC_ROW → CLUSTERING_ROWS → COLUMN_DATA

Each state validates input and transitions appropriately using proper VInt decoding and handles optional components like deletion info, static rows, and TTL information.
