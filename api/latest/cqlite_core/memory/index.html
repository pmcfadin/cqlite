Memory management for CQLite.

Issue #1568 (Epic B / B2) deleted the dead MemoryManager cache core — the LRU block cache, the row cache, and the buffer pool that no read path used — now that B1 (#1567) ships the real DecompressedChunkCache. What remains is the semver-frozen public stats shell: MemoryManager::stats and MemoryStats, reachable through Database::stats().memory_stats. Its block-cache numbers are now sourced from the live B1 cache (real hits/misses/occupancy) instead of the deleted always-zero counters, so a repeated cached read yields a non-zero MemoryStats::block_cache_hit_rate rather than a structural 0.0.
