cqlite_core::cql

Module ast 

Source
Expand description

Abstract Syntax Tree definitions for CQL statements

This module defines the AST node types that represent parsed CQL statements. The AST is designed to be parser-agnostic and provides a unified representation that can be generated by different parser backends (nom, ANTLR, etc.).
