1//! Vortex export writer for QueryResult (feature = "vortex", issue #4237)
2//!
3//! Converts CQL query results to the [Vortex](https://github.com/spiraldb/vortex) columnar file
4//! format, as a second export target sibling to [`super::parquet`]. Vortex is an **export
5//! target only** in this slice (owner ruling, 2026-09-18) — reading `.vortex` files is a later
6//! slice, out of scope here.
7//!
8//! This module is compiled only when the `vortex` cargo feature is enabled (off by default,
9//! mirroring `parquet`). The Vortex crate is pinned EXACT (`=0.86.1` at the workspace level):
10//! the on-disk format has been stable since 0.36, but the crate API is not, so a version bump is
11//! always a deliberate, reviewed edit.
12//!
13//! # One shared CQL → Arrow mapping (design.md D1)
14//!
15//! This writer introduces **no second CQL → Arrow mapping**. It consumes the exact same
16//! [`rows_to_record_batch_with_schema`](super::arrow_convert::rows_to_record_batch_with_schema)
17//! producer the streaming Parquet writer ([`super::parquet::StreamingParquetWriter`]) uses, then
18//! converts each resulting Arrow `RecordBatch` to a Vortex array through Vortex's own official
19//! Arrow-extension importer (`VortexSession::arrow().from_arrow_array`, called once per column so
20//! a conversion failure can be attributed to a specific column — see [`VortexExportError`]). That
21//! importer is the path that recognizes the `arrow.uuid` extension metadata CQLite's Arrow schema
22//! already carries for `uuid`/`timeuuid` columns (`super::arrow_schema`), so UUID identity survives
23//! the format boundary without any Vortex-specific type-mapping code in this module.
24//!
25//! # Streaming shape
26//!
27//! [`StreamingVortexWriter`] mirrors [`super::parquet::StreamingParquetWriter`]'s
28//! create → repeated `write_chunk` → `finalize` shape, with one difference: Vortex's writer API
29//! (`vortex::file::Writer`) is natively async (push-based over a bounded channel, backed by
30//! `tokio::fs::File`), so these methods are `async fn` rather than synchronous — the CLI export
31//! loop already runs inside an async context (`cqlite-cli/src/commands/export.rs`), so this is a
32//! direct `.await` at each call site, not a new async boundary. One Arrow batch is converted and
33//! pushed at a time; nothing accumulates the whole file (or the whole input) in memory.
34//!
35//! # Fail-closed (R4)
36//!
37//! The writer atomically creates a unique hidden `.<name>.<pid>.<n>.<t>.tmp` sibling of the destination (`create_new`; never a predictable name) and only `rename`s it to the real
38//! path on a fully successful `finalize()`. Any error during conversion, the push itself, or
39//! `finish()` removes the temp file (best-effort) before propagating; a [`Drop`] impl covers the
40//! remaining case — an error from OUTSIDE this writer's own methods (e.g. the caller's chunk-pull
41//! deadline) that unwinds past it without ever calling `finalize`. So the destination path never
42//! holds a partial file, even if the writer is abandoned or the PROCESS is killed between chunks.
43//! (This is process-kill safety, not power-loss durability: there is no `fsync` before the
44//! rename, so an OS/power failure mid-write is a separate, unaddressed concern.)
45

65/// Errors produced by the Vortex export writer.
66///
67/// A dedicated `thiserror` enum (mirroring [`super::parquet::ParquetExportError`]) so the writer
68/// does not depend on the CLI's `OutputError`. The CLI maps these to its own error type at the
69/// boundary.
70#[derive(Debug, Error)]
71pub enum VortexExportError {
72    /// Underlying I/O failure (opening the temp file, or renaming it into place).
73    #[error("I/O error: {0}")]
74    Io(#[from] std::io::Error),
75    /// Arrow array or schema construction failure (the CQL → Arrow half).
76    #[error("Arrow error: {0}")]
77    Arrow(#[from] arrow::error::ArrowError),
78    /// A Vortex error not attributable to a specific batch/column (e.g. writer setup).
79    #[error("Vortex error: {0}")]
80    Vortex(#[from] vortex::error::VortexError),
81    /// A value could not be represented in the target Arrow type.
82    #[error("{0}")]
83    InvalidValue(String),
84    /// Invalid writer configuration (e.g. zero row group size).
85    #[error("invalid Vortex export options: {0}")]
86    InvalidOptions(String),
87    /// The writer hit a terminal failure earlier (its temp file is already removed); every
88    /// later `write_chunk`/`finalize` returns this instead of touching a closed writer.
89    #[error("Vortex writer is poisoned by an earlier failure; the export was abandoned")]
90    Poisoned,
91    /// A conversion or write failure attributed to one batch and one column (R4 — fail closed,
92    /// naming the batch index and column so the operator can find the offending row shape).
93    #[error("Vortex export failed at batch {batch_index} (column: {column}): {message}")]
94    BatchConversion {
95        /// Zero-based index of the batch (`write_chunk`/`finalize` flush) that failed.
96        batch_index: usize,
97        /// The column name responsible, or a `<...>` placeholder naming the failing PHASE
98        /// (row→Arrow conversion, Arrow→Vortex struct assembly, or the Vortex writer push)
99        /// when the failure is not attributable to one column.
100        column: String,
101        /// The underlying error's message.
102        message: String,
103    },
104}
105
106impl From<ArrowConvertError> for VortexExportError {
107    fn from(e: ArrowConvertError) -> Self {
108        match e {
109            ArrowConvertError::Arrow(a) => VortexExportError::Arrow(a),
110            other => VortexExportError::InvalidValue(other.to_string()),
111        }
112    }
113}

135/// Convert one Arrow `RecordBatch` to a Vortex struct array, column by column, through Vortex's
136/// official Arrow-extension importer.
137///
138/// Column-by-column (rather than the single-call `ArrowSession::from_arrow_record_batch`
139/// convenience wrapper this function is otherwise equivalent to) so a failure can be attributed
140/// to a specific column name for [`VortexExportError::BatchConversion`] (R4). This is the path
141/// that recognizes `arrow.uuid` extension metadata, exactly as
142/// `ArrowSession::from_arrow_record_batch` does internally.
143fn convert_batch_to_vortex(
144    session: &VortexSession,
145    schema: &ArrowSchema,
146    batch: &RecordBatch,
147    batch_index: usize,
148) -> Result<VortexArrayRef, VortexExportError> {
149    let arrow_session = session.arrow();
150    let fields = schema.fields();
151    let mut names = Vec::with_capacity(fields.len());
152    let mut columns = Vec::with_capacity(fields.len());
153    for (col, field) in batch.columns().iter().zip(fields.iter()) {
154        let converted = arrow_session
155            .from_arrow_array(ArrowArrayRef::clone(col), field.as_ref())
156            .map_err(|e| VortexExportError::BatchConversion {
157                batch_index,
158                column: field.name().clone(),
159                message: e.to_string(),
160            })?;
161        names.push(FieldName::from(field.name().as_str()));
162        columns.push(converted);
163    }
164    let array = StructArray::try_new(
165        FieldNames::from_iter(names),
166        columns,
167        batch.num_rows(),
168        Validity::NonNullable,
169    )
170    .map_err(|e| VortexExportError::BatchConversion {
171        batch_index,
172        column: "<struct-assembly>".to_string(),
173        message: e.to_string(),
174    })?
175    .into_array();
176    Ok(array)
177}

179/// Atomically create a UNIQUE same-directory temp file for `path` (fail-closed, R4).
180///
181/// A predictable `<path>.tmp` opened with a truncating create lets concurrent exports clobber
182/// each other and lets a pre-existing symlink at that name truncate an unrelated file. Here
183/// the name carries the pid, a process-wide counter and a timestamp, and the file is opened
184/// with `create_new` (`O_CREAT|O_EXCL`, which refuses an existing entry INCLUDING a symlink),
185/// retrying with a fresh name on `AlreadyExists`. The returned path is the exact file that is
186/// later renamed into place or removed.
187fn create_unique_tmp(path: &Path) -> std::io::Result<(std::fs::File, PathBuf)> {
188    use std::sync::atomic::{AtomicU64, Ordering};
189    static COUNTER: AtomicU64 = AtomicU64::new(0);
190    let dir = path.parent().filter(|d| !d.as_os_str().is_empty());
191    let name = path.file_name().unwrap_or_default().to_string_lossy();
192    for _ in 0..32 {
193        let nanos = std::time::SystemTime::now()
194            .duration_since(std::time::UNIX_EPOCH)
195            .map(|d| d.subsec_nanos())
196            .unwrap_or(0);
197        let tmp_name = format!(
198            ".{name}.{}.{}.{nanos:x}.tmp",
199            std::process::id(),
200            COUNTER.fetch_add(1, Ordering::Relaxed)
201        );
202        let tmp = dir.map_or_else(|| PathBuf::from(&tmp_name), |d| d.join(&tmp_name));
203        match std::fs::OpenOptions::new()
204            .write(true)
205            .create_new(true)
206            .open(&tmp)
207        {
208            Ok(f) => return Ok((f, tmp)),
209            Err(e) if e.kind() == std::io::ErrorKind::AlreadyExists => continue,
210            Err(e) => return Err(e),
211        }
212    }
213    Err(std::io::Error::new(
214        std::io::ErrorKind::AlreadyExists,
215        "could not create a unique Vortex temp file after 32 attempts",
216    ))
217}

219/// A streaming Vortex writer over query results, mirroring
220/// [`super::parquet::StreamingParquetWriter`]'s create → `write_chunk` → `finalize` shape.
221///
222/// ```no_run
223/// # async fn example() -> Result<(), Box<dyn std::error::Error>> {
224/// use cqlite_core::export::vortex::{StreamingVortexWriter, VortexExportOptions};
225/// # use cqlite_core::query::QueryMetadata;
226/// # let metadata = QueryMetadata::default();
227/// # let result_iterator: Vec<Vec<cqlite_core::query::QueryRow>> = vec![];
228/// let mut writer = StreamingVortexWriter::create(
229///     "/tmp/results.vortex",
230///     &metadata,
231///     &VortexExportOptions::default(),
232/// )
233/// .await?;
234///
235/// for chunk in result_iterator {
236///     writer.write_chunk(&chunk).await?;
237/// }
238///
239/// writer.finalize().await?;
240/// # Ok(())
241/// # }
242/// ```
243pub struct StreamingVortexWriter {
244    session: VortexSession,
245    schema: Arc<ArrowSchema>,
246    columns: Vec<ColumnInfo>,
247    /// `None` after `finalize` (or after an error has already cleaned up the temp file).
248    writer: Option<vortex::file::Writer<'static>>,
249    /// The temp file this writer still OWNS; `None` once it was renamed into place or
250    /// removed, so `Drop` never unlinks a path another process may since have created.
251    tmp_path: Option<PathBuf>,
252    final_path: PathBuf,
253    row_buffer: Vec<QueryRow>,
254    row_group_size: usize,
255    rows_written: u64,
256    batches_pushed: usize,
257    /// Set on the first terminal failure; later calls return [`VortexExportError::Poisoned`].
258    poisoned: bool,
259}
260
261impl StreamingVortexWriter {
262    /// Create a streaming Vortex writer over the destination path.
263    ///
264    /// The Arrow schema is built from `metadata.columns` using the same
265    /// [`build_arrow_schema`](super::arrow_convert::build_arrow_schema) helper the streaming
266    /// Parquet writer uses. Opens a `<path>.tmp` sibling immediately; nothing is ever written to
267    /// `path` itself until [`finalize`](Self::finalize) succeeds.
268    ///
269    /// # Panics
270    ///
271    /// Must be called from inside a Tokio runtime — it uses `tokio::fs::File` and Vortex's own
272    /// writer looks up the ambient Tokio handle internally. Calling it outside one panics.
273    ///
274    /// # `!Send`
275    ///
276    /// The returned `StreamingVortexWriter` is `!Send` (it holds a `vortex::file::Writer`, whose
277    /// background layout task is driven inline rather than via `tokio::spawn`). It can be `await`ed
278    /// freely within a single task, but cannot be sent to another task or held across a `tokio::spawn`
279    /// boundary.
280    ///
281    /// # Errors
282    ///
283    /// Returns [`VortexExportError::InvalidOptions`] if `options.row_group_size` is zero, or an
284    /// I/O/Arrow/Vortex error if the schema cannot be built, the temp file cannot be opened, or
285    /// the Vortex writer cannot be initialized.
286    pub async fn create(
287        path: impl AsRef<Path>,
288        metadata: &QueryMetadata,
289        options: &VortexExportOptions,
290    ) -> Result<Self, VortexExportError> {
291        if options.row_group_size == 0 {
292            return Err(VortexExportError::InvalidOptions(
293                "row_group_size must be greater than 0".to_string(),
294            ));
295        }
296
297        let schema = Arc::new(super::arrow_convert::build_arrow_schema(&metadata.columns)?);
298        let session = VortexSession::default();
299        let dtype = session
300            .arrow()
301            .from_arrow_schema(schema.as_ref())
302            .map_err(VortexExportError::from)?;
303
304        let final_path = path.as_ref().to_path_buf();
305        let (std_file, tmp_path) = create_unique_tmp(&final_path)?;
306        let file = tokio::fs::File::from_std(std_file);
307        let writer = session.write_options().writer(file, dtype);
308
309        Ok(Self {
310            session,
311            schema,
312            columns: metadata.columns.clone(),
313            writer: Some(writer),
314            tmp_path: Some(tmp_path),
315            final_path,
316            row_buffer: Vec::with_capacity(options.row_group_size),
317            row_group_size: options.row_group_size,
318            rows_written: 0,
319            batches_pushed: 0,
320            poisoned: false,
321        })
322    }
323
324    /// Buffer rows and push complete chunks.
325    ///
326    /// Returns the number of rows pushed to the writer in this call (rows remaining in the
327    /// buffer are pushed by [`finalize`](Self::finalize)).
328    pub async fn write_chunk(&mut self, rows: &[QueryRow]) -> Result<usize, VortexExportError> {
329        if self.poisoned {
330            return Err(VortexExportError::Poisoned);
331        }
332        // After `finalize` the writer is gone: rows accepted now could never reach the file,
333        // so refuse them before buffering or counting (no silent loss).
334        if self.writer.is_none() {
335            return Err(VortexExportError::InvalidOptions(
336                "writer already finalized - cannot write more rows".to_string(),
337            ));
338        }
339        self.row_buffer.extend(rows.iter().cloned());
340        self.rows_written += rows.len() as u64;
341
342        let mut pushed = 0;
343        while self.row_buffer.len() >= self.row_group_size {
344            let chunk: Vec<QueryRow> = self.row_buffer.drain(..self.row_group_size).collect();
345            if let Err(e) = self.push_batch(&chunk).await {
346                self.abandon().await;
347                return Err(e);
348            }
349            pushed += self.row_group_size;
350        }
351
352        Ok(pushed)
353    }
354
355    /// Push any buffered rows, finish the Vortex file, and rename the temp file into place.
356    ///
357    /// Must be called exactly once after all chunks are written; dropping the writer without
358    /// calling `finalize` leaves only the `.tmp` sibling on disk, never a file at the destination
359    /// path (R4 — fail closed).
360    pub async fn finalize(&mut self) -> Result<(), VortexExportError> {
361        if self.poisoned {
362            return Err(VortexExportError::Poisoned);
363        }
364        if !self.row_buffer.is_empty() {
365            let remaining = std::mem::take(&mut self.row_buffer);
366            if let Err(e) = self.push_batch(&remaining).await {
367                self.abandon().await;
368                return Err(e);
369            }
370        }
371
372        let writer = match self.writer.take() {
373            Some(w) => w,
374            None => {
375                return Err(VortexExportError::InvalidOptions(
376                    "writer already finalized - cannot finalize twice".to_string(),
377                ))
378            }
379        };
380
381        if let Err(e) = writer.finish().await {
382            self.abandon().await;
383            return Err(VortexExportError::Vortex(e));
384        }
385
386        // `tokio::fs::rename` is `std::fs::rename` on a blocking thread, which REPLACES an existing
387        // destination on every platform (Unix `rename(2)`; Windows `MoveFileExW` with
388        // `MOVEFILE_REPLACE_EXISTING`, per the std docs). Pinned by
389        // `export_replaces_a_preexisting_destination`.
390        //
391        // Write-error audit (roborev r2): `finish()` awaits vortex's `write.flush()` (vortex-file
392        // `writer.rs`), and tokio's `File::flush` surfaces a failed in-flight write — so an I/O
393        // error such as ENOSPC fails the export HERE. This writer never calls `sync_all` or relies
394        // on drop to report errors (the paths where tokio parks the error), and the file handle
395        // is owned by vortex's writer, so no other terminal path exists. Pinned on Linux by
396        // `write_error_on_dev_full_fails_finish`.
397        let Some(tmp_path) = self.tmp_path.clone() else {
398            return Err(VortexExportError::Poisoned);
399        };
400        if let Err(e) = tokio::fs::rename(&tmp_path, &self.final_path).await {
401            self.abandon().await;
402            return Err(e.into());
403        }
404        self.tmp_path = None;
405        Ok(())
406    }
407
408    /// Total number of rows accepted by `write_chunk` so far.
409    pub fn rows_written(&self) -> u64 {
410        self.rows_written
411    }
412
413    /// Convert a slice of rows to a RecordBatch (the shared producer, D1) and push it as one
414    /// Vortex array chunk.
415    async fn push_batch(&mut self, rows: &[QueryRow]) -> Result<(), VortexExportError> {
416        let batch_index = self.batches_pushed;
417
418        let batch = rows_to_record_batch_with_schema_attributed(
419            Arc::clone(&self.schema),
420            &self.columns,
421            rows,
422        )
423        .map_err(|(column, e)| VortexExportError::BatchConversion {
424            batch_index,
425            // The offending column where the builder knows it; else the failing phase.
426            column: column.unwrap_or_else(|| "<row-to-arrow-conversion>".to_string()),
427            message: e.to_string(),
428        })?;
429
430        let array = convert_batch_to_vortex(&self.session, &self.schema, &batch, batch_index)?;
431
432        let writer = self.writer.as_mut().ok_or_else(|| {
433            VortexExportError::InvalidOptions(
434                "writer already finalized - cannot write more rows".to_string(),
435            )
436        })?;
437
438        writer
439            .push(array)
440            .await
441            .map_err(|e| VortexExportError::BatchConversion {
442                batch_index,
443                column: "<vortex-writer-push>".to_string(),
444                message: e.to_string(),
445            })?;
446
447        self.batches_pushed += 1;
448        Ok(())
449    }
450
451    /// Terminal-failure path: DROP the writer (closing its open temp file) BEFORE unlinking
452    /// the temp, then poison. Never propagates its own error — the ORIGINAL failure is what
453    /// the caller needs to see.
454    async fn abandon(&mut self) {
455        drop(self.writer.take());
456        if let Some(tmp_path) = self.tmp_path.take() {
457            let _ = tokio::fs::remove_file(&tmp_path).await;
458        }
459        self.poisoned = true;
460    }
461}

463/// Fail-closed cleanup for every path `write_chunk`/`finalize`'s own `abandon` calls above
464/// do NOT cover (review finding, R4): an error from the CALLER's side of `write_chunk` — e.g.
465/// `collect_chunk_within`'s deadline/query-timeout path in `cqlite-cli/src/commands/export.rs`
466/// — propagates via `?` straight past this writer with no chance to run its own async cleanup.
467/// Without this, R4's "leaves no readable `.vortex` file at the destination path" claim held
468/// only for errors the writer's OWN methods observed, not for one that unwound through it.
469///
470/// Ensures the (possibly still-open) `vortex::file::Writer` is dropped BEFORE the temp file is
471/// unlinked — required on Windows (an open file cannot be deleted there), a no-op on POSIX.
472/// Dropping an in-progress `Writer` aborts its background layout task cleanly (it is a `Send`
473/// task spawned on the session's Tokio handle, not orphaned work) rather than deadlocking.
474///
475/// After a SUCCESSFUL `finalize()` the temp file no longer exists (renamed to `final_path`), so
476/// this `remove_file` call is a harmless not-found; it is the cleanup path ONLY when `finalize`
477/// never ran to completion.
478impl Drop for StreamingVortexWriter {
479    fn drop(&mut self) {
480        drop(self.writer.take());
481        if let Some(tmp_path) = self.tmp_path.take() {
482            let _ = std::fs::remove_file(&tmp_path);
483        }
484    }
485}
