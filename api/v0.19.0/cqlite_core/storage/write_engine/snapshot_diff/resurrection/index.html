The resurrection-risk predicates (issue #4201, spec R4 / R4A / R5).

Every rule here is derived from Cassandra at the pinned cassandra-5.0.8 tag (git show cassandra-5.0.8:<path>), never from CQLite’s own behaviour (#3041):

  • Shadow rule — a cell is deleted by a tombstone iff timestamp <= markedForDeleteAt: src/java/org/apache/cassandra/db/DeletionTime.java:173-175 (deletes(long timestamp) { return timestamp <= markedForDeleteAt(); }). A tombstone that ties a live cell’s timestamp therefore wins, exactly as cell-vs-cell reconciliation does at src/java/org/apache/cassandra/db/rows/Cells.java:92-98 (“Tombstones always win reconciliation with live cells of the same timstamp”).
  • Purge boundary — gcBefore = nowInSec - gc_grace_seconds (src/java/org/apache/cassandra/db/ColumnFamilyStore.java:1967-1970), and a tombstone is purgeable iff localDeletionTime < gcBefore, a STRICT < (src/java/org/apache/cassandra/db/partitions/PurgeFunction.java:41-42).
  • Range span — a clustering is inside a slice iff start <= clustering <= end (src/java/org/apache/cassandra/db/Slice.java:181-184), where an inclusive start bound sorts before the clusterings it names, an exclusive start bound after them, an inclusive end bound after them and an exclusive end bound before them (src/java/org/apache/cassandra/db/ClusteringPrefix.java:70-79, comparedToClustering).

The scopes a tombstone covers follow the trace’s own TombstoneKind: a partition tombstone covers every cell of the partition (static included), a row tombstone the cells of its clustering, a cell tombstone exactly its (clustering, column), a collection tombstone the elements of its (clustering, column), and a range tombstone the cells of every clustering inside its span.

Declared gap: a row’s liveness marker (the INSERT primary-key timestamp) is not a cell in the reconciliation trail, so a row that holds ONLY a liveness marker (no cells) is invisible to the shadow check; a tombstone whose only victim is such a row reports resurrection_risk: no.
