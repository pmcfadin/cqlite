# Code of Conduct

## Our Pledge

CQLite is developed in the open and embodies the values of the Apache Cassandra
community. We are committed to providing a friendly, safe, and welcoming
environment for everyone, regardless of background or identity.

## Our Standard

This project adopts the **[Contributor Covenant, version 2.1][covenant]** as its
Code of Conduct. Please read the full text before participating:

- Contributor Covenant v2.1: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: be respectful, assume good faith, welcome newcomers, and focus on what
is best for the community. Harassment and exclusionary behavior of any kind are
not tolerated.

## Scope

This Code of Conduct applies within all project spaces — the GitHub repository
(issues, pull requests, discussions), and any public space when an individual is
representing the project.

## Reporting

If you experience or witness unacceptable behavior, report it privately to the
project maintainer:

- **Email**: pmcfadin@gmail.com

All reports will be reviewed and investigated promptly and fairly. The
maintainer is obligated to respect the privacy and security of the reporter of
any incident.

## Enforcement

Project maintainers are responsible for clarifying and enforcing these standards
and may take appropriate corrective action — including removing comments,
commits, code, and contributions, or temporarily/permanently banning a
contributor — in response to behavior they deem inappropriate, threatening,
offensive, or harmful. The enforcement guidelines in the Contributor Covenant
v2.1 (Correction → Warning → Temporary Ban → Permanent Ban) are followed.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
