These four points (`s2-n16`, `s3-n16`, `s4-n32`, `s5-n32`) come from an extension
run that was **killed** and they **MUST NOT enter the C(S) table** or be quoted
as results. Two independent disqualifications, either sufficient:

1. **One rep each.** AC1 requires medians of >= 3. A single rep carries no
   dispersion, and this rig's spread at these N values is 0.5-3.4%.
2. **No contemporaneous incumbent.** They were measured 1-2 h after the main
   grid, in a session with a measured directional round-over-round drift. The
   bracketing question is *"is N=32 below N=24?"* — comparing a late point
   against an early incumbent lets drift alone answer it, and answer it wrong in
   the direction that inflates the peak and therefore inflates AC2's target.
   That is the one error this issue cannot ship, so the comparison is not made.
