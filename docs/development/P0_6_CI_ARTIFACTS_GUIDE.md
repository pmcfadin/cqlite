## Triggering CI Artifact Generation

### Automatic Triggers

The workflow runs automatically on:
- ✅ Push to `main` branch
- ✅ Push to `develop` branch  
- ✅ Pull requests to `main` or `develop`

### Manual Trigger

To generate fresh artifacts manually:

1. Go to Actions → SSTableDump Parity Gate workflow
2. Click "Run workflow" button
3. Select test scope:
   - `quick` - Basic validation (~5 minutes)
   - `full` - Comprehensive validation (~15 minutes) **[RECOMMENDED]**
   - `comprehensive` - Full corpus validation (~25-30 minutes)

### Command Line Trigger (with GitHub CLI)

```bash
# Trigger comprehensive validation
gh workflow run "SSTableDump Parity Gate (Issue #38)" \
  --field test_scope=comprehensive

# Check run status
gh run list --workflow="SSTableDump Parity Gate (Issue #38)" --limit=1
```
