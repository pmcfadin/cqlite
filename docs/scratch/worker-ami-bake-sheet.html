⛏ Need from you — install sources

Five tools sit behind bootstrap's "install per your setup." Give me the install command for each and the Packer provisioner is complete. gh, rustup, sccache and nextest already have known install paths.

  • roborevcargo install from a git/registry URL? prebuilt binary? private package?
  • openspecnpm global, cargo install, or a downloaded binary?
  • codexOpenAI Codex CLI — npm @openai/codex, or your enterprise's channel?
  • claudenative installer or npm @anthropic-ai/claude-code?
  • agent-notifyyour own ntfy wrapper script, or a package? (optional — can skip)

✓ Confirmed NOT needed — leaner than expected

  • No JDK / Gradle — the Java connector isn't a gate component (nightly/release CI only).
  • No Docker for the worker loop — datasets arrive by curl; Docker is regeneration/nightly-parity only.
  • No system compression libs — lz4/snappy/deflate are pure-Rust crates; no liblz4-dev etc.
  • No protoc — arrow-flight/tonic use pre-generated bindings; no build-time codegen.
  • No EBS dataset snapshot needed — the corpus is small enough to just fetch at boot.
