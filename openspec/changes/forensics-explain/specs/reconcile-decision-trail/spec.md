# reconcile-decision-trail — new capability (forensics-explain, issue #4193, slice F0)

The k-way merge SHALL report every reconciliation decision it makes to a caller-supplied trace
sink, at zero cost when no sink is supplied. All requirements are ADDED.

## ADDED Requirements

### Requirement: R1 — Untraced merges compile to today's code and cost nothing measurable

`KWayMerger` SHALL take a type parameter `S: TraceSink` defaulting to a zero-sized `NoTrace`
whose methods have empty `#[inline]` bodies. Every production constructor
(`new`, `new_cancellable`, `new_with_gc*`, `from_row_iterators`, `build_single_partition_merger*`,
`new_from_readers`) SHALL return `KWayMerger<NoTrace>`. `MergeEntry`, `MergeStep` and
`CompactReport` SHALL gain no field.

#### Scenario: R1.1 strict perf benches within threshold
- **Given** the strict bench set in `cqlite-core/benches/perf-gate.json` (`compaction/narrow`,
  `compaction/wide`, `compaction/tombstone_heavy`, `read/get_partition_big`, `read/get_partition_bti`,
  `read/point_lookup_repeated`, `read/clustering_slice`, `read/full_scan`)
- **When** `.github/workflows/perf-regression.yml` runs PR vs main on the same runner
- **Then** no strict bench's Criterion median regresses beyond its `threshold_pct`.

#### Scenario: R1.2 structural zero-cost assertions
- **Given** `cqlite-core/tests/issue_4193_trace_sink_zero_cost.rs`
- **When** it runs under the gate's `core-tests`
- **Then** `size_of::<NoTrace>() == 0`, every constructor above type-checks as `KWayMerger<NoTrace>`
  (a `fn assert_untraced(_: &KWayMerger<NoTrace>)` call per constructor), and `size_of::<MergeEntry>()`
  equals the value pinned in the test with a comment naming this requirement.

#### Scenario: R1.3 byte parity unchanged
- **Given** the gate components `compaction-byte-parity`, `write-tests`, `query-semantics-oracle`
- **When** the full gate of record runs on this change
- **Then** each is `PASS` with its existing fixture set — no golden is regenerated by this change.

### Requirement: R2 — The verdict vocabulary is closed and each verdict is emitted by exactly one named step

The trail SHALL use exactly the verdicts `winner`, `shadowed-by-timestamp`,
`shadowed-by-tombstone{partition|range|row|cell|collection}`, `expired`, `purgeable`,
`dropped-column`. Each SHALL be emitted from the reconcile step design.md §D1 names and from no
other site. There SHALL be no `unknown`/`other` verdict.

#### Scenario: R2.1 one emit site per verdict
- **Given** `scripts/tests/test_trace_verdict_sites.sh` (registered in `tooling-tests`)
- **When** it greps `cqlite-core/src/storage/write_engine/merge/` for `Verdict::` constructor sites
  outside `trace.rs` and tests
- **Then** every variant appears in exactly the file(s) §D1 assigns it, and any variant appearing
  elsewhere, or any `Verdict` variant not in the list above, FAILs naming the file.

#### Scenario: R2.2 every verdict has a Cassandra-written fixture where it is the only correct answer
- **Given** `cqlite-core/tests/issue_4193_verdict_fixtures.rs`, one `#[test]` per verdict, each
  resolving its table via `sstables_root_for_table` and failing closed when the committed fixture is
  absent, with `now` pinned per design.md §D6 and the expected verdict written as a literal citing
  the `cassandra-5.0.8` source it derives from
- **When** the merger runs over ALL generations of the fixture with a `RecordingSink` in
  full-compaction configuration at that `now`
- **Then** the named cell's `CellDecision.verdict` equals the literal, and its `decided_by` names the
  deciding generation (`run_index`), timestamp, and for tombstones the kind, deletion time, and
  `droppable_at_now`.

#### Scenario: R2.3 gc_grace boundary is exact to the second
- **Given** `test_tomb/gc_before_boundary` and its tombstone's on-disk `localDeletionTime` read
  back from the fixture
- **When** the merger runs at `now = ldt + gc_grace_seconds` and again at `now + 1`
- **Then** the tombstone's verdict is `shadowed-by-tombstone`-carrying (not purgeable, retained) at
  the boundary and `purgeable` one second later, matching #1385's strict-`<` rule.

### Requirement: R3 — The trail never changes the result

A traced merge SHALL emit the identical `MergeStep` sequence as the untraced merge over the same
inputs and configuration.

#### Scenario: R3.1 traced == untraced, every fixture
- **Given** every table under `test_compaction_tombstone_ttl`, `test_tomb`, `test_compactionparity`
- **When** the same inputs are merged once with `NoTrace` and once with `RecordingSink`, same
  `now`/`gc_before`/`purge_safe`
- **Then** the two `Vec<MergeStep>` are equal, and the `RecordingSink` is non-empty for each table
  (an empty trail on a table with rows FAILs — no vacuous pass).

### Requirement: R4 — A generation that cannot be read is an error, never a shorter trail

Building a traced merger over a set of generations SHALL return `Err` naming the unreadable
generation and MUST NOT emit a partial trail (the #4159 class).

#### Scenario: R4.1 truncated Statistics.db
- **Given** a temp copy of a two-generation fixture with one generation's `Statistics.db` truncated
- **When** the traced merger is built over both
- **Then** construction returns `Err` naming that generation's path, and no `CellDecision` is emitted.
