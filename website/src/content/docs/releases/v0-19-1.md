# CQLite v0.19.1 — patch release

v0.19.1 is [v0.19.0](/cqlite/releases/v0-19-0/) plus two changes. Nothing else changed.

## Fixed

- **`cqlite compact --major` could lose a fully-expired input** (#4666). The command deleted an
  input that held only expired data right after writing the merged output, before the output was
  published. If the run then failed or was killed, that input was gone. Inputs are now removed only
  after the output is durable: its files are fsynced with `TOC.txt` last, and then its directory.
  A crash before that point leaves every input in place.

## CI

- **Release builds use the pinned toolchain** from `rust-toolchain.toml`, the one the gate tests,
  instead of floating stable (#4648).

If you ran `compact --major` with v0.19.0 and it failed partway, check that your input
SSTables are all still present. Upgrade to 0.19.1. The full list is in the
[CHANGELOG](https://github.com/pmcfadin/cqlite/blob/main/CHANGELOG.md).
